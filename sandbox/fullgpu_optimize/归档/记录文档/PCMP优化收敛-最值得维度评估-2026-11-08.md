## 二、最值得优化的维度（分层结论）

### 第一层：零争议，立即做（5/5 或 4/5 共识，零行为风险，当天~三天）

**1. 可观测性/台账层**（全票）
digest 正则 Done 污染（实测已发生）+ mesh_stats 裸数字恒空 + exitcode [int] 溢出卡 running + 生效参数不回显 + bpMs/badnormal/rollback/conflicted 全部"算而不存"。墙钟收益 0，但它是**一切验收、A/B、扫描、质量门的前置**——不修它，后面所有优化都不可度量。工时 1-3 天。

**2. 纯删除/快赢止血包**（全票）
.nrm 停写（50W 12.6MB/次、25M 档 1.26GB/次）+ STL 读回校验降格（0.2-0.45s）+ readSoup 二次读消除 + 死代码第一批 ~690 行 + 日志单位 m→mm + golden 改名+manifest。全部高置信、当天~两天兑现。

**3. 测试止血**（4/5）
gtest 换静态 1.14（消 SEH 崩溃掩盖）+ Release 裸 assert 修复 + 10.4 四层修复的守护断言。半天买回 53 个测试（迁移行为快照）的意义——**plan 全部完成判据建立在可能说谎的测试上**。

### 第二层：强共识，本周~两周

**4. 对拍量具与指标地基**（5/5）
GomCheck（在系统 temp 随时会丢）+ mesh_compare（已构建不在链）产品化入链；槽级指标行格式；golden 三份互异 SHA 基准 manifest。这是 final-plan S8.5"4 周 8 轮对拍"的验收凭据，也是迁移对冲 P5 的本体。

**5. 风险止损包**（B 主导，成本极低）
- **GOM 合规冻结**：6611 导出签名级逆向已参数化进自研代码，迁入商用即引爆且不可逆——法务结论前冻结通道+命名切割，零技术成本；
- **degraded 隔离**：exit3 判定前移 + 产物改名 .degraded + 报告红标（带病成品直达客户是常态风险）；
- NaN 关键判定 isfinite（3-5 处）+ CUDA malloc 返回检查 + 链尾方向一致率 gate（30k 采样，GomCheck 思路）。

**6. 测量先行**（反方代理的硬条件）
先开 HOLE_FILLER_TIMING 拿 MHF 分段真实分布（决定 3-6s 边表收益是否成立）；先分解 stats 29.6s 构成（决定并入收益）；先做同参数重复方差实验（一切 A/B 的统计前提，从未做过）。半天~一天/项，买"该不该立项"的裁决依据。

### 第三层：有价值但有硬条件

**7. stats 并入 step3**（账面最大 22-29s，但反方代理拦截）：stats≈C_env(>80%) 环境项未分解；并入=换测量口径（Open3D 读回焊接 vs SR 内存网格），5 个数字与 6 run 历史基线断裂。**条件：先分解计时+冻结读回口径双跑一段对照**。
**8. 25M 分档验证**：裁决三个产品级阻塞事实（无成品路径/超时/显存贴顶），旧仓产物 From=2 免费起跑，1-2 周。
**9. SR 拆库 + common GPU 内核去重**：迁移依赖链 [0] 号与 S7 前置，可并行启动不占关键路径（战略代理 G 档）。
**10. 上游信息通道提案**：spacing 0.59 实为 0.5 体素影子、源头本就 float32、视向死点在融合现场——**治根方向在链外一列 uint32**，沙盒侧只做验证实验+提案，不入产线代码。

## 三、明确不值得做（三代理一致否决）

| 项 | 否决理由 |
|---|---|
| MHF 深拷贝消除 | 实测 ≤0.1s（<0.5% 近不可测），且被迁移吞没 |
| 全链边表/CSR 统一 | 月级工程 3-6s 低置信收益，100% 被 R1 索引网格重写替代 |
| BPV2 非确定性根治 | 9+ 独立非确定源需四层深改，绿地必重写；统计级协议（多次取中位）用 1% 成本买到 80% 决策价值 |
| seeds GPU 化 | 墙钟 0-0.4s（9.6s 是 12 线程累加值非墙钟）；"大档收益"前提（5000W 成品路径）不存在 |
| .asc binary 化 | 给即将退役的过渡态镀金；序列化层物理在仓外无人供数据；并行/直解同效不动格式 |
| 参数扫描 20 项补齐（现在） | 前置三缺：无方差带、指标层不可信、数据集 1.5/24 格——先扫=产出噪声排序 |
| 继续深度 GOM 逆向对齐 | 每一步加深商用合规暴露；三份基准身份不明且 GOM golden 自身 watertight=false |

## 四、一句话总策略

**时间上限（~50s）由编排层决定且大半会随迁移自然兑现；沙盒期真正的净值产出是 K 级资产——量具、测试快照、标定值、规模模型、负结果索引——加上零成本风险止损。顺序：台账与测试止血（3 天）→ 量具与风险止损包（1 周）→ 测量先行裁决（1 天/项）→ 按裁决结果决定 stats 并入与 25M 验证是否立项；一切结构级深改留给 S5-S9 迁移本体。**
