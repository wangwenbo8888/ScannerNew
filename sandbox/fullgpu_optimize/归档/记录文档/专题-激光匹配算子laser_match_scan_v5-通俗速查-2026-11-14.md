## 一、算子是什么、在哪

| | |
|---|---|
| 全名 | laser_match_scan_v5（激光线匹配 · 第 5 版后段） |
| 位置 | `ops/scanning/laser/laser_match_scan_v5/`（.h 结构与参数 / .cpp 实现） |
| 分工 | 前段（GPU，另一个类）：找候选配对；**本算子＝后段（CPU）**：判定真假、剔坏点 |
| 输入 | 左点 ~3.3 万/帧、卡 ~5.2 万张/帧（前段产出）、段表 ~81 段/帧 |
| 输出 | 配对点 ~2.8 万/帧（左点/右点/线号/段号/带符号残差）→ 交三维重建 |

名词三个：**卡**＝一条候选配对（这个左点↔这个右点↔这根线），卡上带**残差**＝右点实际位置−标定表预测位置（带符号，像素）；**段**＝连续同轨迹的点串，一根激光条的碎片；**票**＝段里持有某根线卡的点数。

## 二、流程逻辑（左→右一帧内顺序）

```
[GPU 前段] 查表预测→发卡(±4px 窗)→传回内存
      ↓
[CPU V5 后段·人工8步骨架]
 第0步 备料：行号复算(y÷0.67)、点状态清点、单点段入口弃
 第1步 计票：每段每线数票＋建静态残差表(每段每线的平均|残差|)
 第2步 入围：支持率>70% 的线进该段候选名单；空名单→弃段＋告警
 第3~6步 级联：三阶段(大≥60→中5~59→小2~4)投票定线
      投票道: 第一名票够(≥4/全票≥2)且是第二名≥2倍→定
      消元(第5步): 定下的线从行重叠邻段票板划掉→回环(第6步)
 第7步 裁决: 票分不出→E=票数比×(次线残差/主线残差)
      E>1.3确认第一名｜E<0.77翻案定次线｜中间死区再等
 第8步 回环: 判后再回投票道循环，直到无段可动；剩余兜底弃
      ↓
 收尾三件(剔坏点):
 ⑪ 自适应清洗: ≥5点段，残差中位为中心，偏离超同伴散布×1.5→剔（跟同伴比）
 τ表+逐点门: 按线号取大段残差中位×4.0为门槛(只紧不松,下限1.2px)，
      只管赢家卡≤4张的段: |残差|>门槛→剔（跟字典比）
 幸存规则: 段内可输出点<2→整段弃
      ↓
 收集打包: 幸存点输出五元组→重建→(帧级视差门)→GPU融合
```

## 三、每步功能一句话

| 步 | 功能 | 为什么 |
|---|---|---|
| 前段·查表 | 每个左点按行查标定表→预测右图位置＋候选线号 | 把大海捞针缩到小窗口 |
| 前段·发卡 | 预测位置±4px 内找到右点就记一张卡＋算残差 | 宁多勿漏，真假后段再判 |
| 0 备料 | 行号、状态、丢弃单点段 | 单点零复核，实测多垃圾 |
| 1 计票 | 段×线票数＋平均残差表 | 后面投票/裁决的数据基础 |
| 2 入围 | 支持率门（>70%）筛候选 | 低于七成的线没戏，别干扰投票 |
| 3~6 级联 | 三阶段投票＋消元＋回环 | 大段证据足先定；一根线同行只归一段 |
| 7 裁决 | 票僵持时按残差定夺（对称双门） | 票少但位置准的线能翻案 |
| 8 回环 | 判后回投票再循环 | 消元解锁邻段，级联吃尽 |
| ⑪ 清洗 | 段内跟同伴比剔离群 | 抓"个别点飘" |
| 逐点门 | 小段跟字典比剔超标 | 抓"小段整体超差"（⑪样本不足管不了它） |
| 幸存 | 剩<2点整段弃 | 防单点复活出假数据 |

## 四、默认参数（生产 config_baseline 值；括号=代码出厂默认，不同才标）

| 参数 | 生产值 | 管哪 | 通俗含义 |
|---|---|---|---|
| match_threshold | 4.0 | 前段发卡 | 预测位置左右几像素内找右点 |

| share_fast | **0.7**（0.8） | 第2步 | 支持率超过七成才入围 |
| margin_min | 2.0 | 第4步 | 第一名得票须≥第二名两倍 |
| votes_floor / _solo | 4 / 2 | 第3步 | 定线最低票数（有对手/全票） |
| big_seg_min_pts | 60 | 三阶段 | ≥60点算大段优先判 |
| small_seg_max_pts | 4 | 三阶段 | ≤4点算小段（逐点门同界） |
| quality_e_min | **1.3**（1.9） | 第7步 | 确认/翻案对称双门（1.3↔0.77） |

| res_gate / res_gate_k | **开 / 4.0**（关/2.7） | 逐点门 | 门槛=大段中位×4，下限1.2px |
