## 一、帧格式

| 项 | 约定 |
|---|---|
| 编码 | ASCII 文本 |
| 分帧 | `;` 结尾分帧 |
| 载荷格式 | `<指令> <参数字母><值> <参数字母><值> … ;` —— 指令与参数、参数与参数之间单个空格分隔，参数字母与数值间无空格 |
| 大小写 | 指令/参数字母均大写；数值十进制（G02 温度含一位小数） |

## 二、下行指令（上位机→下位机，4 条）

### N10 采集指令

```
格式：N10 H<频率> B<补光> T<管1> V<管2> C<管3> D<管4> L<激光亮度>;
示例：N10 H30 B60 T1 V1 C1 D1 L50;
```

| 参数 | 取值 | 语义 |
|---|---|---|
| H | 1–200 | 拍照频率（Hz） |
| B | 0–100 | 补光灯亮度 |
| T | 0/1 | 激光管 1 开关（0:关 1:开） |
| V | 0/1 | 激光管 2 开关 |
| C | 0/1 | 激光管 3 开关 |
| D | 0/1 | 激光管 4 开关 |
| L | 0–100 | 激光管亮度 |

**触发语义**：

- 每次触发：**两个补光灯与两个相机全部同步触发**（每帧双目同时采图＋双补光点亮）
- 激光管：仅已开启（参数=1）的管参与，按 **T→V→C→D 顺序在已开启管间循环轮流**，每次触发点亮一管：
  - `T1 V1 C0 D0` → T,V,T,V,…
  - 仅 `T1` 开启 → 每帧均为 T
  - `T1 V1 C1 D0` → T,V,C,T,V,C,…
- 触发节奏由 H（拍照频率 Hz）决定

### N11 停止采集

```
格式：N11 H0;
```

| 参数 | 取值 | 语义 |
|---|---|---|
| H | 0 | 停止采集 |

### N12 设定温度回传周期

```
格式：N12 T<周期>;
示例：N12 T5;
```

| 参数 | 取值 | 语义 |
|---|---|---|
| T | 1–1000 | 温度回传时间（ms），驱动 G02 上报间隔 |

### N13 设定加热温度

```
格式：N13 S<温度>;
示例：N13 S45;
```

| 参数 | 取值 | 语义 |
|---|---|---|
| S | 0–80 | 设定加热温度 |

## 三、上行指令（下位机→上位机，3 条）

### G01 按键手势

```
格式：G01 <键><手势>;
示例：G01 U1;   （上键单击）
```

| 键 | 1=单击 | 2=双击 | 3=长按 |
|---|---|---|---|
| U（上键） | U1 | U2 | U3 |
| L（左键） | L1 | L2 | L3 |
| R（右键） | R1 | R2 | R3 |
| M（中键） | M1 | M2 | M3 |

### G02 温度回传（4 路）

```
格式：G02 A<t1> B<t2> C<t3> D<t4>;
示例：G02 A25.3 B25.4 C26.0 D24.5;
```

| 参数 | 取值 | 语义 |
|---|---|---|
| A | 0–100 | 温度传感器 1 |
| B | 0–100 | 温度传感器 2 |
| C | 0–100 | 温度传感器 3 |
| D | 0–100 | 温度传感器 4 |

上报周期由 N12 设定。

### G03 硬件触发拍照次数

```
格式：G03 S<次数>;
示例：G03 S500;
```

| 参数 | 取值 | 语义 |
|---|---|---|
| S | 0–无限 | 硬件触发相机拍照次数 |
