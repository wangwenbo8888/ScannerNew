# 流水线文档

> 本目录独立、完整描述 JEAMMWARE 工程涉及的三条流水线。
> 详细设计稿见 `docs/开发需要的信息/业务流/`，逐算子说明见 `docs/算子说明文档/`。

## 流水线清单

| 编号 | 流水线 | 文档 | 性质 |
|---|---|---|---|
| 01 | 标定流水线 | `客户端标定流水线.md` | 工厂现场标定（调试期，一次性） |
| 02 | 扫描流水线 | `客户端扫描流水线.md` | 运行时扫描（用户期，持续） |
| 03 | 厂家标定流水线 | `03-厂家标定流水线.md` | 出厂标定（独立子工程 `factory_calib/`） |

## 三条流水线的关系

```
                ┌─────────────────────────────────┐
                │  03 厂家标定（factory_calib）       │
                │  模块1 相机 / 模块2 激光（独立 CLI） │  → 出厂基准参数
                └──────────────┬──────────────────┘
                               │ （基准参数可作 01 的初始值种子）
                               ▼
   ┌─────────────────────────────────────────────────────────┐
   │  01 工厂标定（现场）                                        │
   │  姿态采集判断 → 相机标定 + 激光虚拟相机标定 → 温度补偿表       │
   │  产出：内/外参、立体矫正、Q、虚拟相机外参、各温度补偿表         │
   └────────────────────────────┬────────────────────────────┘
                                │ （标定参数注入运行时）
                                ▼
   ┌─────────────────────────────────────────────────────────┐
   │  02 扫描（运行时）                                          │
   │  单帧：掩膜分离 → ccl → (标记点链 ‖ 激光链) → 配准           │
   │  跨帧：多流水线并行调度                                      │
   │  后处理：全局 BA 优化                                       │
   │  产出：每帧 R/T + 标记点3D + 激光3D点云                      │
   └─────────────────────────────────────────────────────────┘
```

## 算子复用

三条流水线共享 `modules/09_operatorlib/` 算子库（命名空间 `calib::`）：

- **标记点链**（`core/marker/`，12 算子）：01 姿态判断 + 02 扫描配准共用
- **激光线链**（`core/laser/`，4 算子）：01 激光标定 + 02 扫描共用
- **视觉前端**（`core/vision/`：`mask_extract` + `ccl`）：所有流水线共用入口
- 03 `factory_calib/` 为独立子工程，算子逐字拷贝自 09_operatorlib（受保护，独立演进）

## 标定 vs 扫描的关键差异

| 维度 | 标定（01） | 扫描（02） |
|---|---|---|
| 激光线形态 | 完整 + 有序 | 断裂 + 无序 |
| 激光匹配模式 | ByLabel（逐线编号）+ `laser_match` | Flat（统一占位）+ `laser_match_scan`（查温度表） |
| `epipolar_interp` | `lineIdCheck=true` | `lineIdCheck=false` |
| 去畸变参数 | 阶段4 用**标定后**内参 | 用**温度补偿表**查表结果 |
| 配准 | 单帧 `frame_fuse` | `optical_flow_fuse`（默认）+ `frame_fuse`（降级） |
