# 03 — 厂家标定流水线（factory_calib）

> ⚠ **AI 只读保护区**（见 `factory_calib/AGENTS.md`）：本文件仅记录其 `README.md` 公开的高层概要，不涉及受保护源码。**权威与细节以 `factory_calib/README.md` 为准**。

## 1. 概述与目标

- **定位**：JEAMMWARE 厂家标定工具，产线交付物（独立子工程，自包含 CMake）
- **触发**：出厂标定，独立于主工程运行（产线机器执行）
- **目标**：产出相机标定 JSON + 激光标定 JSON，可作为 01 工厂标定的初始参数种子
- **状态**：已通过 Phase 0-7 实施 + 事后 code review + Release 全量回归（26/26 绿：模块1 8/8 + 模块2 18/18）

## 2. 输入 / 输出

### 模块1

- **输入**（`data_in/camera/`）：`config.json`（棋盘格 + 算子参数）+ `temps.txt`（参考温度）+ `left/` `right/` 棋盘格图集
- **输出**（`data_out/camera_calib.json`）：
  - `intrinsic`（L/R 的 K/D + rvecs/tvecs + rms）
  - `extrinsic`（R/T/E/F）
  - `rectify`（R1/R2/P1/P2/Q + validRoi{L/R}）
  - 4 张温度表（intrinsicTempTableL/R、extrinsicTempTable、stereoRectifyTempTable）

### 模块2

- **输入**（`data_in/laser/`）：`config.json`（激光链参数）+ `camera_calib.json`（← 拷贝/软链自模块1 输出）+ `pose_00..24/`（`L_tubeX.png` / `R_tubeX.png` + `temp.txt`）
- **输出**（`data_out/laser_calib.json`）：
  - `virtualK/R/T`（优化后）
  - `laserExtrinsicTempTable`（虚拟→L/R 每温度）
  - `planeMapTempTable`（每温度映射）

## 3. 两个可执行（流水线）

```
┌──────────────────────────────────────┐      ┌──────────────────────────────────────┐
│  模块1：camera_calib.exe  (CPU)        │      │  模块2：laser_calib.exe  (CUDA)        │
│  相机内/外参 + 立体矫正 + 温度补偿表    │ ───► │  激光虚拟相机标定 + 温度补偿表          │
│  输入: 棋盘格图集 + config             │      │  输入: pose_xx 激光图 + camera_calib.json│
│  输出: camera_calib.json              │      │  输出: laser_calib.json                │
└──────────────────────────────────────┘      └──────────────────────────────────────┘
```

- **模块1**（`module1_camera/`）：纯 CPU，无 CUDA，任何机器可构建。功能覆盖 01 流水线阶段 3 的相机标定（内/外参 + 立体矫正 + 温度补偿表）。
- **模块2**（`module2_laser/`）：CUDA，功能覆盖 01 流水线阶段 4 的激光虚拟相机标定 + 温度补偿表。**需消费模块1 输出（串行）**；CLI 仅 Release 可构建（Debug 自定义 OpenCV 缺 `imgcodecs`，CMake 自动跳过 CLI，仅算子自测可跑）。

> 两模块算子与 01 同源（逐字拷贝自 `modules/09_operatorlib/`），算子链详见 `客户端标定流水线.md`。`factory_calib` 内部实现细节见其 `README.md`（AI 只读）。
> 模块2 退出码：`0` = 完整流水线成功；`1` = 部分失败（任何算子 `success=false` / `haveVirtualPose=false` / 无累积 3D 点）。stderr 经 spdlog 打印诊断。

## 5. 与其他流水线的关系

- **与 01 工厂标定的关系**：算子链等价（同源），但 `factory_calib` 为**独立 CLI 工具**（输入 JSON / 图像目录，输出 JSON），01 为**集成流水线**（实时图像流）。`factory_calib` 可为 01 提供初始参数种子。
- **边界约束**：`factory_calib` 与主工程算子库保持"逐字拷贝"边界，任何分歧会使未来同步困难（见 `factory_calib/AGENTS.md`）。
