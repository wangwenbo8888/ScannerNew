# 01 · 入口与启动（main.cpp）

> `app/main.cpp`（47 行）。程序入口，完成运行时环境准备、组件装配与 Qt 主循环。
> includes 仅本地头（`MainWindow.h`/`AppContext.h`）+ Qt + spdlog，**不直接依赖已退役的 `framework/`**；装配经由 `AppContext`，其底层依赖已迁至 `base/`（`AppContext.h` → `base/types.h`）。

## 启动序列（按代码顺序）

| # | 步骤 | 代码 | 说明 |
|---|------|------|------|
| 1 | OSG 插件路径 | `_putenv_s("OSG_PLUGIN_PATH", "F:/osg3.6.5/install/bin/osgPlugins-3.6.5")` | ⚠ 硬编码绝对路径，部署到其他机器需改 |
| 2 | Qt 高 DPI | `AA_EnableHighDpiScaling` + `AA_UseHighDpiPixmaps` | 高分屏自适应 |
| 3 | 日志初始化 | `spdlog::set_level(spdlog::level::info)` | 仅设级别，未配置文件 sink/轮转（模块10 待建） |

| 5 | QApplication | `QApplication app(argc, argv)` | |
| 6 | 暗色主题 | 加载 `:/icons/dark.qss` 并 `setStyleSheet` | ⚠ **dark.qss 未登记进 resources.qrc，资源路径无效，样式当前不生效** |
| 7 | 装配应用 | `AppContext appCtx; appCtx.initialize();` | 装配点见 [02-AppContext装配](02-AppContext装配.md)；`AppContext.h` 引 `base/types.h`（原 `framework/common/types.h` 已随 framework 退役） |

## 核心要点
- **装配委托给 AppContext**：`main` 只做"环境 + 装配 + 循环"，不直接接触任何组件对象。
- **framework 退役后无残留依赖**：`main.cpp` 自身不 include 任何 `framework/` 路径；`framework/` 目录已删除，其运行时容器/类型（types、EventBus 等）迁至 `base/`，由 `AppContext`（`#include "base/types.h"`）承接。`stubs/` 已补齐，`scan_demo` 可构建。
- **MSAA 8×** 是 3D 渲染质量的关键设置（对应模块3 渲染）。
- **样式表（当前失效，已核实仍 pending）**：`main.cpp` 试图从 `:/icons/dark.qss` 加载暗色主题，但 `dark.qss` 物理存在于 `app/` 却**未登记进 `resources.qrc`**（核实：qrc 内仅 .svg 图标，无 .qss 条目），资源路径无效 → `QFile::open` 失败、样式不生效（静默）。
- **生命周期对称**：`initialize()` 与 `shutdown()` 成对，`AppContext` 析构也调 `shutdown()`（双保险）。
