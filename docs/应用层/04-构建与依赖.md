# 04 · 构建与依赖（app/CMakeLists.txt）

> `app/CMakeLists.txt`（98 行）。产物 `scan_demo.exe`，定义 app 与部分 modules 文件的编译、链接与运行时部署。

## 产物
- 可执行文件：**`scan_demo`**（即 scan_demo.exe）。

## Qt 自动化
| 开关 | 值 | 说明 |
|------|----|------|
| `AUTOMOC` | ON | 自动 MOC（Q_OBJECT） |
| `AUTOUIC` | ON | 自动 UIC（.ui → ui_*.h） |
| `AUTORCC` | **OFF** | QRC 不自动处理，改为手动 `rcc.exe` 命令 |

> `resources.qrc` 通过 `add_custom_command` 调用 `C:/Qt/Qt5.15.2/.../rcc.exe` 生成 `qrc_resources.cpp`，再编入 exe。⚠ 路径硬编码。
> ⚠ 另：`dark.qss` 物理在 `app/` 但**未列入 `resources.qrc`**，故 `:/icons/dark.qss` 资源无效（`main.cpp` 的样式加载当前静默失败）。

## 编入源码（注意：非全部链接 mod_ 库）
```
APP_SOURCES      = main.cpp + AppContext + MainWindow
MOD_CALIBRATION  = modules/01_calibration/{calib_workflow, CalibDialog, CalibDisplay, IntegrateTestDialog}.cpp/h
MOD_SCANNING     = modules/02_scanning/ScannerWindow.cpp/h/.ui
MOD_RENDERING    = modules/03_rendering/OSGWidget.cpp/h
MOD_FILEIO       = modules/06_fileio/file_io.cpp/h
```
⚠ **这些 modules 文件被直接编进 exe，而非通过 `mod_xxx` 库链接**。原因推测：这些是带 UI 的模块（Qt widget / dialog），与 exe 紧耦合；而纯框架/算子库（`mod_devicemgmt`、`mod_operatorlib`）则正常链接。

## 头文件包含目录
`app/` + 工程根 + `modules/{01_calibration,02_scanning,03_rendering,06_fileio,04_postprocessing}`（含 04 但未编其源码，仅为头）。

## 编译宏
`NOMINMAX`（避开 Windows min/max 宏）、`_CRT_SECURE_NO_WARNINGS`。

## 运行时部署（POST_BUILD）
```cmake
add_custom_command(TARGET scan_demo POST_BUILD
    COMMAND copy_dlls.bat "$<TARGET_FILE_DIR:scan_demo>" "$<CONFIG>")
```
`copy_dlls.bat` 按 Debug/Release 拷贝：
- **Qt5**：Core/Gui/Widgets/OpenGL/Svg/SerialPort + `platforms/qwindows.dll`
- **OSG**：osg161 系列 + OpenThreads
- **OpenCV**：core/calib3d/imgproc/imgcodecs/features2d/flann + CUDA 系列（cudaarithm/cudawarping/cudaimgproc/cudev）

⚠ `copy_dlls.bat` 内 Qt/OSG/OpenCV 均为**绝对路径**（`C:/Qt/...`、`F:/osg3.6.5/...`、`F:/opencv4.13/...`），换机即失效。大恒 Galaxy SDK DLL、CUDA runtime、VC++ redist **未** 由该脚本处理（见 [模块11](../模块功能/11-安装部署.md) 待实现）。

## 依赖小结
- **构建期**：Qt 5.15.2、OSG 3.6.5、OpenCV 4.13（含 CUDA）、Eigen、spdlog、大恒 Galaxy SDK。
- **运行期**：上述全部的 DLL + Qt 平台插件。
- **缺失**：统一安装包（NSIS/Inno）、依赖完整打包、首运行配置（均属模块11 待建）。
