## 待实现：从模块3移植套索选择与编辑

> 移植来源：`OSGWidget` 套索相关方法（见 [`03-渲染显示.md`](03-渲染显示.md) 第4节）。目标是在本模块内封装为独立的编辑组件，`OSGWidget` 仅保留渲染职责。

### 1. 套索选择（2D 屏幕多段线）
- 进入/退出套索态：左键加点、右键或闭合首点收尾
- 套索几何：独立正交相机 `POST_RENDER`，绿色 `GL_LINE_STRIP`，闭合后 `GL_LINE_LOOP`
- 命中测试：屏幕投影 + 射线法 `isPointInPolygon2D` 判定圈内点
  - MVP 矩阵来源：`CullCallback` 捕获 → `computeRenderingMVP`（OSG 行主序 → OpenGL 列主序转置）
- `highlightSelectedPoints` — 圈内点高亮为蓝色，保留原色供恢复

### 2. 删除
- `deleteSelectedPoints` / `deletePointsInPolyline` — 删除方式：选中点 alpha 置 0 + 开 `GL_BLEND`（点仍在 buffer，仅不显示）
- `enterLassoDeleteMode` — 套索删除模式，闭合后弹确认对话框（`QMessageBox::question`）

### 3. 撤销
- `undoDelete` — 从删除历史栈顶弹出，还原原色
- 历史记录结构：`{ geom, indices, originalColors }`（记录被删点索引与原色）

### 4. 信号与入口
- 信号 `lassoCompleted()` — 套索闭合后通知外部
- 入口（移植后由本模块承接）：
  - 底部工具栏删除按钮 `m_selectionButtons[9]`（`MainWindow.cpp:1354`）
  - 快捷键 `Ctrl+Z` 撤销（`MainWindow.cpp:1361`）
