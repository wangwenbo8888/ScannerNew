## 子功能细化

### 5.1 点云编辑操作
- **选中**: 框选/套索/球选 点云区域
- **删除**: 删除选中点
- **标记**: 给选中点添加类别标签
- **裁剪**: 按平面/框/曲面裁剪
- **分离**: 将选中区域分离为独立对象

### 5.2 命令栈 (Undo/Redo)
```cpp
class EditCommand {
    virtual void execute() = 0;
    virtual void undo() = 0;
    virtual void redo() = 0;
};
class EditCommandStack {
    std::vector<std::unique_ptr<EditCommand>> undoStack_;
    std::vector<std::unique_ptr<EditCommand>> redoStack_;
    void push(EditCommand*);  // execute + push to undo
    void undo();
    void redo();
};
```

### 5.3 操作历史
- 记录每次编辑操作的元数据 (时间/类型/影响点数)
- 可导出为审计日志

### 5.4 UI交互
- 工具栏: 选择/删除/标记/裁剪/分离 按钮
- 快捷键: Ctrl+Z(撤销) / Ctrl+Y(重做)
- 右键菜单: 上下文操作
