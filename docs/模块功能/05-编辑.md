## 2. 代码需要调整的

核心调整：**把寄居在模块3 的编辑逻辑解耦迁移至本模块**，让 `OSGWidget` 退回纯渲染、本模块成为编辑权威。

### 2.1 建库与目录骨架
- `modules/05_editing/CMakeLists.txt`：由 `INTERFACE` 占位改为真实静态库 `mod_editing`（`STATIC`），新增 `include/` + `src/`。
- 新建编辑组件头/源（如 `LassoSelector`、`EditController`），吸收下表从 `OSGWidget` 抽出的方法与状态。

### 2.2 从 `OSGWidget` 抽出（迁移项）
将以下方法与状态从 `modules/03_rendering/OSGWidget.{h,cpp}` 移入本模块；`OSGWidget` 仅通过接口/信号接收编辑结果。

| 类别 | 抽出内容 | 来源 |
|---|---|---|
| 套索交互 | `enterLassoMode`/`exitLassoMode`/`addLassoPoint`/`closeLasso`/`updateLassoGeometry` 及 5 个 `m_lasso*` 成员 | `OSGWidget.h:141–148` + `.cpp` 对应实现 |
| 删除 | `deleteSelectedPoints`/`deletePointsInPolyline`/`enterLassoDeleteMode` | `.cpp:863,912,1320` |
| 命中 / 高亮 | `isPointInPolygon2D`/`highlightSelectedPoints`/`m_highlights` | `.cpp:1168,1184`、`.h:159` |
| 撤销栈 | `pushDeleteUndo`/`undoDelete`/`m_deleteHistory` | `.cpp:1286,1298`、`.h:228–233` |
| 信号 | `lassoCompleted()` | `.h:104` |

> 套索渲染依赖正交相机 `POST_RENDER` + `CullCallback` 捕获的 MVP 矩阵（`computeRenderingMVP`，OSG 行主序 → OpenGL 列主序转置）；迁移时需明确渲染上下文 / 矩阵的获取契约（由 03 提供，05 消费）。

### 2.3 入口重新接线（`app`）
- `app/MainWindow.cpp:1354`（删除按钮）、`:1361`（`Ctrl+Z`）：由直接调 `m_3dView->...` 改为经由本模块 `EditController`，再作用于渲染层。

### 2.4 编辑源与融合源同步（设计调整）
- 现状：删除仅把渲染 `Geometry` 的 alpha 置 0（点仍在 buffer），而点云**权威源**是融合算子的 `fusedPoints_`（modules/09 `laser_cloud_fuse` / `marker_cloud_fuse_cpu`）——两套点云不同步（参见 [`06-文件管理.md`](06-文件管理.md) §3.1）。
- 调整方向：编辑操作应作用于统一权威源（或经 `PointCloudBuffer` / 融合算子显式回写），而非只改渲染几何，避免"删了看不见、导出还在"。

## 3. 需要增加的

### 3.1 撤销 / 重做体系
- **重做（Redo）**：当前仅 `undoDelete`，无 Redo。
- **统一命令栈**：抽象 `EditCommand`（do/undo/redo 接口），把删除、高亮及后续各类编辑统一为命令对象，替换当前两套并存的历史栈（`m_highlights` / `m_deleteHistory`）。

### 3.2 点云编辑操作（新增）
- **真删除 / 隔离**：当前仅"隐藏"（alpha=0），需支持从权威源真删除 / 单独导出选中集。
- **裁剪**：平面裁剪 / 包围框裁剪 / 曲面裁剪（保留或删除圈内/圈外）。
- **分离**：按选择集拆分为多个点云对象。
- **平滑 / 降采样**（可选）：编辑态局部处理。

### 3.3 标记点编辑
- 标记点（marker）的增 / 删 / 改、类别标签赋值、与 `marker_cloud_fuse_cpu` 产出的标记点集对齐编辑。
- 标记点选择与点云选择的统一交互。

### 3.4 交互与入口
- **接线底部工具栏其余 9 个选择按钮** `m_selectionButtons[0]–[8]`（当前纯图标未接线，仅 `[9]` 删除已接）。
- Redo 快捷键（如 `Ctrl+Shift+Z` / `Ctrl+Y`）。

### 3.5 治理
- 操作历史 / 审计日志（谁在何时对哪片点云做了何种编辑），支持回放与工程存档。

### 3.6 后续路线（三步，按收益排序）
1. **止血（最优先，小改动）**：删除/撤销接 06 `PointCloudBuffer` 唯一权威容器——命中点打墓碑标记（软删除），渲染读时跳过，导出立刻正确；撤销=清标记。**不迁模块结构，只加回写边**。
2. **搬家（等 02 扫描链定型后）**：05 转 STATIC 库落地，吸收 OSGWidget 的删除/命中/撤销栈，引入 `EditCommand` 统一命令栈（补 Redo）；OSGWidget 退回纯渲染（即 §2 迁移计划）。
3. **长本事（编辑真做起来后）**：真删除（挤掉墓碑）、裁剪/分离、其余 9 个选择按钮接线、操作历史审计。

> 排序理由：权威源通路是地基（扫描/导出/后处理都受益）；搬家依赖 02 定型（融合算子仍在演进，早迁白迁）；新功能最后（地基不稳加了也白加）。
