## 职责
实时扫描180-200fps: 标记点链(配准求R/T) ∥ 激光链(三维重建) 双链并行。

## 当前状态: ✅ 单帧流程已实现, ⚠️ 并行调度待完善

## 子功能细化

### 2.1 预处理 (GPU)
- **mask_separation**: 激光/标记点掩膜分离 → `d_markingPointMask` + `d_laserMask`
- **ccl (连通域分析)**: 标记点区域标签 → **分支点**, 之后双链并行

### 2.2 标记点链 (CPU, P-core)
```
03 image_split → 04 zernike_edge → 05 image_merge → 06 undistort_cpu
→ 07 ellipse_fit → 08 marker_match → 09 epipolar_intersect
→ 10 edge_match → 11 point_reconstruct
```
- 输出: 标记点3D坐标 + 法线 + 半径

### 2.3 激光线链 (GPU, CUDA stream)
```
04 steger(Flat模式) → 05 undistort_cuda → 06 epipolar_interp
→ 07 laser_match_scan(全局查找) → 08 laser_reconstruct
```
- **17线**: laser_match_scan 通过温度补偿平面映射表全局查找确定line_id
- 输出: 激光3D点云 `d_points3d`

### 2.4 单帧配准
- **默认: optical_flow_fuse** (光流配准, 需PrevFrameState)
- **降级: frame_fuse** (PFH特征配准)
- **双失败: 继承上一帧R/T**
- 输出: R(3×3) + T(3×1)

### 2.5 并行流水线调度 (扫描流水线260629.md)
```
P0采集线程 ─200fps─► RingBuffer (双目同帧单元)
                        │
    ┌───────────────────▼──────────────────────────────┐
    │ Pipeline 0..X-1 (每个 = 1专用E-core + 1动态P-core + 共享GPU 2 slots) │
    │                                                     │
    │ E-core编排:                                          │
    │   ② GPU全链: mask_sep → ccl → laser 04~08 (串行)    │
    │   ③ ccl完成后双链并行:                                │
    │      GPU: 激光链继续                                  │
    │      P-core: 标记点链 03~11 + 配准                    │
    │   ④ 合并发布: FrameResult → 输出队列                  │
    │                                                     │
    │ Pipeline X (第+1): 预备态, P-core释放即接管           │
    └─────────────────────────┬──────────────────────────┘
                              ▼
    FrameResult输出队列 (lock-free MPMC)
    { frameId, R, T, markerPoints3D, laserPoints3D, temperature }
```

**关键参数**:
- GPU slot数: 2 (每slot半SM)
- Pipeline数: X = (X-1) + 1 (P-core数 + 1预备)
- RingBuffer slots: 4×X
- 丢帧阈值: 2×X (超过则跳到最新帧)
- PrevFrameState: `atomic<shared_ptr>` 最新快照模型

**纯标记点模式**: 关闭激光链, 仅标记点链 + 配准 (用于无激光场景)
