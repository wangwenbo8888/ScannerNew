## 3. 视图③ 并行调度时序图

**视角**：调度两维度。**3.1** 单帧生命周期状态机（参照 `调度260629 §4.1` 表格风格）；**3.2** 多帧硬件资源时序占用（ASCII 甘特，参照 `调度260629 §2.1/§2.2` 框图风格）。

### 3.1 单帧生命周期状态机（帧 N）

```
   帧 N 生命周期 (E 核编排 · 1 E核独占):

   状态           运行位置      算子                              等待条件
   ──────────────────────────────────────────────────────────────────────
   ① PREFETCH     E 核          抓帧 · 组装输入                    环形缓冲有新帧 (lag>2X 跳最新)
   ② WAIT_GPU     —            (排队)                             GPU 槽空 (先到先得)
   ② RUN_GPU      GPU 槽 A/B   ┌ mask_separation → ccl            持槽串行 · 中间不释放
                                │   → (ccl 就绪 → 触发 ③)
                                └ 激光 04~08: steger→undistort_cuda
                                      →epipolar_interp→laser_match_scan
                                      →laser_reconstruct
   ③ WAIT_PCORE   —            (GPU 激光链继续在槽后台跑)
   ③ RUN_PCORE    P 核 (动态)   标记点 03~11 → optical_flow_fuse     P-core Broker 分配 worker
                                  (失败 → frame_fuse 兜底)
                                  load/store g_prevState (最新快照)
   ④ PUBLISH      E 核          汇合两边 → 组装 FrameResult          ②激光链 + ③标记点链 都完成
                                → 输出队列 + 累加逐帧 obs
                                → 释放 GPU 槽 · 回 ①

   关键并行 (§4.3):
     · ② RUN_GPU 内 ccl 完成后, GPU 激光链 ‖ P 核标记点链 完全并行 (时间重叠)
     · 跨帧并行: X 流水线竞争 X-1 P 核 + 2 GPU 槽 → 恒有 1 流水线待命
     · PrevState 最新快照模型 (§4.3 决策3): load 可拿非 N-1 帧 → 打破链式等待
```
