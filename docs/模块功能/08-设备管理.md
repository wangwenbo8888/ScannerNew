# 模块8 · 设备管理

> 一句话：08 是**设备总管家**——相机、下位机、按键、温度计都归它管，别人要用电设备只找它一个，不许私下摸。
> 返回索引：[`模块功能目录.md`](../../模块功能目录.md)

## 1. 功能目标

### 1.1 DeviceManager 设备管理器（【公】app 存活件，开机即造、全程不销毁）
- 做什么：总管家——①一键开关机（open()/close() 包办全部设备）；②切模式（去标定/去扫描/回待机）；③总判断——收集各路信息→判断→发执行命令（含全部按键语义：菜单/门控/动作映射）；④记账广播（下位机状态记录[原 3 号灯]、温度、设备消息、参数变化——ParamStore 唯一参数账本，UI 控件与其双向同步）。
- 交互：01-②③④⑨；02-②③④⑥⑩。

### 1.2 CameraControl 相机管理（08 内部）
- 做什么：相机参数师——**只设相机参数**：开闭相机、曝光、分辨率、增益、装标定参数、报相机温度；拍照触发不归它管（开闭由 MCUDriver 经下位机硬触发）。
- 交互：01-④；02-④（帧温上报）。

### 1.3 MCUDriver 下位机驱动（08 内部）
- 做什么：串口传令兵——①下行 4 条 typed 命令（N10 七参〔即启采〕/N11 H0〔停止/熄灯〕/N12 T〔温度周期〕/N13 S〔加热〕——协议 260831）；②统一上行入口（G01 手势/G02 四路温度/G03 触发计数，见 §1.7 上行架构）。
- 交互：01-③④；02-③④⑥。

### 1.4 KeySemantics 按键裁判（08 内部）
- 做什么：按键语义裁判——**直收 MCU 已判手势**（G01 帧手势位 1短/2双/3长；KeyManager 已退役），查门禁＋菜单状态→转移表→执行动作；「预留」＝协议可达、产品未定义。
- 交互：02-③⑥（手势）；01 全程无按键。

### 1.5 HardwareMonitor 硬件监控（08 内部）
- 做什么：体检护士——每秒巡检两层：①外设层（在线状态/帧率/左右配对失败率，2 号相机灯在此）；②上位机自体检（CPU 温度[过热降频先导预警]、CPU 占用[仅记录存档不告警]、GPU 显存/温度、内存水位、磁盘剩余[<10GB 预警/<1GB 停写保护]、关键线程心跳＋业务三件套：采集帧率/处理帧率/丢帧率——计数器挂 06 容器，巡检广播在此；UI 状态栏显示）。
- 交互：01-④；02-④⑤。

### 1.6 许可证/激活（目标）
- 做什么：设备开锁——加密狗/软授权检查、试用期、功能等级。
- 交互：—。

### 1.7 上行架构（「串口一条道，进门分道走，总管家汇合」）
- 传输合：上行共用一条串口一个分帧器；处理分：温度（周期遥测可丢）与手势（离散事件丢失代价高）消费节奏不同，禁止混入同一处理器；汇合：各链到 DeviceManager 统一判断。
- 配套：温度由 MCU 按 N12 T 周期主动上报（默认 100ms，替代 PC 周期轮询省下行带宽）。

```
        下行(命令)                          上行(上报)
app/工作流 ──► DeviceManager ──► MCUDriver ──串口──► 下位机
                 ▲   │命令(N10启采七参/N11停/N12温度周期/N13加热)  │
                 │   ▼                                   串口(一条道)
    相机参数 ◄── CameraControl                        MCUDriver 分帧
                                                    │ G01 手势(MCU已判)─► KeySemantics ──┐
                                                    │ G02 温度(恒4路)─► 温度链(可丢,下周期还有)┤► DeviceManager
                                                    └ G03 触发计数 ──► 记账(未消费,D6)────┘  (收集→判断→发令)
                                                                                          │
                                                       EventBus 广播(温度/手势/设备消息) ─┘► app/工作流
```

> 状态机照应：全工程状态机灯现 3 台——1 号全局门禁机（app 第 5 存活件，代码在 10）、2 号相机灯（08 HardwareMonitor）、4 号按键菜单机（08 DeviceManager 内菜单逻辑）。原 3 号下位机灯已裁撤（状态由 DeviceManager 记录）；原 5 号手势判定机取消（手势判定归 MCU，G01 直达）。

## 2. 实现现状（以代码为准）

- 编译归属：STATIC 库 `mod_devicemgmt`（`modules/08_devicemgmt/CMakeLists.txt`），PUBLIC 链 base＋OpenCV＋spdlog，PRIVATE 链大恒 Galaxy SDK＋Pdh（自检 CPU 占用）；命名空间 `Scanner::device` / `Scanner::device::serial` / `Scanner::hal`。
- 生命周期与线程总图：

```
【公】DeviceManager（app 存活件）
  ├─ 逻辑线程（10ms 一拍）：排空任务队列→pump 上行环→手势 dispatch
  │    →Warmup tick→故障巡检→参数快照
  ├─ MCUDriver（:IMCU）
  │    ├─ rx 线程（零业务）：read→feed→按 G01/G02/G03 入 3 环（手势/计数各 64＋温度 8）
  │    ├─ 写线程：下行帧落线（QSerialPort 专属线程）
  │    └─ 逻辑线程：send*/pump（排空环→分流回调；盲发无 ACK 对账）
  ├─ CameraControl（:IScannerCamera）：SDK 回调线程→双缓冲左右配对交付
  ├─ HardwareMonitor：巡检线程（默认 1s，纯读取）
  └─ 无锁零件（CommandChannel/ParamStore/MenuLogic/Warmup）
       单一属主＝逻辑线程；门面变异入口经 post() 编队（容量 64 满丢新）
```

- 测试覆盖：tests/ 12 个测试 exe 注册 ctest（serial 层 4＋按键链 2＋门面零件 6）；工程全量 ctest 99/99 绿（Release 单配置）。

- 测试：test_frame_codec（经 MCUDriver 组合链）。
- 状态：✅

### 2.4 `serial/FrameCodec.h/.cpp`（FrameCodec，08-4）
- 核心能力：串口字节的翻译官——字节流拼帧/拆包的**裸文本成拆器**（协议 260831 定稿），协议口径收敛此处。
- 协议/契约：帧＝`载荷;`（ASCII、`;` 结尾分帧、无校验无 seq）；载荷允许空格（`N10 H30 B60 …`/`G02 A25.3 B25.4 …`）；保留 50ms 半帧超时。
- 线程/并发：feed 与 advanceTimeout 须同线程（挂起缓冲无锁）。
- 测试：test_frame_codec。
- 状态：✅

### 2.5 `serial/CommandChannel.h/.cpp`（CommandChannel，08-5）
- 核心能力：下发命令的快递员——**盲发直通**（encode＋写出口，同步回告写成败；协议 260831 无 ACK，D4/D8）。
- 协议/契约：sendGroup＝依序直发，任一步写失败整组短路回调报败；无重传无待确认表。
- 线程/并发：非阻塞铁律（send 内等待＝自锁）；单线程属主＝逻辑线程（无锁设计）。
- 测试：test_command_channel。

### 2.7 `MCUDriver.h/.cpp`（MCUDriver，08-7）
- 核心能力：下位机驱动的组装壳——SerialPort＋FrameCodec＋CommandChannel＋3 有界环拧成一体，:public IMCU。
- 交互：typed 四命令——N10 `H<1-200> B<0-100> T/V/C/D<0|1> L<0-100>`（七参即启采）/ N11 H0（停止/熄灯同一命令）/ N12 `T<5-1000>`（温度周期，MCUDriver 钳制）/ N13 `S<0-80>`（加热，入口钳制）；旧命令（N11H1/N12Z/N13E/N15/N16）已删净。
- 探测：逐口发 `N12 T100`→300ms 内收到任意 G 帧＝命中（N12 即开温度上报，G02 到达为链路活凭据；纯回环线不回 G 帧不误命中）。
- 线程/并发：rx 线程零业务（read→feed→入环）＋写线程落线＋逻辑线程 pump；记账口 lastRxTime 心跳/gestureRingDropped/parseFailCount/shotCount（G03 记账口径 D6）。
- 错误/降级：writeOverride 测试缝（测试模式单线程不开真串口）。
- 测试：test_mcu_driver。
- 状态：✅

### 2.8 `DeviceManager.h/.cpp`（DeviceManager，08-8）【公】
- 核心能力：设备大总管——外面只找它，它管相机/下位机/按键/温度所有硬件；组合根内部 unique_ptr 持有全部零件（铁规：不漏零件指针/类型，对外只出值类型与薄转发）。
- 交互：open 一条龙（相机→MCU 搜口探测〔N12 T100＋G 帧凭据〕→N12 周期定版→逻辑线程，任一步败倒序关）；待机/标定＝**纯软件态**（不发命令，D2）；启采＝单发 N10、停采＝N11 H0；**N10 四管掩码按 ScanMode 固定映射**（D7 不入账本：标点 T0V0C0D0＋L0＋B 抬 40〔kMarkerOnlyBg〕/面片 T1V1/精细 C/深孔 D）；采集中改参＝全参重发 N10＋warn（D1）；参数双口（get 互斥快照/set 编队）；menuSelect ③/④ 经 EventBus UserDefined 广播派工作流。
- 生命周期归属：【公】app 存活件。
- 线程/并发：门面一切变异入口经 post() 任务队列编队（mutex+deque 容量 64 满丢新），logicTick 一拍排空；同步返回值口径——门禁检查调用方线程同步做，命令编队异步。
- 错误/降级：**故障 8 码对表（260831）**——0x0802 串口静默（**open 成功即武装**）/0x0804 温度乱跳（同路 G02 帧**绝对差值**>tempSpikeAbsC〔默认 10℃〕）/0x0806 手势环溢出/0x0807 串口写失败（盲发口径缩义）/0x0808 闲置（G03 帧对账预留，D6）；边沿锁＋恢复清锚防爆屏、只报不动手；EventBus FaultOccurred＋spdlog。
- 恢复路径（D8）：close＝N11 H0＋ModeController 黑板复位＋lastTemps\_ 清零＋0x0802 武装撤销；open 重同步 N12（黑板非 Idle/采集中再按 lastCaptureMode 重发 N10）。
- 测试：test_device_manager。
- 状态：✅（真机联调待做）
