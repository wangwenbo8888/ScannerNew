## 1. 目标功能（以 01/02 流程图 + 模块功能目录 §三 基准为准）

> 一句话：06 是**数据大管家**——运行中数据（帧/点云/设备状态）的容器、跨工作流交接的仓库（标定结果/点云）、每次开工要装配的配置与缓冲，外加文件导入导出，都归它管。

| 对象（归属） | 管什么（通俗） | 用在（步骤号） |
|---|---|---|
| **数据管理·仓库**（【公】app 存活件，开机即造、全程不销毁） | 跨工作流的「数据保险柜」，三个格子：①**标定结果仓库**——收 01-⑦ 标定成果统一落盘（相机内/外参、立体矫正、激光平面映射、两张温度表），是持久基准量；②**标定参数仓库**——01 产出的参数存这里，02-① 门禁「参数就绪」查它（开机自检「是否正确导入标定参数」也查它）；③**点云仓库**——02-⑧ 优化后点云留内存、不随 ⑩ 销毁：供 04 后处理内存调用、续扫作 existingMarkers 基准、人工请求才导出 | 01-②⑦；02-①②⑧ |
| **数据管理·会话件·01 版**（【私】② 构造、⑨ 逆序销毁） | 标定开工三件套：加载标定配置＋初始参数＋25 目标姿态表；创建帧环形缓冲实例（周期帧＝标记点帧＋N 路激光管帧＋温度） | 01-②④⑤ |
| **数据管理·会话件·02 版**（【私】② 构造、⑩ 逆序销毁） | 06 会话件只管装表＋ring——配置归 07 ScanConfig（ScanTypes.h 已有已消费；设计方案 §8-7，2026-08-21 人工确认口径）：创建帧环形缓冲实例（双目帧）；**出口查表**——装配期装载两张温度补偿表（激光表同时上载显存），缓冲出口按帧温逐帧查表、随帧附标定快照（「增强帧」——算子无查表动作） | 02-②④⑤ |
| **环形缓冲容器**（随会话件【私】，支撑约定） | 帧的传送带：08 只管往里放、流水线只管往外取，采图与计算互不等待；02 消费 lag 超限就跳最新丢中间，永远追新帧 | 01-④⑤；02-④⑤ |
| **文件 IO**（06） | 落盘/读盘的搬运工：点云 PLY/XYZ、网格 STL/OBJ、标志点、标定参数的导入导出（冷路径） | 01-⑦（落盘）；02-⑧（按需导出）；03/05（模型与标志点加载） |
| 流水线原语（IWorkflow / ParameterManager）（06） | 执行引擎零件：工作流统一接口＋参数键值仓，供 01/02/04 消费（Pipeline/Stage 已按 D3 裁删） | 01/02/04 工作流内部 |

> 支撑约定（目录 §三）：**温度表分工（01-D5）**——01 生成两张温度补偿表（0.2℃ 阶梯）随标定结果落盘，02 扫描侧在缓冲出口逐帧查表消费，生成与消费分离；**会话记账**——账本归 01/02 自身，06 只管存取（存档仅人工手动触发）。
> 数据语义分层（L1–L4）与判定规则见根目录 [`数据管理原则.md`](../../数据管理原则.md)：06 管的是 L3 逐帧产物容器与 L4 跨阶段产物仓库；L1/L2 暂存与累积器归 09 算子内部。

## 2. 现状对齐（核心能力一句话；本节随代码演进更新）

> 一句话：**仓库两层已立、会话件两件已建、出口查表已接线**——标定仓库 CalibrationRepository（JSON 单文件收五样＋readyForScan 门禁）与点云仓库 PointCloudBuffer（三用途接线）都已立；会话件 ScanSessionData（02）/CalibSessionData（01）已建；app 谓词已切 readyForScan；file_io 已收库（`Scanner::data::fileio`，点类型解 OSG）。**仓库已立：CalibrationRepository＋PointCloudBuffer 正名；会话件已建：两件；出口查表已接线 ScanSessionData**。剩接入期工作：08 采集回调接 pushFrame、激光网格数据生产链（§3）。

库 `mod_fileio`（STATIC，`modules/06_fileio/`，链 base/spdlog/OpenCV/nlohmann_json）：

| 文件/类 | 现状核心能力 |
|---|---|
| `RingBuffer.h`（`Scanner::data`） | 线程安全环形缓冲模板：溢出三策略（丢最旧/丢最新/阻塞），pop 带超时 |
| `FrameBuffer`（:IFrameSink） | 帧中转站：DropOldest 保最新帧，`popFrame(100ms)` 供工作流取帧。app 的 AppContext 持有一个 60 槽实例注入各处（显示链路用）；ScannerWindow 另自建一个显示用实例 |
| `PointCloudBuffer`（:IPointCloudSink） | **点云仓库**（正名；app 存活件、不随 ⑩ 销毁）：读写锁＋版本号；marker 通道（MarkerRecord 含 globalId，独立锁独立版本）。**三用途已接线**——04 内存调用（快照读）、续扫 existingMarkers 基准（02 assemble 期 snapshotMarkers 注入）、人工导出（exportCloud/exportMarkers，MainWindow 导出菜单走仓库） |
| `CalibrationRepository.{h,cpp}` | **标定结果仓库**（app 存活件）：JSON 单文件（＝07 serializeCalib 载荷＋外层 meta{version,createdAt,calibId,imageSize}）；`write` 落盘成功才提交内存（临时文件＋原子改名）；typed getters（stereo()/stereoTempTable()/planeMapTiers() 等）；`readyForScan` 缺样清单门禁（02-①/开机自检查它）——01 RepoWriter 直写、app 开机 best-effort load |

| `CalibSessionData.{h,cpp}` | **01 会话件**：会话档 JSON 三键加载（initialParams 原文透传/targets 每条 16 数/boardPoints，逐元素类型校验）＋Backpressure 姿态环（SlotRing\<CycleUnit\> 8 槽，07 PosturePipeline attachRing 注入） |

| `DeviceStateCache`（:IDeviceStateSink） | 设备状态记账：mutex 保护，温度/fps/丢帧便捷查询（08 HardwareMonitor 写、UI 读） |
| `IFrameSink.h` / `IPointCloudSink.h` / `IDeviceStateSink.h` | 依赖倒置插座：HAL/算子产出推给容器，容器不认识具体设备 |
| `SlotRing.h`（纯头文件） | 原子槽位环（单写多读，槽位 shared_ptr 原子换入）：Overwrite（扫描·满则覆盖最旧永不阻塞）/ Backpressure（姿态·满则阻塞等 done() 腾位）——**07 五流水线的实际输入容器**（Posture/ScanPipeline 经 attachRing 注入指针；环实例现随会话件持有） |
| `CycleUnit.h` / `EnhancedFrame.h` / `TempTableTypes.h`（纯头文件） | 07 消费的数据单元三件：CycleUnit 采集周期单元（标记点帧＋N 路激光管帧「乘客」＋温度，A 姿态链消费）；EnhancedFrame 增强帧（双目灰度＋帧温＋CalibSnapshot 标定快照，C 扫描链消费）；TempTableTypes 两张温度表 06 侧持档类型（立体侧持 Matx 数据；激光侧仅档温索引，GpuMat 表归 07/09 持有） |

| `file_io.{h,cpp}`（`Scanner::data::fileio`） | 点云 PLY（读 ASCII＋二进制/写 ASCII）、XYZ、PCD，网格 STL（自动识别）、OBJ，标志点 JSON 的导入导出——**已收编入 mod_fileio**（点类型 `cv::Point3f` 解 OSG；MainWindow/OSGWidget/PostProcessWorkflow 调用面已适配）；PCD import 既有缺陷钉测不修（data_type 初值致头循环早退，登记后续修） |
