# 模块7 · 会话管理

> 返回索引：[`模块功能目录.md`](../../模块功能目录.md)

## 职责
扫描启/停/暂停/恢复, 覆盖率统计, 断电续扫, 会话元数据。

## 已实现功能（以代码为准）

> 实现位于 `framework/service`（`StateMachine`、`SessionService`），由 `app/AppContext` 实例化、`modules/02_scanning` 调用；`modules/07_session` 目录为占位。

### 扫描状态机 — `Scanner::service::StateMachine`
- 事件驱动状态转换 `transition(EventType)`，含合法转换校验 `isValidTransition`
- 当前状态查询 `getCurrentState` / `getStateName`、操作权限判定 `canOperate`
- 状态变更回调 `onStateChange`，经 `EventBus` 通知

### 会话生命周期 — `Scanner::service::SessionService`
- 启/停/暂停/恢复：`startSession` / `stopSession` / `pauseSession` / `resumeSession`
- 状态查询：`isActive` / `isPaused`
- 帧计数：`onFrameProcessed` / `onFrameFused`
- 会话元数据 `SessionMetadata`：sessionId、projectName、起止时间、总帧数、融合帧数、覆盖率

### 覆盖率 / 断电续扫
- 覆盖率写入接口 `setCoverage(percent)`
- 断电续扫存盘 `saveCheckpoint(path)`：将会话元数据写为 JSON 文件
