### 7.2 会话生命周期
```cpp
struct ScanSession {
    std::string sessionId;         // UUID
    std::string startTime;         // ISO8601
    std::string projectId;
    ScanConfig config;             // 采集参数
    ScanState state;               // 当前状态
    ScanStats stats;               // 统计
    std::string calibrationPath;   // 关联标定
    std::vector<FrameResult> frames; // 帧结果
};
```

### 7.3 覆盖率统计
- 实时计算已扫描区域占总体积的比例
- 基于体素哈希: 已填充体素数 / 预估总体素数
- 可视化: 已扫描区域绿色, 未扫描区域灰色

### 7.4 断电续扫
- 会话状态定期持久化 (每N帧)
- 启动时检测未完成会话 → 提示恢复
- 恢复: 加载已采集帧 + 继续采集

### 7.5 故障处理 (主动响应模型)
- 相机断连 → **主动响应**: 暂停扫描 + 告警 → 上报 FaultHandler
- MCU通信失败 → **主动响应**: 暂停扫描 + 告警 → 上报 FaultHandler（停激光由模块8 硬件级响应）
- GPU OOM → **主动响应**: 降级处理 → 上报 FaultHandler
- ※ 模块7 负责会话级响应(暂停/停止扫描); 模块8 负责硬件级响应(停激光/标记设备离线); FaultHandler 聚合后转「故障」态 + 通知 UI
