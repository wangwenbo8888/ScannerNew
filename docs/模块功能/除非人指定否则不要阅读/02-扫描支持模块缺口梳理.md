# 02-扫描流程 · 支持模块缺口梳理

> 状态：**缺口清单（2026-08-15）**——按扫描主流程逐步走查（同标定版套路）；S0~S6 = 启动→流式帧循环→配准→融合→GBA 收尾→落盘
> 盘点基准（已核实）：06 FrameBuffer/PointCloudBuffer（仅增量）、08 HardwareMonitor（1s 轮询骨架）、base EventType（无 GBA 事件）、09 算子接口含 SetTempTable/seed 注释、laser_match_scan 已带 LoadTempTable JSON 便捷重载
