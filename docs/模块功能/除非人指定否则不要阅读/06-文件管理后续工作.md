## 三、E8 ArtifactStore 设计要点

```
职责: 跨阶段产物持久化（会话产物目录树 + 索引 + 版本）
目录约定:
  artifacts/
  ├─ scan_<sessionId>/     {pointcloud.ply, obs_frames.bin, poses.json, report.md}
  ├─ calib_<sessionId>/    {calibration.yml(温度表内嵌), poseData/, report.md}
  └─ post_<sessionId>/     {mesh.stl, metrics.json}
接口: saveArtifact(kind, name, writer) / loadArtifact / listSessions / prune
分期: 一期 = 目录约定 + saveMarkerCloud + 扫描会话落盘（02 S6-4 近期项）
      二期 = obs/位姿 bin 格式 + 断电续作全链（01 W8 / 02 会话恢复）
```
