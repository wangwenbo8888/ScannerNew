## 2. PostProcessWorkflow（D1，五阶段）

```pseudo
CLASS PostProcessWorkflow IMPLEMENTS IWorkflow:
    PHASE: Loading → Normals → Meshing → Refining → Exporting → Done|Error|Cancelled
    PRIVATE stages_ : 数组[5] of StageFn    // 独立 stage 抽象（04 文档既定）
    PRIVATE mesh_   : MeshData              // 中间产物驻留
    PRIVATE cancel_ : atomic<bool>

    FUNCTION postProcessLoop():
        // ===== Loading =====
        (ver, points, colors) = pointCloudBuffer_.getSnapshot()
        ☠ CHECK points 非空（沿用现有检查）
        IF config_.voxelDownsample > 0: points = voxelDownsample(points, 配置)
        // ===== Normals（法线重算——GBA 重融合后旧法线失效）=====
        normals = normalOp_.Execute(points)              ☠ CHECK；cancel_ 检查点
        // ===== Meshing（封装）=====
        mesh_ = wrapOp_.Execute(points, normals, config_.wrapParams)   ☠ CHECK
        // ===== Refining（补洞→光顺→边界，三连）=====
        mesh_ = fillOp_.Execute(mesh_, config_.holeParams)             // 洞面积<max 才补
        mesh_ = smoothOp_.Execute(mesh_, config_.smoothParams)         // HC 保特征
        mesh_ = boundaryOp_.Execute(mesh_, config_.boundaryParams)
        // ===== Exporting =====
        IF fmt∈{STL,Both}: file_io.exportSTL(path, mesh_)              // 已有函数
        IF fmt∈{PLY,Both}: file_io.exportPLY(...)
        ☠ CHECK 写盘成功
        result_ = {success, meshTriangles: mesh_.triangles.size, outputPath, 质量指标}
        state_ = Done

    FUNCTION cancel():                        // 批处理可中断（分钟级必需）
        cancel_ = true    // 各阶段 Execute 前后检查；算子内部不中断（单阶段秒级可接受）
```

## 3. 网格算子（09/mesh/，D2~D4）

### 3.1 MeshWrapCPU（贪心投影三角化，D2）

```pseudo
CLASS MeshWrapCPU:                            // 三元组契约：MeshWrapParams/Result/Operator
    FUNCTION Execute(points, normals, params) -> MeshWrapResult:
        // 1. 邻域结构：KDTree（Eigen 自实现 or OpenCV.ml FLANN——依赖合规）
        kdtree = build(points)
        avgDist = 平均最近邻距离
        radius = params.wrapRadius × avgDist
        // 2. 贪心生长：
        frontier = 队列；triangles = {}
        seedEdge = 最长相容边（法线近共线的一对近邻点）
        frontier.push(seedEdge)
        WHILE frontier 非空 AND 未达上限:
            (i, j) = frontier.pop()
            FOR candidate k IN kdtree.radiusSearch(i|j 中点, radius):
                IF triangle(i,j,k) 满足 Delaunay 空圆性质(近似) AND 法线夹角<阈值
                   AND 边(i,k)/(j,k) 未被两三角形共用（流形约束）:
                    triangles.push(i,j,k)
                    frontier.push 新边；break
        // 3. 孤立点剔除（无任何三角形引用）
        RETURN {mesh, 洞计数(初步), 边界边集合(留边界算子复用)}
```

### 3.2 MeshFillHolesCPU（D3）

```pseudo
FUNCTION Execute(mesh, params) -> MeshResult:
    holes = 提取边界环（边界边→环遍历，只处理 |环边数| ≤ maxRingSize 的洞）
    FOR each hole IN holes:
        IF holeArea(hole) > params.maxHoleArea: CONTINUE        // 大洞=真实边界开口，不补
        IF 非 平面性良好（各点到拟合平面距离 < σ）: CONTINUE     // 只补近平面孔
        triangles += 平面扇形/重心三角化填充(hole)
        新增顶点(重心) append 到 mesh.vertices
    RETURN mesh
```

### 3.3 MeshSmoothCPU（HC，D4）

```pseudo
FUNCTION Execute(mesh, params) -> MeshResult:
    // HC = Laplacian 位移 + 反向校正（保特征，文档钦定）
    q = vertices 副本
    FOR iter IN 1..params.iterations:
        FOR each v: delta[v] = avg(neighbors(v)) - v           // Laplacian
        p  = q + alpha × delta                                  // 平滑位移
        b[v] = p - (q + beta × (avg(neighbor_q) - q))           // 反向校正项
        q = p - b × 距离加权
    RETURN {vertices: q, normals: 重算}
```

### 3.4 MeshBoundaryCPU（D3）

```pseudo
FUNCTION Execute(mesh, params) -> MeshResult:
    rings = 提取边界环（复用 3.2 的环提取）
    FOR each ring:
        平滑：环顶点 Laplacian(仅环内邻接，迭代 params.iterations)
        重采样：长边细分/短边合并（目标边长=平均边长 ±50%）
    RETURN mesh
```
