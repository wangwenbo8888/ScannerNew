## 四、验收标准（产品里程碑——对标 v2.2 目标设计）

> 里程碑按**产品能力递进**组织：每个 M 都是用户视角可感知的能力，而非代码模块完成度。

| 里程碑 | 产品能力（用户视角） | 对应工作 |
|---|---|---|
| M1（W1+W2） | 用户做一次标定，参数可靠落盘、温度表不丢，无格式/实现混乱隐患 | W1+W2 |
| M2（W4 最小版） | 设备引导用户摆姿态，自动凑齐 25 个有效姿态（无需人工挑选） | W0+W4+W6 |
| M3（W5+W3） | 一次标定产出扫描所需**全部**参数（内外参/矫正/Q/激光平面/两张温度表），单次存储，**合格/不合格有判定** | W5+W3+W7 |
| M4（07 汇合） | 标定过程不丢帧、不掉姿态，实时姿态反馈流畅（吞吐≥36 周期/秒） | W4-7 + 07 Phase 3 |
| M5（产品级） | 断电可续作标定（免重采已集姿态）；标定报告（RMS/有效姿态数/温度曲线/表版本）可供出厂检验 | W8 + W7-3 |
