## 三、CalibrationWorkflow 重写（两阶段状态机）

### 3.1 类骨架（保持 IWorkflow 契约不变，外部无感知）

```cpp
class CalibrationWorkflow : public IWorkflow {
    // IWorkflow 接口全保留（start/pause/resume/stop/...）
    // 阶段 0 参数注入（替代现有棋盘格三参数）
    void setWarmupSeconds(int s);                  // 预热（默认 180s）
    void setPoseTargetsPath(const std::string&);   // 25 目标姿态表 JSON
    void setLaserTubeCount(int n);                 // N 激光管（配置化，真机确认后填）
private:
    enum class Phase { Init, Warmup, PostureCollect, Computing, Done, Error };
    std::atomic<Phase> phase_;
    std::unique_ptr<PostureCollector> collector_;   // 流水线 1
    // 流水线 2 内部函数式组织（见 §五）
    Result runCameraCalibChain();                   // Stage3: 3-1→3-2→3-3→3-4→3-5 + 5-1/5-2
    Result runLaserCalibChain();                    // Stage4: 4-1~4-13 + 5-3（PJC）
};
```

### 3.2 主循环（单线程顺序，替代现有 calibrationLoop 六步）

```
phase Init        → 读初始参数/姿态表/温度基线（CalibStore + 姿态表 JSON）
phase Warmup      → 预热倒计时（设备控制经 ctx_->mcu()：标定进入 N16 B1 + 加热；每秒读 4 路温度记曲线）
phase PostureCollect → PostureCollector::run()（见 §四；期间 progress 上报"姿态 x/25 + 实时命中反馈"）
phase Computing   → runCameraCalibChain() 与 runLaserCalibChain()（4-1~4-4 提前线程并行）
phase Done        → CalibQualityGate 判定 → 写 CalibStore + save → 完成回调
任一 phase 失败   → Error + 结果带 message（现有 CalibrationResult 扩展 qualityFlag 字段）
```

现有六步棋盘格路线**整体删除**（findChessboardCorners/角点路径退役，D1=a 的直接后果）。

## 四、PostureCollector（流水线 1 核心，新建）

### 4.1 职责与接口

```cpp
class PostureCollector {
public:
    struct Config {
        int targetCount = 25;         // 目标姿态数
        int laserTubeCount = 4;       // N（配置化）
        int confirmCycles = 2;        // 多帧确认：连续 2 周期同姿态
        double tempSampleIntervalMs = 100;
    };
    // 同步运行至集齐或 abort；hitCallback 实时上报（UI 姿态引导）
    Result run(std::function<void(const PostureProgress&)> progress,
               std::atomic<bool>& abort);
    std::vector<CollectedPose> takeCollected();  // 交付：25 姿态×(标记点帧+N激光管帧+温度)
};
```

### 4.2 内部流程（对应 v2.2 阶段 1+2，算子衔接严格按流水线文档第二节表）

```
循环 {
  ① 取 Cycle：从 ctx_->frameBuffer() 弹出采集周期单元（标记点帧+N激光管帧+温度）
     —— 依赖 W0-4 触发时序；FrameBuffer 泛型化或新增 CycleBuffer（06 域，见 §八-A）
  ② GPU 前端（MarkerChain::frontend）:
     mask_extract(2-1) → frame_filter(2-1b, 激光线帧销毁) → ccl(2-2)
     —— 三个 09/core/vision 算子；GpuMat 全程驻留，仅 components 下载
  ③ CPU 标记点链（MarkerChain::compute）:
     image_split(2-3) → zernike_edge(2-4) → image_merge(2-5) → undistort_cpu(2-6)
     → ellipse_fit(2-7) → marker_match(2-8) → epipolar_intersect(2-9)
     → edge_match(2-10) → point_reconstruct(2-11)
     —— 九个 09/core/marker 算子顺序 Execute；算子对象成员级复用（构造一次）
  ④ 配准+姿态: frame_fuse(2-12) → pose_estimate(2-13)
     —— poseTargets 来自 CalibStore::loadPoseTargets
  ⑤ 命中处理（多帧确认状态机，编排层逻辑非算子）:
     命中姿态 X 且上一周期也命中 X 且中间 N 激光管帧时间戳连续
       → CAS: collected_[X].compare_exchange(false→true)（防重复）
       → 缓存该完整周期（标记点帧+N 管帧+温度）到 pendingPoses_
     计数 == 25 → return
}
```

**关键实现点**：
- 2-6 `undistort_cpu` 的初始参数**只从 CalibStore::InitialParams 取**（单一来源，2-6⇄3-1 一致性约束的实现手段）
- `PrevFrameState` 此阶段不需要（2-12 frame_fuse 是"当前帧 vs 全局标记点集"配准，非光流链式）——全局标记点集初始为空，首帧建立
- 姿态合格帧的 2-7 椭圆中心**旁路保存**（`ellipseCentersByPose_`）——Stage3 的 3-1 输入（流水线文档 2-7→3-1 标注）

## 五、流水线 2：两条标定链（函数式组织，不建新类层级）

### 5.1 runCameraCalibChain()（Stage3，7 算子）

```
输入: pendingPoses_ 的椭圆中心集（矫正坐标系）+ CalibStore::InitialParams
3-1 inverse_distort    ×25 姿态 ×左右   （矫正中心→原始畸变坐标；RoundTripVerify 自验）
3-2 intrinsic_calib    多帧原始畸变中心 + 标定板3D点（按帧温度热膨胀补偿）
    ├→ 5-1 intrinsic_compensate          （内参温补表）
3-3 extrinsic_calib    ←3-2 内参
    ├→ 5-2 extrinsic_compensate          （外参温补表）
3-4 stereo_rectify     ←3-2/3-3
    └→ 3-5 stereo_rectify_temp_table     ★温度表1 → CalibStore
```

### 5.2 runLaserCalibChain()（Stage4，PJC 路线 12 算子）

```
输入: pendingPoses_ 的激光管帧 ×25 姿态 + Stage3 产物（内参/Q）
[提前线程] 4-1 mask_extract → 4-2 ccl → 4-3 laser_label → 4-4 steger(ByLabel)
    —— 与 Stage3 并行；产出暂存 d_centerPoints/d_line_ids（GpuMat 池）
[串行段]   4-5 undistort_cuda(标定后内参) → 4-6 epipolar_interp(lineIdCheck=true)
           → 4-7 laser_match → 4-8 laser_reconstruct(Q←3-4)
[编排聚合]  d_points3d download → vector<PosePointSet>（按姿态分组；编排动作非算子）
           → projector_joint_calib（CPU LM；f/主点←stereoK 派生；initialT←机械公差）
           → 4-12 plane_map(virtualK=f+主点, R=I, T=projectorT)
           → 4-13 plane_map_temp_table  ★温度表2 → CalibStore
           → 5-3 laser_extrinsic_compensate
```

**CUDA 资源**：单 `cv::cuda::Stream` 成员（现有算子契约 `Stream&` 流亲和）；GpuMat 显存池按最大姿态帧预算预分配（Warmup 期间完成，兼作 GPU 预热）。
