## 一、现状（已核）

CameraControl（大恒双目：硬触发/ROI/温度/异步配对交付，部分空桩）+ MCUDriver（N10/N11/N12/N13 + 接收线程，K 报文仅匿名事件）+ HardwareMonitor（1s 轮询骨架）+ **§4 KeyManager 子模块（立项，零代码）**。

## 三、实施顺序与验收

```
无依赖先行: F6 / F-K1 / F4(自检骨架,加密狗位留 Mock)
W0 冻结后:  F1 → F2 → F3
H1 后:      F-K3 / F7
UI 批次:    F-K5
```

| 里程碑 | 验收 |
|---|---|
| FM1（F6/F-K1/F-K2） | 按键报文→语义动作全链可测（Mock 门禁）；相机参数可调 |
| FM2（F1~F3） | 真机标定 Warmup/采集序列可控；4 路温度可读（W0 后） |
| FM3（F4/F5） | 上电自检报告 + 许可证门禁生效（S1 实质化） |
| FM4（F-K3/F7） | 按键启停扫描真机可用；断线自动终止会话 |
