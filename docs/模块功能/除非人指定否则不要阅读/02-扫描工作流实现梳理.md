### 3.2 单帧流程（对齐客户端扫描流水线.md §一 总图）

```
输入: grayL, grayR（双副本：Host Mat 已有，Device 首次上传）
①  GPU 前端: mask_separation → ccl(标记点掩膜)
      ├─ d_markingPointMask → ccl → components   （CPU 链启动条件）
      └─ d_laserMask                          （激光链输入，A 模式为空）
②  标记点 CPU 链（与 ③ 并行，单线程版顺序执行）:
      image_split → zernike → image_merge → undistort_cpu(★查温度表1)
      → ellipse_fit → marker_match → epipolar_intersect → edge_match
      → point_reconstruct
③  激光链 CUDA（B 模式，全程 Device 驻留）:
      steger(Flat) → undistort_cuda(★查温度表1) → epipolar_interp(false)
      → laser_match_scan(★查温度表2, SetTempTable 注入) → laser_reconstruct(Q)
④  配准: optical_flow_fuse（读 PrevFrameState 快照；失败→frame_fuse 兜底）
      → R/T + globalIds；首帧（挂 existingMarkers 时以已有点为靶标）
⑤  融合:
      marker_cloud_fuse_cpu（挂 existingMarkers 时先 seed()）
      laser_cloud_fuse_cuda → laser_cloud_normal_cuda（B 模式）
⑥  输出: FrameResult{frameId, R, T, marker3D, laser3D(d_points3d 留 Device), temp}
      + 旁路: ScanObsCollector.onFrame(R_init, t_init, markerObs)（GBA 输入）
```

### 3.3 关键接线（现状缺口的对应解法）

| 现状缺口（02 文档 §2） | 本设计解法 |
|---|---|
| Stage1 手搓掩码 | ① `mask_separation_cuda`（A 模式无激光工况走 §八-B 备注） |
| 标记链缺 6 算子 | ② 补 image_split/image_merge/undistort_cpu/epipolar_intersect/edge_match/optical_flow_fuse——**与标定 MarkerChain 是同族算子、不同参数语义**（扫描查温补表，标定用初始参数）——编排壳独立建，算子复用 |
| 激光链空壳 | ③ 五算子接通，line_id Flat 语义 |
| 无配准（R/T 恒等） | ④ optical_flow_fuse 主 + frame_fuse 兜底 |
| 无温度查表 | ★三处查表：每帧从 HardwareMonitor 缓存取当前温度 → lookup(tempC) |
| 融合无标记点分支 | ⑤ marker_cloud_fuse_cpu（现 FuseStage 只调 laser 版 CPU） |

## 四、RegistrationState（配准状态与快照）

```cpp
class RegistrationState {
    // PrevFrameState 原子快照（调度 260629 §10；单线程版退化为普通成员，接口不变备调度）
    std::atomic<std::shared_ptr<calib::PrevFrameState>> prev_;
    calib::AtomicFrameState snapshot();          // load
    void publish(const calib::PrevFrameState&);  // store（配准结束时）
    // 全局标记点集（frame_fuse 兜底与 existingMarkers 的靶标）
    std::vector<calib::MarkerCloudPoint> globalMarkers_;   // seed() 来源
    // globalId 三阶段连接键（配准→融合→GBA）维护
};
```

globalId 语义（客户端扫描流水线.md §5.2）：首帧 `globalId=i`；挂 existingMarkers 时匹配点 `globalId=bestIdx`；后续帧光流链式传播。兜底 frame_fuse 是否产出 globalId 是**开放问题**（文档未明确）——本实现：兜底帧 globalId 置 -1，GBA 侧跳过其软先验（保守，不破坏连接键）。

## 六、GlobalOptimStage（收尾，新建）

```
输入: ScanObsCollector 累积的逐帧 {R_init, t_init, markerObs[]}（★非 fusedPoints_）
     + existingMarkers（挂载时作软先验高权重：σ 极小残差 ‖X−X_existing‖²/σ²）

```
