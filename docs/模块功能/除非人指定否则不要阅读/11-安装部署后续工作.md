## 三、实施顺序与验收

```
I1（随时可做，建议随 E 批）──► I2（全域稳定后）──► I3 ──► I4
                                                 I5（三主域 M3 后，可与 I3 并行）
```

| 里程碑 | 验收 |
|---|---|
| IM1（I1） | 全新机器克隆仓库 → 一条命令配置+构建通过（零手工改路径） |

## 四、风险

| 风险 | 缓解 |
|---|---|
| CUDA runtime 打包体积/许可 | 采用 runtime installer 链式安装（NVIDIA 许可允许）；或要求产线预装 |
| 依赖清单漂移（Qt/OSG/OpenCV 版本升级） | I2 打包脚本从 CMake 变量取版本（I1 的直接受益） |
| 向导复杂度膨胀 | 四步硬边界（连设备/语言/许可/标定引导），其余设置进主界面 |
