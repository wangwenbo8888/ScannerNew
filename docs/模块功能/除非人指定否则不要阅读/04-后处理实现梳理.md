## 三、PostProcessWorkflow 重写

```cpp
class PostProcessWorkflow : public IWorkflow {
    // 五阶段 + 取消语义
    Phase: Loading → Normals → Meshing → Refining → Exporting → Done | Error | Cancelled
    // 07 WorkflowManager 驱动；不过设备门禁（S6 免疫）但走生命周期管理
    // 进度：每阶段权重（法线10% 封装40% 补洞15% 光顺20% 边界10% 导出5%）
    // 取消：cancel() 置原子位，各阶段边界检查；已完成阶段产物保留供导出
};
```

要点：
- **Stage 抽象拆分**（04 文档 §3 既定）：七阶段从单函数拆为独立 stage——每阶段一个成员函数 + 独立可测
- 输入快照版本锁定：start 时取 version，跑批期间不受新发布影响（GBA 只在扫描结束时发布一次，天然无竞争，防御性锁定）
- 中间产物（MeshData）内存驻留；超大点云（>千万点）分块策略为开放点（§六）

## 四、网格算子族选型（09 新建，4 个算子）

| 算子 | 选型建议 | 备选 | 依据 |
|---|---|---|---|
| `MeshWrapCPU`（封装） | **贪心投影三角化**（Greedy Projection，OpenCV 无 / PCL 有 / 自实现 ~400 行） | Poisson（需法线+八叉树，重但孔少） | 文档标注"Poisson/贪心三角化"二选一；扫描仪点云密度均匀，贪心够用且快；Poisson 留二期 |
| `MeshFillHolesCPU`（补洞） | 边界环检测 + 平面补洞（小洞三角形填充，~300 行） | — | 自实现 |
| `MeshSmoothCPU`（光顺） | **HC 平滑**（文档明确"光顺(HC)"；保特征，~200 行） | Laplacian（简单但缩特征） | 文档钦定 HC |
| `MeshBoundaryCPU`（边界优化） | 边界环提取+平滑+重采样（~250 行） | — | 自实现 |

> 依赖纪律（算子规范 §依赖限制）：仅 OpenCV/Eigen/CUDA——**不引入 PCL/OpenMesh**（与调度 260629 §14.5 一致）；贪心三角化若 OpenCV 无现成则自实现。
> 全 CPU 实现（网格非像素级并行，CUDA 收益低；如后期实测慢再议 mesh_wrap CUDA 化）。
