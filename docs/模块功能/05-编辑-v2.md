### 1.1 模块背景〔AI 预填，迭代时刷新〕

- **模块定位**：扫描间隙的点云修整台——停采集后的就绪态里圈选杂点删除（可撤销），删干净再进全局优化（GBA）〔此为设计意图；260927 生产口径 GBA 随关会话先行，编辑实际发生于 GBA 后的待机期——缺口见 D7〕
- **上下游依赖**：
  - 上游：02 扫描工作流（提供融合云＋逐帧观测两个账本；账本随会话存活——关会话即随 pipeline 销毁，见 D7）
  - 上游：03 OSGWidget（圈选交互与显示级软删载体）＋ app（门禁／工具条／物理化编排）
  - 下游：07/09 双账本（融合云移除＋观测剔除）→ 07-E 全局优化（求解排除已删观测）
- **关键约束**（源自 2026-09-05 设计定案 D1–D8）：
  - 编辑时机＝就绪态内、全局优化之前；编辑不终结扫描工作流（退出后可续采／再编辑／完成扫描）
  - 删除经双账本作用：融合累积器移除该批点＋逐帧观测累加器打剔除标记
  - 三栏正交选择：工具类型（套索／多段线）× 选择类型（贯穿／只取表面）× 对象类型（点云／标志点／两者）
  - 对象口径（2026-09-05 裁定）：激光点并入「点云」口径；三角面不可编辑
  - 只取表面层厚带宽统一 1mm（显示级与 SelectionService 同默认）
  - 线程模型：编辑交互 UI 单线程属主（域对象无锁）；会话内存态不持久化
  - 采集启停归设备 M 键（260927 口径）：M 停采仅设备级（会话仍活跃，此间门禁拒绝编辑）；点扫描模式键＝关闭会话（物化＋全局优化后台批）后回待机——生产编辑入口＝待机分支（见 D6/D7）
  - 「物理化」＝把显示级删除落地到真账本（融合云移除＋观测剔除）
  - 「pending」＝待物理化的删除下标集
  - 「alpha=0」＝顶点透明度置 0（屏幕上不可见——显示级软删的隐藏手段）
