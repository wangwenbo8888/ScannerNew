# 模块4 · 后处理

> 一句话：本模块是扫描收尾的离线批处理编排者——把 02 全局优化后的点云加工成 STL（3D 打印通用的三角网格文件）成品，供用户导出使用。
> 返回索引：[`模块功能目录.md`](../../模块功能目录.md)

## 1. 功能目标

范围：五阶段离线批处理＝**法线重算 → 封装(网格化) → 补洞 → 光顺(HC) → 边界优化，出 STL**。全局标记点优化(GBA)与重融合不在本模块（归 02 扫描工作流收尾执行），本模块消费其产出的修正后点云。

### 1.1 PostProcessWorkflow（后处理工作流，04-1）
- 做什么：离线批处理编排——读点云、跑五阶段、出 STL、报进度。
- 交互：消费 02 产出的 GBA 修正后点云（内存快照）；五阶段算子取自 09（法线已有、网格四族待建）；STL 落盘走 06 文件 IO。

## 2. 实现现状（以代码为准）

数据流一张图：

```
06 PointCloudBuffer（点云仓库·02 GBA 修正后点云留存的内存形态）
        │ getSnapshot（点云快照）
        ▼
04 PostProcessWorkflow.makeCloudData → MeshData(xyz)
        │ start()：装配 07 E（skipStages/outputPath 透传）＋ 起 postThread_ 批算
        ▼
07 PostProcessPipeline.run（五阶段：法线→封装→补洞→光顺→边界）
        │ 产物 MeshData → StlExportFn（04 侧适配器 exportStlViaFileIo）
        ▼
06 fileio::exportSTL → output.stl（法线数量匹配时随片透传）
```

### 2.1 `modules/04_postprocessing/PostProcessWorkflow.h/.cpp`（PostProcessWorkflow）
- 核心能力：IWorkflow 编排壳——生命周期（initialize/start/stop）＋进度回调透传＋产物记账（PostProcessResult：三角面数/耗时/输出路径）；五阶段编排已移交 07 PostProcessPipeline，本类只装配触发。
- 交互：06 PointCloudBuffer 快照入 → 07 PostProcessPipeline.run 出；STL 经 StlExportFn 适配器 `exportStlViaFileIo`（07 MeshData 的 float 顶点/法线/三角索引 → 06 fileio::MeshData）落盘；skipStages 位掩码（bit0 法线…bit4 边界）透传；onFinished(bool) 完成回报钩子由 app 注入。
- 线程/并发：postThread_ 独立阻塞批算线程（start 建、stop join）；stop＝CancelToken.cancel（阶段前/导出前检查点安全退出）＋ pipeline.stop ＋ join 线程；用户主动取消按 ok=true 报 onFinished（正常终止非故障），线程体每会话恰执行一次。
- 状态：◐（壳与 STL 真导出已实装；法线阶段已实接 09，网格四族算子 09 待建——07 内置桩 degraded（降级：部分完成非致命）「operator pending」占位）
