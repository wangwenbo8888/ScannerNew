## 2. 代码需要调整的

- **空壳无算子**：`postProcessLoop()` 七阶段全是 sleep 占位 + TODO，需真正编排调用算子（GBA / 融合 / 法线 / 网格四阶段）。
- **stages 未拆分**：7 阶段全挤在 `postProcessLoop()` 单函数里，无独立 stage 抽象，不利维护与排错。
- **CMake 归属错位**：`mod_postprocessing` 是 INTERFACE 空库且不含 PostProcessWorkflow 源码，源码实际由 app 编译；模块自建库与编译归属需厘清（要么入库要么明确文档化）。
- **依赖契约路径已迁移**：工作流 include 的 `IWorkflow.h`/`PointCloudBuffer.h` 已随 framework 退役迁至 `modules/06_fileio/`，include 路径需对齐新归属（治理见 `docs/模块功能/06-文件管理.md §2`）。
- **导出占位**：STL 导出 `meshTriangles=0`，需对接 FileService（模块6）。
