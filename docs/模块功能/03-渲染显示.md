## 职责
点云实时3D渲染 (CUDA-GL零拷贝), 标记点/激光点云viewer。

## 当前状态: ✅ display/已实现

## 子功能细化

### 3.1 激光点云渲染器 (CUDA-GL interop)
- **laser_cloud_renderer**: 直接读VRAM中`LaserCloudFuseDeviceContext.d_fusedXyz` + `d_fusedNormal`
- **point_expand_kernel**: CUDA展点kernel → GL VBO → glDraw
- **零拷贝**: 点云数据全程在GPU显存, 不回传CPU

### 3.2 标记点渲染器 (CPU展点 + VBO)
- **marker_cloud_renderer**: 读`vector<MarkerCloudPoint>` → OSG VBO展点四边形 → glDraw
- 用途: 显示配准标记点位置, 辅助定位

### 3.3 扫描查看器 (OSG场景图 + Shader)
- **scanner_viewer**: OSG窗口管理 + 场景图 + 着色器
- 功能: 旋转/平移/缩放/框选 + 实时预览扫描结果
- 坐标系: 世界坐标(标定板原点为参考)

### 3.4 UI集成
- **OsgWidget**: QWidget内嵌OSG图形窗口 (已实现)
- 与jeamui主窗口集成 (已实现)
- 标定预览图像显示 (QImage Format_Indexed8 + 256灰度表)

## 数据来源
```
扫描输出 → 点云融合 → LaserCloudFuseDeviceContext(VRAM) → laser_cloud_renderer → 屏幕
                    → vector<MarkerCloudPoint>(CPU)      → marker_cloud_renderer → 屏幕
```

## 依赖
- 模块9 (laser_cloud_fuse_cuda + laser_cloud_normal_cuda 产出的DeviceContext)
- OSG 3.6.5 + CUDA-GL interop
