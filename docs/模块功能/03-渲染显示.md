## 场景区分（由 MainWindow 编排，OSGWidget 无内部状态机）

`OSGWidget` 本身是通用 viewer，**无场景/模式枚举**。场景切换全部由 `MainWindow` 调用不同方法序列实现。`OSGWidget` 内真正生效的模式标志仅 2 个：`m_lassoMode`、`m_lassoDeleteMode`。

> ⚠️ **`m_viewLocked` 是死代码**：全工程从未置 `true`（仅在 `clearScene`/`loadPointCloud`/`loadMesh` 置 `false`，`paintGL:776` 判空但恒假）。标定模式的视图锁定实际由 MainWindow 用 `setCameraManipulator(nullptr)` + `setViewMatrix()` 绕过它实现。

## 已实现功能

### 1. OSG + Qt 渲染框架
- `QOpenGLWidget` 内嵌 `GraphicsWindowEmbedded`，单线程 `Viewer`
- `QTimer`(16ms ≈ 60fps) 驱动 `update()` 重绘
- 投影矩阵锁定（`m_userProjection`），防止 `frame()` 内部篡改
- `debugValidateProjection()` — 弹窗显示投影/视图矩阵校验（调试用）

### 2. 数据加载与渲染
- `loadPointCloud(points)` / `loadPointCloud(points, colors)` — 点云，VBO + DYNAMIC（单色 LeadScan 蓝 / 逐顶点 `Vec4ub` 着色）
- `loadPointCloudWithNormals(points, normals)` — 带法线动态点云（VBO + DYNAMIC）
- `loadFromPointCloudBuffer(PointCloudBuffer*)` — ADR7.8 只读快照接口
- `loadMesh(filepath)` — STL/OBJ 网格（`file_io::importMesh`，三角形展开 + GL_LIGHT1 双面光照 + 材质，仅 VBO）
- `loadMarkerPoints(markers)` — 标志点（点大小 5.0，VBO + DYNAMIC）
- `loadTestData(numPoints)` — 生成带 4 孔的测试工件点云（无 VBO）
- `clearScene()` — 清空场景、停止流式加载、清空高亮/撤销历史

### 3. PLY 流式加载
- `loadTestDataFromPLY` — 解析二进制 PLY，按 50000 点/批定时 `streamNextBatch`
- 信号 `streamProgress(loaded, total)` → MainWindow 更新树节点点数
- 加载过程自适应相机（包围盒对角线 → 透视 fov 45°）

### 4. 套索选择与编辑（2D 屏幕多段线）

> 🔜 **待迁移**：本节功能计划解耦至 [模块5 · 编辑](05-编辑.md)（便于独立管理）。目标规格见 `05-编辑.md`「待实现：从模块3移植套索选择与编辑」。**当前代码仍内联在 `OSGWidget`，迁移尚未开始** —— 以下为现状记录，供移植参照。

- `enterLassoMode` / `closeLasso` / `exitLassoMode` — 左键加点、右键/闭合点收尾
- 命中测试：`CullCallback` 捕获 MVP，`computeRenderingMVP`（行主序→列主序转置）投影到屏幕，射线法 `isPointInPolygon2D`
- `highlightSelectedPoints` — 圈内点高亮为蓝色，保留原色供恢复
- `deleteSelectedPoints` / `deletePointsInPolyline` — 删除（alpha=0 + GL_BLEND）
- `undoDelete` — 删除历史栈
- `enterLassoDeleteMode` — 套索删除模式（带确认对话框）
- 信号 `lassoCompleted()` — 套索闭合后通知外部

### 5. 相机控制
- `osgGA::TrackballManipulator`（禁止惯性 throw）— 旋转/平移/缩放
- `autoFitCamera` — LeadScan 风格定位到包围球（Y 偏移 + viewDirection）
- `home` / `setCameraManipulator`
- `adjustViewToMaxProjection` — PCA 求最大投影平面法向（**代码存在，已注释禁用**）

### 6. 叠加层
- `createAxesIndicator` — 左下角 XYZ 三轴指示器（锥头 + X/Y/Z 文本标签 + 原点球），独立正交相机 POST_RENDER
- `createCenterOverlay` / `setCenterOverlayVisible` — center.png 中心十字（**代码存在，构造时注释禁用**）

### 7. 鼠标交互事件分发
- 旋转/平移/缩放/双击事件转发到 `GraphicsWindowEmbedded` 事件队列
