## 1. 功能目标

（03 无定稿流程图，目标以目录 §2.4＋旧版职责段为基准）

### 1.1 OSGWidget（03-1）
- 做什么：3D 场景渲染与显示——点云/网格/标志点的可视化、相机控制（旋转/平移/缩放）、套索选择编辑、叠加层（坐标轴指示器/中心十字）。
- 交互：读 06 点云仓库快照（loadFromPointCloudBuffer 只读窄接口）与 06 fileio 网格导入（loadMesh）；07 流水线渲染推送口（ISceneFeed）由 03 侧实现——实时点云/姿态视图/冻结通知从这里进；05 编辑的套索能力由本画布承载。

## 2. 实现现状（以代码为准）

- 编译归属：`modules/03_rendering/CMakeLists.txt` 仅 INTERFACE 占位库 `mod_rendering`（保目标名无源码）；OSGWidget.{cpp,h} 由 app 直编入 scan_demo（`app/CMakeLists.txt:56-57`，include 路径 `:84`）。依赖 Qt（QOpenGLWidget）/OSG 3.6.5/Eigen（PCA）。
- 线程/并发：单 Qt UI 线程渲染——QTimer 16ms 驱动 paintGL 重绘；07 ISceneFeed 从流水线线程推送（pushPostureView 可能多 lane 并发），实现侧须线程安全。
- 场景编排归属（OSGWidget 无场景/模式枚举，仅 m_lassoMode/m_lassoDeleteMode 两标志；切换全由 MainWindow 方法序列编排）：

```
MainWindow（编排者）
  ├─ 标定模式：01-④ buildCalibScene 产 osg::Group → 相机锁定
  │     （setCameraManipulator(nullptr)+固定视图）＋ 分屏 2D 标定板＋左右/前后彩条
  ├─ 扫描/浏览态：loadPointCloud 融合点云 → 自由 TrackballManipulator＋悬浮条
  ├─ 文件导入：loadMesh（STL/OBJ）/ loadTestDataFromPLY
  └─ 旁路刷新通道：QTimer 500ms 轮询 06 PointCloudBuffer → 点数变化即
        loadFromPointCloudBuffer 刷新（独立于场景切换，有数据就刷）
隐式模式指示器：中心十字 overlay ON＝空闲/浏览态、OFF＝有数据/标定态
```

### 2.1 `modules/03_rendering/OSGWidget.h/.cpp`（OSGWidget，03-1）
- 核心能力（按功能组）：
  - 渲染框架：QOpenGLWidget 内嵌 GraphicsWindowEmbedded，单线程 Viewer；投影矩阵锁定（m_userProjection，防 frame() 内部篡改）；debugValidateProjection 调试弹窗。
  - 数据加载：loadPointCloud（单色 LeadScan 蓝/逐顶点色）、loadPointCloudWithNormals（VBO＋DYNAMIC 动态点云）、loadMesh（经 06 fileio::importMesh，三角展开＋双面光照＋材质，仅 VBO）、loadMarkerPoints（点大小 5.0）、loadFromPointCloudBuffer（ADR7.8 只读快照直读）、loadTestData（带 4 孔测试工件）、clearScene。
  - PLY 流式加载：二进制 PLY 解析按 50000 点/批定时 streamNextBatch；信号 streamProgress(loaded,total) 供 MainWindow 更新树节点点数；加载中 PCA 自适应相机（包围盒对角线→透视 fov 45°）。
  - 套索选择与编辑：enterLassoMode 左键加点/右键闭合；命中测试＝HitTestCullCallback 捕获 MVP＋computeRenderingMVP（行主序→列主序转置）投影到屏幕＋射线法 isPointInPolygon2D；highlightSelectedPoints 圈内高亮保原色；deleteSelectedPoints/deletePointsInPolyline（alpha=0＋GL_BLEND）；undoDelete 删除历史栈；enterLassoDeleteMode（带确认框）；信号 lassoCompleted。
  - 相机控制：TrackballManipulator（禁惯性 throw）；autoFitCamera（包围球定位，Y 偏移＋viewDirection）；home/setCameraManipulator；adjustViewToMaxProjection（PCA 最大投影平面法向——代码存在已注释禁用）。
  - 叠加层：createAxesIndicator（左下角 XYZ 三轴指示器——锥头＋文本标签＋原点球，独立正交相机 POST_RENDER）；createCenterOverlay（中心十字——代码存在，构造时注释禁用）。
- 交互：消费 06 PointCloudBuffer 快照（渲染线程并发只读，靠仓库读写锁保证）；06 fileio 网格导入；01 CalibDisplay 喂 osg::Group；07 经 ISceneFeed 推实时姿态/点云快照/冻结通知。
- 场景编排：见模块级编排图——本体无模式状态机。
- 现状限制：m_viewLocked 为死代码（全工程从未置 true，标定模式视图锁定实际由 MainWindow 用 setCameraManipulator(nullptr)＋setViewMatrix 绕过实现）；MainWindow 顶栏注释与代码不符（注释称 i==2..5 含切面扫描，实际条件不含 i==6；i==6 切面/i==7 重置两按钮未接线）。
- 状态：✅
