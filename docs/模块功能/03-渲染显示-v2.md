# 模块3 · 渲染显示

> 一句话：本模块是**3D 显示画布**——点云/网格/标志点/激光点的可视化、相机控制、套索选择编辑、叠加层（坐标轴/中心十字），扫描长什么样全看它。
> 返回索引：[`模块功能目录.md`](../../模块功能目录.md)

## 1. 功能目标

### 1.1 OSGWidget（03-1）
- 做什么：3D 场景渲染与显示——点云/网格/标志点的可视化（网格含 04 后处理产出的三角化网格）、标定姿态引导显示（目标扫描仪姿态＋实际扫描仪姿态）、相机控制（旋转/平移/缩放）、套索选择编辑、叠加层（坐标轴指示器/中心十字）。
- 交互：读 06 点云仓库快照（loadCloudSnapshot 只读值传窄接口）与 06 fileio 网格导入（loadMesh）；07 流水线渲染推送口（ISceneFeed）推来的实时点云/姿态视图/冻结通知/后处理网格从这里进；05 编辑的套索能力由本画布承载。

## 2. 实现现状（以代码为准）

- 编译归属：`modules/03_rendering/CMakeLists.txt` INTERFACE 库 `mod_rendering`（承载 RenderSanity 纯函数件＋OpenCV 链接＋单测）；OSGWidget.{cpp,h} 由 app 直编入 scan_demo（`app/CMakeLists.txt:58-60、78`，include 路径 `:87`）。依赖 Qt（QOpenGLWidget）/OSG 3.6.5/OpenCV core（cv::Point3f 值签名）/Eigen（PCA）。
- 线程/并发：单 Qt UI 线程渲染——QTimer 33ms（30fps）驱动 paintGL 重绘；07 流水线线程的渲染推送经 app SceneFeedAdapter 中转（调用线程立即值拷贝＋Qt queued signal 切 UI 线程，严禁跨线程持有融合器内部 vector 引用）；冻结通知＝原子标志。
- 场景编排归属（OSGWidget 无场景/模式枚举，仅 m_lassoMode/m_lassoDeleteMode 两标志；切换全由 MainWindow 方法序列编排）：

```
MainWindow（编排者）
  ├─ 标定模式：01-④ buildCalibScene 产 osg::Group → 相机锁定
  │     （setCameraManipulator(nullptr)+固定视图）＋ 分屏 2D 标定板＋左右/前后彩条
  │     姿态显示现状：扫描仪 STL 姿态模型 ×1（硬编码演示变换——未接 01 的
  │     25 目标姿态表与实际姿态源）；偏差 HUD（createHud 六轴偏差分级条）
  │     函数存在未挂场景，数值为演示硬编码
  ├─ 扫描/浏览态：loadPointCloud 融合点云 → 自由 TrackballManipulator＋悬浮条
  ├─ 文件导入：loadMesh（STL/OBJ——04 后处理 STL 落盘产物亦经此口）/ loadTestDataFromPLY
  ├─ 实时显示链：SceneFeedAdapter queued 信号 → loadMarkerPoints/loadLaserPoints
  │     （标志点/激光专用几何，原地更新不清场）
  └─ 旁路刷新通道：QTimer 500ms 轮询 06 PointCloudBuffer → 点数变化即
        pcb->getSnapshot → loadCloudSnapshot 值传刷新（独立于场景切换，有数据就刷）
隐式模式指示器：中心十字 overlay ON＝空闲/浏览态、OFF＝有数据/标定态
```

- 实时显示链数据流（标志点/激光）：

```
07 FuseConsumer（消费线程独占）
   │ CloudViewHandle（hostMarker 指针＋hostLaser host 块＋laserCount）
   ▼
app SceneFeedAdapter（ISceneFeed 首个实现）
   · 调用线程立即值拷贝＋NaN/Inf 滤除 → queued signals
   ├─ markerCloudUpdated ─▶ MainWindow ─▶ loadMarkerPoints（同心圆点精灵 24px）
   ├─ laserCloudUpdated ─▶ MainWindow ─▶ loadLaserPoints（浅蓝 2px 小点）
   ├─ freezeChanged ── D 全局优化批处理期：adapter ingest 丢弃，画面保持末帧
   └─ latestMarkers() ──扫描合账──▶ 06 PointCloudBuffer 落库（A 模式标志点云出口）
                                  └─▶ cloudTimer 500ms ─▶ loadCloudSnapshot
```

- 后处理网格通路（文件媒介，非实时链）：

```
07-E PostProcessPipeline（MeshData：xyz/normals/triangles；五阶段＝法线/封装/补洞/光顺/边界）
   → 04 StlExportFn → 06 file_io::exportSTL 落盘（Config.outputPath，默认 output.stl）
   → 用户经「文件管理→导入网格」loadMesh 进渲染
   （MeshData→渲染内存直连未建；封装/补洞/光顺/边界四阶段为桩——09 网格算子
     落地前 triangles 不产出）
```

### 2.1 `modules/03_rendering/OSGWidget.h/.cpp`（OSGWidget，03-1）
- 核心能力（按功能组）：
  - 渲染框架：QOpenGLWidget 内嵌 GraphicsWindowEmbedded，单线程 Viewer；投影矩阵锁定（m_userProjection，防 frame() 内部篡改）；debugValidateProjection 调试弹窗。
  - 数据加载：loadPointCloud（单色 LeadScan 蓝/逐顶点色）、loadPointCloudWithNormals（VBO＋DYNAMIC 动态点云）、loadMesh（经 06 fileio::importMesh，三角展开＋双面光照＋材质，仅 VBO）、loadTestData（带 4 孔测试工件）、loadCloudSnapshot（快照值传入口——防御闸＋先建后换原子替换，见 2.2）、clearScene。
  - 标志点/激光显示链：loadMarkerPoints（专用几何原地更新；同心圆贴图 64×64 外黑环＋内白圆，POINTS＋PointSprite 点精灵 24px，MIN_FILTER 显式 LINEAR；clearScene 摘除后按 getNumParents 判定重建重挂）；loadLaserPoints（专用几何原地更新，浅蓝 0.529/0.808/0.980，2px）。
  - PLY 流式加载：二进制 PLY 解析按 50000 点/批定时 streamNextBatch；信号 streamProgress(loaded,total) 供 MainWindow 更新树节点点数；加载中 PCA 自适应相机（包围盒对角线→透视 fov 45°）。
  - 套索选择与编辑：enterLassoMode 左键加点/右键闭合；命中测试＝HitTestCullCallback 捕获 MVP＋computeRenderingMVP（行主序→列主序转置）投影到屏幕＋射线法 isPointInPolygon2D；highlightSelectedPoints 圈内高亮保原色；deleteSelectedPoints/deletePointsInPolyline（alpha=0＋GL_BLEND）；undoDelete 删除历史栈；enterLassoDeleteMode（带确认框）；信号 lassoCompleted。
  - 相机控制与视角跟随：TrackballManipulator（禁惯性 throw）；autoFitCamera（包围球定位，Y 偏移＋viewDirection，导入路径用）；home/setCameraManipulator；setLeftCameraView（左相机视角——eye 沿 -z 看向标志点包围球中心、up=-y、取景距离 1.2r、fov 30°，画面方向与左相机原图一致）；maybeAutoFrame（扫描视角跟随——生长感知自动取景：标志点包围球半径出 0.8×~1.25× 带即重取景、1s 节流、用户拖拽期避让）；setAutoViewFit 总开关；adjustViewToMaxProjection（PCA 最大投影平面法向——代码存在，调用点注释禁用）。
  - 叠加层：createAxesIndicator（左下角 XYZ 三轴指示器——锥头＋文本标签＋原点球，独立正交相机 POST_RENDER）；createCenterOverlay（中心十字——代码存在，构造时注释禁用；setCenterOverlayVisible 可控显隐）。
  - 渲染加固：setFaultSink 轻量事件出口（03 不依赖 base/EventBus，app 装配桥接）；setIngestBudget 摄入预算（点数上限＋包围盒半径上限 mm）；suspendRender/tryResumeRender（渲染挂起保 UI 存活/外部恢复）；RenderStats 只读观测快照（framesDrawn/ingestCount/lastFrameMs/degradeLevel/suspended）。
- 交互：消费 06 PointCloudBuffer 快照（MainWindow 拉取后值传，03 不 include 06 实现类）；06 fileio 网格导入；01 CalibDisplay 喂 osg::Group；07 经 app SceneFeedAdapter 推实时标志点/激光点快照与冻结通知（pushPostureView 姿态视图在 adapter 侧仅日志空转——01 接线未做）。
- 线程/并发：全部公开入口 UI 线程调用；渲染定时器 33ms（30fps）。
- 错误/降级：码表见 2.2 RenderEvent（0x0301–0x0312）；拒绝语义一律保留现画面（版本未变＝正常静默路径）；摄入先建后换（构建期 bad_alloc 等异常→0x0302 旧景保留，仅替换点云 geode 不 clearScene）；paintGL 护栏——frame() 异常→挂起渲染循环（timer 停、Qt 事件循环存活）tryResumeRender 恢复（30fps）；连续 5 帧 >50ms→摄入预算自动降一级（阶梯 8M/4M/1M/256K，0x0311）；外部 setIngestBudget 显式设预算＝退出自动降级阶梯。
- 现状限制：m_viewLocked 为死代码（全工程从未置 true，标定模式视图锁定实际由 MainWindow 用 setCameraManipulator(nullptr)＋setViewMatrix 绕过实现）；MainWindow 顶栏注释与代码不符（注释列 5 模式含切面扫描，实际条件 i==2..5 不含 i==6；i==6 切面/i==7 重置两按钮未接线）；MainWindow 调试导出 markers_snapshot.ply/laser_snapshot.ply（1/30 节流覆盖写，人工核对用）仍在。
- 状态：✅

### 2.2 `modules/03_rendering/RenderSanity.h`（Scanner::render，03-2）
- 核心能力：快照摄入防御纯函数 sanitizeSnapshot——版本短路/空数据/NaN·Inf 就地滤除（颜色同步搬移）/颜色尺寸不配拒绝/包围盒半径越界整份拒绝/超预算均匀抽稀（恰留预算条、首尾保留）；RenderEvent 事件码表（0x0301 快照拒绝、0x0302 构建降级、0x0303 渲染挂起、0x0304 挂起恢复、0x0311 帧超时抽稀、0x0312 降级级别变化——app 桥接契约）。仅依赖 OpenCV core，无 Qt/OSG，可无头单测。
- 交互：loadCloudSnapshot 摄入前调用；码表经 setFaultSink 注出，app 桥 EventBus（param1=码、param2=Degraded）＋日志。
- 测试覆盖：`tests/test_render_sanity.cpp` 9 用例（版本闸/空/全无效/部分滤除＋颜色同步/尺寸不配/包围盒/抽稀均匀性/正常通过/码表值稳定）。
- 状态：✅

### 2.3 `modules/03_rendering/CMakeLists.txt`（mod_rendering）
