## 1. 信息〔人＋AI〕

### 1.1 模块背景〔AI 预填，迭代时刷新〕

- **模块定位**：整机唯一 3D 显示画布——点云/网格/标志点/激光点的可视化、相机控制、叠加层；扫描长什么样全看它
- **上下游依赖**：
  - 上游：06 PointCloudBuffer 快照（MainWindow 定时轮询拉取后值传）
  - 上游：06 fileio 网格导入（loadMesh 经 `Scanner::data::fileio::importMesh`）
  - 上游：07 流水线实时推送（经 app SceneFeedAdapter：标志点/激光点/冻结通知）
  - 上游：01 CalibDisplay 产标定场景 osg::Group（buildCalibScene）
  - 下游：无业务下游——终端显示
  - 下游：渲染事件经 setFaultSink 函数出口，由 app 桥 EventBus（sourceId=0x03）＋日志
- **关键约束**：
  - 单 Qt UI 线程渲染：QTimer 33ms（约 30fps）驱动 paintGL，全部公开入口须 UI 线程调用
  - 跨线程纪律：流水线线程数据在 SceneFeedAdapter 调用线程立即值拷贝，经 Qt queued signal 切 UI 线程
  - 不直接依赖 base/EventBus：渲染事件走 setFaultSink 函数出口，app 桥接（sourceId=0x03）
  - 不 include 06 PointCloudBuffer：快照由调用方拉取后值传；网格解析用 06 fileio 自由函数
  - 依赖面：Qt/OSG/OpenCV core/Eigen（PCA）/06 fileio/10 日志宏——RenderSanity 仅 OpenCV，可无头单测
  - 编辑（圈选/删除/撤销）功能目标归 [`05-编辑-v2.md`](05-编辑-v2.md)；本模块仅承载其显示层（代码物理在 OSGWidget）
  - 编译归属：OSGWidget.{h,cpp} 由 app 直编入 scan_demo；mod_rendering 仅 INTERFACE 承载 RenderSanity＋单测

## 4. 已有代码现状〔AI〕

### 4.1 总图

```
【渲染数据入口全景】
06 PointCloudBuffer ──MainWindow 500ms 轮询──► loadCloudSnapshot（值传·仅非扫描期重载）
06 fileio importMesh ──「文件管理→导入网格」──► loadMesh（STL/OBJ）
07 流水线 ──app SceneFeedAdapter（值拷贝＋queued signal）──► loadMarkerPoints／loadLaserPoints
01 CalibDisplay ──buildCalibScene──────────► setSceneData（标定分屏）
                     │
                     ▼
        OSGWidget（单 UI 线程，QTimer 33ms paintGL）
             │ 渲染事件码表 0x0301–0x0312
             └──setFaultSink──► app 桥 EventBus＋日志
```

> 场景编排（模式切换）无模块内枚举，全由 MainWindow 方法序列编排：标定分屏 / 扫描浏览 / 模式键切回默认界面（clearScene＋中心十字显隐复位＋Trackball 复位）/ 文件导入 / 仓库轮询刷新五路。
>
> 仓库轮询仅非扫描期重载 3D：扫描会话活跃期只跟工程树计数不重载（激光已由 laserCloudUpdated 直渲，再拉同份点＝双份顶点/内存）；会话结束或导入云才走快照重载（`app/MainWindow.cpp:2507`）。
