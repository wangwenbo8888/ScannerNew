## 3. 代码实际实现的（AI 可随代码演进更新此节）

> **一句话职责**：把"拍照 → 算参数 → 存文件"这条标定流程串起来。本模块只做**编排、存储、UI**三件事；标定算法本身（算子）都在 `modules/09_operatorlib/calibration/`，不在 01。
>
> **编译归属**：文件物理都在 `modules/01_calibration/`，分两处编译——`CalibStore` → 静态库 `mod_calibration`；工作流 + UI（`CalibrationWorkflow` / `calib_workflow` / `CalibDialog` / `CalibDisplay` / `IntegrateTestDialog`）→ 直接编入 app 的 `scan_demo.exe`。

### 3.1 参数存储 — CalibStore（`CalibStore.h/.cpp`）

线程安全的标定参数仓库（mutex 保护）：
- `save/load`：用 `cv::FileStorage` 落盘（实际产出 YAML，如 `calibration.yml`）。
- 存的字段：内参/畸变（左右）、矫正 R1/R2/P1/P2/Q、外参 extR/extT、图像尺寸。
- 有全部 setter；除外参外有全部 getter；`hasData()/clear()`。

### 3.2 标定主流程 — CalibrationWorkflow（`CalibrationWorkflow.cpp:57-270`）

实现 `IWorkflow` 接口，后台线程跑 6 步：

1. **采集**：从帧缓冲弹帧，收满 `numPoses_`（默认 25）组左右灰度图；
2. **角点检测**：直接用 OpenCV `findChessboardCorners` + 亚像素精化（**不是**标记点算子链）；
3. **内参标定**：算子 `intrinsic_calib_cpu`；
4. **外参标定**：算子 `extrinsic_calib_cpu`（右图旋转 180°）；
5. **立体矫正**：算子 `stereo_rectify_cpu`；
6. **温度补偿表**：算子 `stereo_rectify_temp_table_cpu`（参考 25℃、范围 ±10℃、步长 0.2℃）——**只打了日志，没存**。

完成后把内参/畸变/外参/矫正矩阵写入 `CalibStore` 并 `save("calibration.yml")`；进度经回调上报 UI。

### 3.3 算法函数集 — calib_workflow（`calib_workflow.h/.cpp`）

- `runCameraCalibration`：**已实现**。内参→外参→矫正三步编排（无温度表、不写 CalibStore）。
- `runLaserCalibration`（`calib_workflow.cpp:147`）：**桩**。只做输入校验，直接返回 `"operator integration TODO"`。
- JSON 存取：相机侧 `saveCalibResult/loadCalibResult` 完整可用；激光侧只有 `lineCount/endpointCount` 占位字段。

### 3.4 标定 UI（编入 app）

| 文件 | 功能 |
|---|---|
| `CalibDialog` | 标定入口对话框，「相机标定」「激光标定」两个按钮 |
| `CalibDisplay` | OSG 标定场景 + Qt 画的 2D 标定板控件 |
| `IntegrateTestDialog` | 集成测试：串 08 的 CameraControl 采图、调曝光/频率/激光强度、显示左右图、触发标定 |
