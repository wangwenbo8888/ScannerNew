## 职责
**标定**：25 姿态采集 → 解算相机内外参 / 立体矫正 / 激光平面映射表 / 温度补偿表，产出可复用标定参数。

模块1 持有补偿表，故跨**两个运行阶段**：
- **离线 batch 标定**（操作员发起的标定会话，Workflow 层）：采集 → 解算 → 落盘
- **运行时温度补偿查询**（`getCompensatedParams(temp)`，Service 层）：模块8 喂温度 → 返回该温度下补偿后参数 → 模块2 扫描消费

> **主层**：Workflow ｜ **跨层**：Algorithm(标定算子) · Data(标定数据/产物) · Service(温度补偿查询)

## 子功能细化

### 总览：两条独立流水线
```
第一流水线（姿态采集，持续运行至集齐 25 姿态）
  阶段0 初始化 → 阶段1 采集循环 → 阶段2 姿态判断
                          │ 集齐 25 姿态
                          ▼
第二流水线（参数解算，集齐后一次性执行）
  阶段3 相机标定(含温度补偿) ∥ 阶段4 激光标定(含温度补偿)
```
> v2.2 起「原阶段5 温度补偿」已解散：5-1/5-2 并入阶段3，5-3 并入阶段4。

### 1.1 姿态引导采集（第一流水线）
- **阶段0 初始化**：设备预热 3 分钟（热稳定）；从预热起每帧记录温度；读入初始内外参 / 立体矫正参数 / 标定板参数
- **阶段1 采集周期**（下位机硬触发双目同步）：每周期 = 1 帧标记点图 + N 帧激光管图 + 温度；每帧单一特征（标记点或某一激光管）
- **阶段2 姿态判断链**（**姿态优先 · 不丢帧**，1 个 GPU 槽）：
  - GPU：2-1 `mask_extract` → 2-1b `frame_filter`（排除激光线帧）→ 2-2 `ccl`
  - CPU：2-3~2-11 标记点链（`image_split`→`zernike_edge`→`image_merge`→`undistort_cpu`→`ellipse_fit`→`marker_match`→`epipolar_intersect`→`edge_match`→`point_reconstruct`）
  - 2-12 `frame_fuse`：首帧建参考集，后续 PFH+RANSAC 刚体配准求 R/T
  - 2-13 `pose_estimate`：比对 25 目标姿态
- **25 姿态采集控制流**（多帧确认，防偶然单帧命中）：
  命中姿态 X → 回溯确认（上一采集循环也命中 X）→ 完整性检查（两标记点帧之间的 N 个激光管帧时间戳连续、无丢帧）→ 保存上一完整循环 → 原子标记 X 已采集 → 集齐 25 转第二流水线
- **背压**：环形缓冲满时阻塞采集线程，不丢帧

### 1.2 相机标定（第二流水线·阶段3，含温度补偿）
```
3-1 inverse_distort → 3-2 intrinsic_calib → 3-3 extrinsic_calib → 3-4 stereo_rectify
                       │(内参)               │(外参)               │
                       ▼                     ▼                     ▼
                    5-1 内参补偿表         5-2 外参补偿表         3-5 立体矫正温度补偿表
```
- **3-1 逆畸变**：姿态合格帧的椭圆中心，用**初始**内参/畸变/R1/P1 逆变换（须与 2-6 `undistort_cpu` 同源，否则内参标定输入存在系统性偏差）
- 产出：双目内参 / 外参(R,T,E,F) / 立体矫正(R1,R2,P1,P2,Q) / 内参+外参温度补偿表

### 1.3 激光器标定（第二流水线·阶段4，含温度补偿）
```
激光前端链路(4-1~4-8) → [编排层跨姿态聚合] → projector_joint_calib → 4-12 plane_map
                                                                    ├→ 4-13 温度补偿映射表
                                                                    └→ 5-3 激光外参补偿表
```
- **前端链路**：4-1 `mask_extract` → 4-2 `ccl` → 4-3 `laser_label` → 4-4 `steger` → 4-5 `undistort_cuda` → 4-6 `epipolar_interp` → 4-7 `laser_match` → 4-8 `laser_reconstruct`
- **`projector_joint_calib`**（v2.2 替代旧端点链路 4-9/4-10/4-11）：多姿态点云 LM 联合优化求投影机光心 + 发射曲线（不依赖激光线端点）
- 产出：激光平面映射表(17线) / 温度补偿映射表 / 激光外参补偿表

### 1.4 产物与运行时查询
```
标定产物 CalibrationArtifacts
├── 内参: cameraMatrixL/R, distCoeffsL/R, intrinsicRms
├── 外参: R, T, E, F, stereoReprojError
├── 立体矫正: R1, R2, P1, P2, Q, validRoiL/R
├── 激光: virtualK/R/T, laserReprojError, plane_map(17线)
└── 温度表: intrinsic/extrinsic/laser 三组补偿表
```
- **落盘**：经 Data 层 `WorkflowArtifactStore`(ADR7.10) + 模块6 持久化（JSON）
- **消费者**：模块2 扫描、模块4 后处理
- **运行时查询服务** `getCompensatedParams(temp)`（Service 层）：模块8 喂当前温度 → 查温度补偿表 → 返回补偿后内外参/立体矫正/plane_map → 模块2 实时扫描消费
