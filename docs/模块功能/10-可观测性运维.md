## 职责
统一日志(配置/轮转/分级), 性能监控(延迟/帧率/计数器dashboard), 崩溃捕获(minidump/crash)。

## 当前状态: ❌ 仅spdlog基础

## 子功能细化

### 10.1 统一日志
- **spdlog升级**: 配置文件驱动 (级别/格式/轮转/多sink)
- **日志分级**: TRACE/DEBUG/INFO/WARN/ERROR/FATAL
- **多sink**: 控制台(彩色) + 文件(轮转 10MB×5) + 可选远程syslog
- **分类标签**: `[CALIB]` `[SCAN]` `[GPU]` `[HAL]` `[SESSION]`
- **CALIB_LOG_*宏**: 已有, 需扩展到所有模块

### 10.2 性能监控
```cpp
struct PerfCounters {
    // 采集
    std::atomic<uint64_t> captureFps{0};        // 实际采集帧率
    std::atomic<uint64_t> dropCount{0};         // 丢帧数
    // 处理
    std::atomic<uint64_t> processFps{0};        // 处理帧率
    std::atomic<uint64_t> gpuLatencyMs{0};      // GPU链延迟
    std::atomic<uint64_t> cpuLatencyMs{0};      // CPU链延迟
    std::atomic<uint64_t> totalLatencyMs{0};    // 端到端延迟
    // 点云
    std::atomic<uint64_t> markerPointCount{0};  // 标记点数
    std::atomic<uint64_t> laserPointCount{0};   // 激光点数
    std::atomic<uint64_t> fusedPointCount{0};   // 融合后点数
    // 设备
    std::atomic<double> temperature{0};         // 当前温度
    std::atomic<uint64_t> gpuMemoryUsed{0};     // GPU显存使用
};
```
- **Dashboard**: 实时折线图 (帧率/延迟/温度)
- **告警**: 帧率低于阈值/温度过高/GPU OOM

### 10.3 崩溃捕获
- **Windows**: `SetUnhandledExceptionFilter` + minidump (`MiniDumpWriteDump`)
- **自动重启**: 崩溃后可选自动重启 + 恢复会话
- **崩溃报告**: minidump + 日志 + 系统信息打包上传

## 依赖
- spdlog (已有)
- Windows DbgHelp (minidump)

## 优先级
- **高**: 统一日志配置 (调试必需)
- **中**: 性能监控 (调优必需)
- **低**: 崩溃捕获 (出厂级)
