# 模块9 · 算子库

> 一句话：本模块是三维扫描仪的**计算零件箱**——全部纯计算叶子算子的集合，标定/扫描两条流水线要什么算子都来这里拿，算子自己不编排、不碰设备。
> 返回索引：[`模块功能目录.md`](../../模块功能目录.md)

## 1. 功能目标

供标定/扫描两条流水线复用的全部纯计算叶子算子，按族组织、统一契约。覆盖核心视觉前端、标记点链（CPU）、激光线链（CUDA）、标定独有算子（相机/激光虚拟相机/姿态/温度补偿）、扫描独有算子（掩膜分离/激光匹配/点云融合）以及全局优化（Ceres BA）。

统一契约（全库一致）：三元组＝Params（validate/toJson/fromJson）＋Result＋Operator（Execute/Warmup/SetParams/Destroy，pImpl 禁拷贝）；CUDA 算子统一 `Stream&` 流亲和（不内部同步默认流）；目录约定 `<name>_cuda.h`/`.cpp`/`_pimpl.h`/`_impl.cu`/`tests/test_*.cpp`。详见 [`算子规范.md`](../../算子规范.md) §1–§5。

### 1.1 core/common 共享类型层（非算子）
- 做什么：两条算子链共用的词汇表——通用标定类型、跨应用数据契约（calib_result_types.h）、质量标志、统一 Result 模板、日志宏、JSON 工具等 11 个纯头。
- 交互：全库算子与 06（TempTableTypes）/07（Snapshot 参数）消费其契约类型。

### 1.2 core/scheduler 跨帧状态
- 做什么：跨帧记忆——上一帧算到哪了（AtomicFrameState 原子快照）。
- 交互：07 A/C 流水线配准段读写。

### 1.3 core/vision 视觉前端三工序
- 做什么：两条链共用的前端——抠掩膜（mask_extract）、挑帧型（frame_filter，排除激光线帧）、数连通块（ccl/region_analyze）。
- 交互：07 A gpuChain 前段与 C GPU 链首共用。

### 1.4 core/marker 标记点链（12 算子）
- 做什么：标记点识别配准一条龙——分割→Zernike 亚像素→合并→去畸变→椭圆拟合→双目匹配→极线交点→边缘匹配→三维重建→[单帧兜底 frame_fuse｜光流默认 optical_flow_fuse]→体素哈希融合 marker_cloud_fuse_cpu（含 seed 预填已有点）。
- 交互：07 A pChain（9 算子＋初始参数组）与 C P 链（snapshot 参数＋配准）消费。

### 1.5 core/laser 激光线链（4 算子）
- 做什么：激光线处理一条龙——Steger 中心亚像素→CUDA 去畸变→极线插值→三维重建。
- 交互：07 B LaserChain 前段与 C GPU 链激光段消费。

### 1.6 calibration/camera 相机标定链（5 算子）
- 做什么：内参外参矫正表一条龙——逆畸变→双目内参→双目外参→立体矫正→温补矫正参数表。
- 交互：07 B CameraChain 消费。

### 1.7 calibration/laser_calib 虚拟相机/投影机标定链（8 算子）
- 做什么：从编号到平面映射表——编号→匹配→端点→光心→外参优化→PJC 联合标定（投影机光心与发射曲线，独立替代端点链路）→平面映射表→温补查找表。
- 交互：07 B LaserChain 消费。

### 1.8 calibration/posture 姿态估计
- 做什么：算设备当前姿态（pose_estimate）。
- 交互：07 A eFinalize 消费。

### 1.9 calibration/temp 温度补偿三件套
- 做什么：温度变化打的补偿——内参/外参/激光外参温度补偿。
- 交互：01/02 温度表生成侧与 06 出口查表（FrameEnricher）配套。

### 1.10 scanning/preprocess 掩膜分离
- 做什么：把激光和标记点的掩膜分开（mask_separation）。
- 交互：07 C GPU 链首。

### 1.11 scanning/laser 激光匹配扫描
- 做什么：扫描时的激光线匹配（laser_match_scan，查温度映射表）。
- 交互：07 C GPU 链激光段。

### 1.12 scanning/fusion 点云融合＋法线（4 算子）
- 做什么：激光点云的融合与法线估计——CPU/CUDA 双轨并列（laser_cloud_fuse±_cuda / laser_cloud_normal±_cuda）。
- 交互：07 C FuseConsumer（融合适配器）与 E NormalStage（法线）消费。

### 1.13 scanning/global_optim 全局 BA
- 做什么：全局 Bundle Adjustment 优化器＋位姿图残差——收尾纠偏用。
- 交互：07 D GlobalOptimObject 消费（软先验挂已有点）。

## 2. 实现现状（以代码为准）

- 编译归属：单 STATIC 库 `mod_operatorlib`（core＋calibration＋scanning 合建），命名空间 `calib::`（3DSCANNER 机械迁入保留）；`file(GLOB_RECURSE)` 收源（增删算子文件需手动重跑 cmake）、剔除 bench/benchmark 与 gba_dataset_runner；链 OpenCV/Eigen/spdlog/nlohmann_json（PUBLIC）；BUILD_CUDA 定义门控 CUDA 算子；BUILD_GLOBAL_OPTIM 链 Ceres＋编入 global_ba_cpu.cpp，另单独建 `gba_dataset_runner` exe（GBA 离线工具，含 main 不入库）；全部算子自目录入 PUBLIC include（跨算子 include 可解析）；MSVC `/bigobj`（含 .cu 经 `-Xcompiler`）。
- 测试覆盖：45 个测试 exe（每 test_*.cpp 一个 exe＋注册 ctest）覆盖全部算子族；工程全量 ctest 95/95 绿（Debug＋Release）。
- 错误/降级总述：算子级质量经 QualityFlag 标志（ok/degraded/warning 语义）随 Result 返回；鲁棒估计（GBA Tukey 核＋卡方门控；软先验 id 无对应点 warn 忽略不 fail）。
- 消费关系一张图：

```
07 A 姿态：  vision(mask_extract→frame_filter→ccl) → marker 9 算子 → [optical_flow_fuse|frame_fuse] → pose_estimate
07 B 标定：  CameraChain(camera 5 算子) ‖ LaserChain(laser 4 算子前段 + laser_calib 后段 PJC)
07 C 扫描：  mask_separation→ccl → laser 链(steger→undistort_cuda→epipolar_interp
             →laser_match_scan→laser_reconstruct) ‖ marker 链+配准(prev_frame_state)
             → FuseConsumer(fuse±_cuda + normal_cuda) → obs 累加
07 D 收尾：  global_ba_cpu(+两残差头， 软先验) → 重融合(新融合实例重放)
07 E 后处理：laser_cloud_normal(法线阶段) + [网格四族待建→内置桩 degraded]
```

### 2.1 `core/common/`（11 共享头，09-1）
- 核心能力：双链公共类型与契约——calib_types/calib_result_types（跨应用数据契约）/zitai_result_types/quality_flag/result/pipeline_types/calib_warmup_config/calib_logging/json_utils/scanner_api/version。
- 交互：被全库算子与 06/07 消费（TempTableTypes、CalibSnapshot 同源契约）。
- 契约：形态＝纯头，无算子。
- 状态：✅

### 2.2 `core/scheduler/prev_frame_state.h`（AtomicFrameState，09-2）
- 核心能力：跨帧调度状态原子快照（上一帧标记点＋位姿，读最新写覆盖）。
- 交互：07 A/C 配准段经 AtomicFrameStatePtr 持有。
- 契约：形态＝CPU 单头。
- 状态：✅

### 2.3 `core/vision/`（mask_extract/frame_filter/ccl，09-3）
- 核心能力：前端三道工序——抠掩膜、挑帧型、数连通块。
- 交互：07 A gpuChain 与 C GPU 链首；A 链 frame_filter 判激光线帧销毁整周期。
- 契约：CUDA 三元组。
- 测试：test_mask_extract_cuda（＋精度版）/ test_frame_filter_cuda / test_region_analyze_cuda。
- 状态：✅

### 2.4 `core/marker/`（12 算子，09-4）
- 核心能力：标记点识别配准全链（§1.4）；marker_cloud_fuse_cpu 含 seed()（已有点预填，先入不被后帧覆盖）。
- 交互：07 A pChain（初始参数组）/C P 链（snapshot 参数）；融合产出经 07 适配器入 FuseConsumer 与 D 重融合。
- 契约：CPU 三元组。
- 测试：12 算子各有 test（含 test_marker_cloud_fuse_seed——seed 时序钉测）。
- 状态：✅

### 2.5 `core/laser/`（4 算子，09-5）

- 交互：07 B 激光前段与 C GPU 链激光段。
- 契约：CUDA 三元组（Stream& 流亲和）。

- 状态：✅
