## 二、精细战役（11-07）：宽带口径的发现

### 2.1 根因五层剥洋葱（每层一个下午的教训）

```
① 级联间距门旧值：cascade_spacing_px=36.9 是旧机标定值
   → 解析新机 CMTT 实测：T 61~87 / V 39~62 / D 68~108px
② PJC 错误盆地：projectorT z=-54mm（物理荒谬）
   → 开发 pjc.initialT 初值注入（同机好解先验），rms 25.9→6.44
③ 口径断裂（核心发现）：标定链 steger 抽"带内纹理点" vs 实扫 flat"平顶中心"
   → 细线时代两口径重合、宽带下系统性错位＝匹配死根因
④ 宽带形态：精细线是 30~100px 斑驳宽带（非细线）
   → 整条细线链（宽度门/平顶/列扫描）对它全不适配
⑤ 碎段质心偏移：实扫行段被暗纹切碎（30px vs 标定 30~100px）
   → flat_center 增 segMergeGap 段合并（gap≤8 背景断口桥接）
```

### 2.2 路线 B 落地（带中心质心口径）

- `flat_center` 算子增 **scanAxis=1 行模式**（每行段内去背景亮度质心）＋**segMergeGap**——09/fc 双侧同步
- CLI 4-4 增 `steger.extractor=flat`＋`flat` 组
- 标定终版 **rms 0.0765**（vs 纹理口径 6.44，差 84 倍）
- 主工程**双实例选路**：flatRow（恒行模式）给 D 帧、flat（恒列模式）给细线帧——零切换零同步

### 2.3 组切换三轮证伪（架构学费）

| 方案 | 结局 |
|---|---|
| SetParams 直调（每帧） | warmup 重置竞态 → 间歇 0xC0000005 |

| ＋退休重建实例 | 首帧必触发 → 断链 |
| **终版：双实例纯选路** | 构造期固定参数，运行期零切换 ✅ |

## 三、左斜战役（11-08）：环境光与盆地

### 3.1 十二轮实验的主线

| 轮 | 发现 | rms |
|---|---|---|
| v1 | 过曝 6.4%（粘连 runWidth 104~115） | 5.72 |
| v3/v4 | 面板绿灯批混档帧（黑帧/过曝帧混入）；挑帧代理指标与门禁不同源 | 6.56 |
| v7 | 门禁放开实验（=0）：17 ok 但 **19.5**（脏线毒化）——门禁必须严 | 19.5 |
| 对照 | 右斜成功批同 config 重跑：6/26 过门 → **0.119 PASS**——**门禁高拒绝率是设计** | 0.119 |
| v8/v9 | **背景灰度发现**：右斜批 14~19 vs 左斜 28~55（环境光）→ 全关补光背景 0 | **4.69** |
| 网格 | initialT z 九点扫描：**深盆地 z+11~13**，自由收敛漂（z=-1.5） | 4.99 |

### 3.2 关键认知

- **环境光是隐形杀手**：背景 55→0 直接带来 rms 7.2→4.7
- **过门帧质量 > 数量**：6 帧干净帧可 PASS；71 被拒是设计
- **PJC 盆地漂移是常态**：initialT 网格勘探（tools/calib_pjc_grid.py）是标准流程
- **GUI 关窗自动清 data_in**：两度丢主力帧——过门帧即时安全拷贝纪律

## 四、精细二役（11-08 午）：网格化采集到 A6 达标

| 步骤 | 结果 |
|---|---|
| 老数据（18 pose）网格 | rms 0.0765 / A6 14.6 / A7 7.5——A7 是老数据极限 |
| 新批 1（73 pose 随机） | rms 0.132 / A6 6.48——**弱帧（出点中位 523）拖累** |
| mpp 扫描（minPointsPerPose 50→100） | **A6 6.48→2.68**——弱观测帧剔除是关键一手 |
| 混合集（新旧两批） | A6 7.92 反弹——**单批纯数据 > 多批混合**（亮度条件不同互相打架） |
| **新批 2（34 pose 网格化：5 深度×3 偏航×俯仰）** | **rms 0.1076 / A6 1.60 首次达标** / 88% 过门 |

### 方法论沉淀（三条规律）

1. **网格化采集 > 随机多采**（88% vs 54~80% 过门）
2. **单批纯数据 > 多批混合**（混集 A6 5 倍劣化）
3. **质量 > 数量**（30 网格帧 > 73 随机帧）
