## Phase 1 — 入口防御＋护栏（防崩，最高优先）

### 1.1 纯函数抽取：`RenderSanity.h`（header-only，挂 03 INTERFACE 目标）

```cpp
namespace Scanner::render {
struct IngestDecision { bool accept; bool truncated; size_t keptCount;
                        size_t nanFiltered; const char* reason; };
IngestDecision sanitizeSnapshot(std::vector<cv::Point3f>& pts,
                                std::vector<cv::Vec3b>& colors,
                                uint64_t newVersion, uint64_t lastVersion,
                                size_t maxPoints, double maxExtent);
// 规则：版本相同→拒绝(reason="unchanged")；全空→拒绝；
//       NaN/Inf 逐点滤除（计数）；kept>maxPoints→均匀抽稀截断(truncated=true)；
//       包围盒半径>maxExtent(默认1e6mm)→拒绝(reason="extent")
}
```
可独立单测（无 Qt/OSG 依赖）。

### 1.2 OSGWidget 摄入加固（改造 loadFromPointCloudBuffer）

1. 调 `sanitizeSnapshot`——拒绝则直接 return（保留现画面）
2. **原子替换**：新 geode 构建完成才 `replaceChild`（或 setSceneData 切换），废除"先 clear 后建"空窗；构建包 try/catch，`bad_alloc`→保留旧场景＋上报 0x0302
3. 记录 `m_lastVersion`

### 1.3 渲染循环护栏

```cpp
// paintEvent 内
try { m_viewer->frame(); }
catch (...) {
    m_timer->stop();                       // 挂起渲染循环
    reportFault(0x0303, "渲染帧异常，循环已挂起（UI 存活）");
    m_renderSuspended = true;              // 状态条可见标志
}
```
恢复路径：外部可调 `tryResumeRender()`（重起 timer，下帧再抛则再挂——防崩溃风暴）。

### 1.4 轻量事件出口（不引 EventBus，保持 03 可测）

```cpp
// OSGWidget 增：
using RenderFaultSink = std::function<void(int code, const std::string& msg)>;
void setFaultSink(RenderFaultSink s);      // app 装配时桥接到 EventBus/日志
```
**03 事件码表**（对齐 07 的 16xx/19xx 先例）：
`0x0301 快照拒绝(数据异常) / 0x0302 构建降级(bad_alloc 保留旧景) / 0x0303 渲染挂起 / 0x0304 挂起恢复 / 0x0311 帧超时自动抽稀 / 0x0312 降级级别变化`

### 1.5 测试（新增 `modules/03_rendering/tests/`，目标挂入全量 ctest）

- sanitizeSnapshot：NaN 注入/版本不变/超限截断/包围盒越界/全空——5 用例
- OSGWidget 级（若 CI 无显示环境则仅编入人工清单）：坏数据不崩、frame() 抛异常 UI 存活（注入式 fault）

**验收**：坏快照永不黑屏永不崩；模拟 frame 异常后 Qt 循环存活且收到 0x0303；全量 ctest 绿。

## Phase 2 — SceneFeed 接线＋跨线程 marshal（喂饱）

### 2.1 app 侧 `SceneFeedAdapter`（QObject，编入 scan_demo）

```
FuseConsumer 线程 pushCloudSnapshot(handle)
   └─ adapter 在【调用线程】立即拷贝 marker 点集（点数少，拷贝廉价）
      — 禁止跨线程持有句柄（FuseConsumer 随后仍写同一 vector，引用=竞态）
   └─ emit queued signal（值语义载荷）→ UI 线程 OSGWidget::ingestCloudSnapshot
notifyFreeze(true/false) → 置挂起标志（ingest 丢弃，画面保持末帧）
```

### 2.2 帧耗时探针＋自动抽稀

- paintEvent 计时；连续 5 帧 >50ms → 点数预算降一级（8M→4M→1M→仅marker）＋0x0311 上报
- 预算恢复：手动/扫描会话边界复位

### 2.3 接线落地

- AppContext：adapter 实现 `ISceneFeed`，经 PipelineDeps 注入 02/07（兑现两处 TODO）
- 02 扫描会话把 adapter 同时接到 C 线（节流快照）与 D（冻结/解冻＋修正云）

**验收**：模拟扫描源下 marker 云实时显示 ~30fps；freeze 期间画面冻结；跨线程无共享引用（代码审读＋Windows AppVerifier/TSAN 抽查）；02 两处 TODO 注释消除。
