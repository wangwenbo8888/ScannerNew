## 1. 目标与约束

### 目标
- **端到端追踪**：从相机帧到最终点云产物，追踪一帧数据"的一生"——经过哪些算子、数据类型怎么变化、在哪一层。
- **每环节标注数据类型**：每个算子节点标明输入/输出的精确类型（`cv::Mat` / `GpuMat` / 具体 Result struct）。
- **内存/显存流转关系**：每个节点标明数据驻留域（Host 内存 / Device 显存），跨域转换（H2D 上传 / D2H 下载）显式标注。
- **标定→扫描交接显式化**：标定产出的两张温度补偿表是全系统唯一跨工作流数据耦合，独立成节。

### 约束
- 章节自包含（读者无需跳转即可追踪完整数据流），但算子级分叉细节链接到 `docs/流水线/` 详图。
- 数据类型以算子库代码头文件为准（`core/common/*.h` 契约类型）。
- 基于现有算子代码 + 框架设计目标；标注已实现（★）与待建（☐）。

### 与现有章节的关系
- §2 给**静态架构**（谁在哪层）
- §5 给**控制流**（状态怎么跳）
- **§6 给数据流**（一帧数据从哪来、经过谁、变成什么、到哪去）——三者正交

## 3. 各小节内容设计

### 3.1 §6.0 数据旅程总览

三段式横向总览图：

```
〔离线·冷路径〕标定              〔交接〕             〔运行时·热路径〕扫描
(Workflow·Algorithm·DataStore)  (DataStore→内存/显存)  (HAL→DataPlane→Workflow→Algorithm)

相机帧 → Stage0 配置             标定产物              相机帧 → Stage0 预处理
      → Stage1 采集循环         ┌──────────┐          → 双分支(标记点∥激光)
      → Stage2 姿态判断 ──►     │两张温度表│ ──►注入──► → 融合 → 显示
      → Stage3 相机标定         │(DataStore)│          → GlobalOptimStage(批处理)
      → Stage4 激光标定         └──────────┘             → 点云产物
        (秒~分钟)                                  (μs~ms/帧, 180fps)
```

标注要素：
- 每段所在层（Workflow/Algorithm/Data/HAL）
- hot/cold 路径
- 两条独立标定流水线（第一=持续循环，第二=一次性）
- A/B 扫描模式变点（①激光链跳过）
- GlobalOptimStage 定位（扫描与后处理之间的批处理）
- skip-layer 热路径（Workflow→Data 点云双缓冲）

### 3.2 §6.1 标定数据流追踪

导读：标定是离线一次性流程（秒~分钟级），产出两张温度补偿表供扫描查表。分两条独立流水线。

#### §6.1.1 第一流水线（持续循环）Stage0→1→2

**Stage0 初始化**（DataStore 读入）：
- 入：配置文件 → 出：初始内参(fx/fy/cx/cy) + 外参(R/T) + 立体矫正参数 + 标定板参数（均 Host）

**Stage1 图像采集循环**（HAL→DataPlane）：
- 下位机硬触发，每帧只含一种特征：标记点帧(补光灯ON) / 激光管N帧(激光管N ON)
- 出：标记点灰度图 + 激光管灰度图 + 温度（双副本：Host cv::Mat + Device GpuMat）
- 帧率 180fps，每帧记录温度

**Stage2 姿态判断链**（帧级流水线，14 算子，GPU段→CPU段）：

| 算子 | 设备 | 输入类型(域) | 输出类型(域) | 跨域 |
|---|:---:|---|---|:---:|
| 2-1 `mask_extract` | CUDA | `cv::Mat` CV_8UC1 (Host) | `MaskExtractResult`{d_grayImage,d_laserMask,d_cleanedMask} (Device GpuMat) | ↑H2D |
| 2-1b `frame_filter` | CUDA | d_cleanedMask (Device) | `FrameFilterResult`{isMarkerFrame,maskRatio} + d_cleanedMask透传 | — |
| 2-2 `ccl` | CUDA | d_cleanedMask (Device) | `RegionAnalysisResult`{d_labeledMask CV_32SC1 + components} | — |
| 2-3 `image_split` | CPU | cv::Mat(Host灰度副本) + components(Host) | `ImageSplitCPUResult`{splitImages vector<cv::Mat>} | ↓灰度用Host副本 |
| 2-4 `zernike_edge` | CPU | splitImages[i] cv::Mat (Host) | `ZernikeEdgeCPUResult`{edgePoints} | — |
| 2-5 `image_merge` | CPU | vector<vector<EdgePoint>> + ROI (Host) | `ImageMergeCPUResult`{mergedEdgePoints+groupIds} | — |
| 2-6 `undistort_cpu` | CPU | EdgePoints+groupIds+初始内参 (Host) | `StereoUndistortResult`{rectifiedPoints+R1/R2/P1/P2/Q} | — |
| 2-7 `ellipse_fit` | CPU | rectifiedPoints (Host) | `EllipseFitCPUResult`{center,major/minor,axis} | — |

| 2-13 `pose_estimate` | CPU | R/T+标定板目标矩阵 (Host) | `PoseEstimateCPUResult`{currentPose,anyMatched} | — |

- 输出：命中25目标姿态 → 保存完整采集循环图像（标记点帧+激光管帧+温度）
- GPU/CPU 分界在 2-2→2-3：ccl 的 components 已在 Host；灰度用 Host 副本，标记点链此后全 Host

### 3.3 §6.2 标定→扫描交接契约

> 这是全系统**唯一**的标定→扫描数据耦合点。代码契约定义在 `core/common/calib_result_types.h`。

| 标定产物 | 产出算子 | 扫描消费算子 | 数据类型 | 查表域 | 存储路径 |
|---|---|---|---|---|---|
| 温度补偿立体矫正表 | 3-5 `stereo_rectify_temp_table` | 标记点 `undistort_cpu` + 激光 `undistort_cuda` | `StereoRectifyTempTable`（map<double,StereoRectifyParams>） | **Host 内存**查表（`lookup(tempC)`） | DataStore(冷)→启动加载到内存 |
| 温度补偿激光面映射表 | 4-13 `plane_map_temp_table` | 激光 `laser_match_scan`（`SetTempTable` 注入） | `LaserPlaneMapTempTable`（map<double,LaserPlaneMap>） | **Device 显存**查表 | DataStore(冷)→启动上传显存 |
| 内/外参补偿表 | 5-1/5-2/5-3 | （已并入上两表，运行时不单独查） | `*CompensateResult` | — | DataStore(归档) |

补充说明：
- 两张表均按温度阶梯（默认 0.2°C 步长）预计算，运行时 `lookup(tempC)` 取最近温度条目，不抛异常（对齐算子规范 §9）
- 模块8 喂当前温度，扫描算子消费——温度是贯穿标定/扫描的一等轴
- 已知集成缺口：`LaserPlaneMap.leftToRightMap` 生产者尚未按契约产出，仅 JSON 路径当前可用（`calib_result_types.h:74` 标注）

### 3.4 §6.3 扫描数据流追踪（运行时热路径）

导读：扫描是运行时流式流程（180fps，μs~ms/帧），数据走热路径（HAL→DataPlane→Workflow skip-layer→Algorithm）。

**入口**（HAL→DataPlane）：
- 下位机硬触发 → 相机帧写入 DataPlane RingBuffer（☐待建）
- 灰度图双副本：Host 内存（供 CPU 标记点链）+ Device 显存（供 CUDA 激光链），免二次上传

### 3.6 §6.5 内存/显存流转图谱

#### 双副本投递机制
```
相机帧读入 RingBuffer 时：
  灰度图 → Host 内存 (cv::Mat CV_8UC1)     ──► 供 CPU 标记点链
        ↘ Device 显存 (GpuMat CV_8UC1)     ──► 供 CUDA 算子(mask/steger/...)
免二次上传；标定/扫描均遵循
```

#### 关键跨域转换点

| # | 位置 | 转换 | 数据 | 说明 |
|---|---|:---:|---|---|
