# 五链中间结果抽检转储（限量 1000 帧）· 设计

> 2026-11-03 人工发起。状态：设计已获口头确认，待实施。

## 1. 背景与目的

在线扫描调试（如激光飞点问题）需要在真机采集过程中，把**挑定的少数帧**的
五链全部中间计算结果留档，与离线回放工具（`09_OperatorLib/TEST/speed_optimize`
的 scan_replay）逐文件对拍。现有机制各有缺口：

- `config/fc_dump.json {"count":N}`：只存前 N 帧左右原图（FiveChainAdapter.cpp:1344）
- `JMW_FC_FRAME_DUMPS` 环境变量：逐帧位姿＋激光 PLY，但每帧都存、无挑选、不落中间步骤

## 2. 需求（人工确认口径）

1. **限量采集**：采满 1000 帧自动**只停采集**（灯灭、停投影、会话保活——
   等同再按一次 M 键；不走自动收尾）。
2. **挑帧落盘**：把第 **1、2、500、999、1000** 帧从**掩膜分离到融合**的
   全部中间步骤结果输出保存。
3. **开关**：主界面加「抽检转储」开关按钮（仿「模拟数据」开关模式），
   状态即时持久化到 `fc_dump.json`，**下个扫描会话生效**；默认关＝零开销。

## 3. 配置

`config/fc_dump.json` 扩展（与既有 `count` 字段共存）：

```json
{
  "count": 3,
  "probe": {
    "enabled": false,
    "maxFrames": 1000,
    "frames": [1, 2, 500, 999, 1000]
  }
}
```

- `enabled`：由界面开关维护（人工也可手改，重启生效）
- `maxFrames`/`frames`：人工编辑；帧号按**流水线处理序号**（1 起），与计算
  结果一一对应；积压丢帧极端情况下末帧可能未处理——可将 maxFrames 配 1005
  留余量，未命中的帧目录自然缺失并在日志注明

## 4. 落盘格式（对齐 scan_replay 沙箱，可直接离线对拍）

```

│  ├─ 0-binary.png             二值化前端全量前景
```

## 5. 实现要点

### 5.1 界面开关（app/MainWindow，编入 exe）

- 工具区加「抽检转储」toggle（与「模拟数据」开关同区同模式）
- 点击 → 调 AppContext 新接口 `setProbeEnabled(bool)`；AppContext 即时回写
  `fc_dump.json` 的 `probe.enabled`（读写集中在 AppContext 一处）
- 开关态在界面有可见指示；扫描中途切换不影响当前会话

### 5.2 限量停采（app/AppContext，编入 exe）

- 帧回调（AppContext.cpp:760 起，`isCapturing()` 分支内）加计数器：
  probe 开启时计数，达 `maxFrames` 调 `deviceManager_->stopCapture()`
  （灯灭保活，与 M 键停采同一收口），日志注明「probe 限量停采」
- 会话结束计数器清零

### 5.3 挑帧落盘（07_PipelineManager/fivechain，DLL 内部）

- **搬用沙箱 `artifacts.h/.cpp` 存盘工具箱**（PNG 叠加/CSV/PLY/JSON；
  依赖仅 OpenCV＋nlohmann/json，07 均已链接）——内部文件，不进公共头
- FiveChainAdapter 会话装配时读 `probe` 段（现有读 `count` 的机制推广）；
  运行期靠会话重装配刷新（与开关「下会话生效」语义配套，**不改公共头**）
- 各算子段出口加「帧序号命中集合则落盘」钩子（harness 层统一负责，
  **算子 09 零改动**）；仅在命中 5 帧时做 GPU→宿主拷贝与写盘，
  每帧产物几 MB 级，非命中帧零开销

### 5.4 契约与热更

- 07 改动全部在 DLL 内部实现（新增源文件＋内部钩子），**不动公共头**
  → 契约指纹不变 → 可用 `scripts/replace_dlls.ps1` 热换
- exe 侧改动（开关＋计数停采）需重编重启；改前关软件（运行锁 DLL）

## 6. 验证方案

1. **离线先行**：SimScanSource 回放 ≥1005 帧（probe 开、maxFrames=1000），
   检查：5 个 cycle 目录齐全、各步骤文件可读（PLY 进 CloudCompare、CSV 行数
   合理）、rt.csv 全程逐帧、1000 帧自动停采触发、会话保活可续
2. **开关语义**：默认关零文件产生；开→下会话生效；中途切换不打扰当前会话
3. **真机抽检**：一跑核 对在线产物与离线回放（同数据）逐文件对拍一致

## 8. 风险

- 生产线默认关＝零开销；开 probe 仅 5 帧写盘，对帧率影响可忽略（异步小文件）
- 沙箱工具箱按 Apache/内部代码搬用属同仓库移植，无授权问题
- 五链并行结构下个别步骤产物在 GPU 侧——命中帧统一在段出口拷回宿主再写，
  不改变算子时序
