    PCoreBroker b; b.start(2, {});
    std::atomic<int> inFlight{0}, maxInFlight{0};
    std::vector<std::future<Result>> fs;
    for (int i = 0; i < 20; ++i)

```cpp
template<typename T>
class SlotRing {
public:
    enum class WriterMode { Overwrite, Backpressure };
    SlotRing(size_t slots, WriterMode mode);
    // 生产者（P0 单线程写）。Overwrite：永不阻塞；Backpressure：满（writePtr-done>=slots）阻塞
    void write(SPtr<T> item);
    // 顺序消费者：原子领取唯一递增帧号（fetch_add）
    uint64_t claim();
    // 读任意帧号（槽被覆盖后仍持引用者安全；未写入→nullptr）
    SPtr<const T> read(uint64_t frameId) const;
    // Backpressure 模式：本帧消费完毕记账（done 计数）；Overwrite 模式空操作
    void done();
    // 顺序消费者等新帧（writePtr > frameId）或超时
    bool waitFor(uint64_t frameId, std::chrono::milliseconds timeout) const;
    uint64_t writePtr() const;  // 已写入总数
    uint64_t donePtr() const;   // 已消费总数（Backpressure）
};
// 内部：std::vector<std::shared_ptr<T>> slots_ + atomic<uint64_t> writePtr_/claimPtr_/donePtr_
//       + 写侧条件变量（Backpressure 用，与 donePtr 配对）
```

LaneHooks 按设计 §3.7（`gpuChain` 返回 false＝帧销毁；`onFrontReady`；`pChain`（Broker 执行）；`eFinalize(frame, front, result, future)`）。LaneRunner 主循环＝PREFETCH→gpuChain（acquire guard）→onFrontReady（若非空，先 submit pChain 拿 future；A 模式 onFrontReady 为空则此处才 submit）→等 future→eFinalize→发布（队列可空）→下一帧。`stopFlag` 原子检查点在每帧边界（grabs 前与 eFinalize 后）。

**测试用例（假钩子，GPU 用 Task 4 假工厂）：**
1. `E2E_AllFramesProcessed`：写 20 帧进 Overwrite SlotRing，2 lane 跑完 requestStop→drain，断言输出队列累计收到 20 帧结果（帧号集合无缺）。
2. `GpuChainFalseDropsFrame`：gpuChain 对偶数帧返回 false→输出队列只有奇数帧。
3. `ParallelFrontAndP`：gpuChain 须在调用 onFrontReady **之后** sleep 50ms 再记 T3（模拟激光链仍在跑）；onFrontReady 里记 T1、pChain 入口记 T2。断言 T1 < T2 < T3（ccl 就绪即提交、GPU 未完 P 核已跑）。无 sleep 则 T2/T3 完成序不定、用例 flaky。
