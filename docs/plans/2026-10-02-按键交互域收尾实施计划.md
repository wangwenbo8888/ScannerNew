## P-1：全局 10 态门禁注入（#3）

**问题**：gate 闭包现仅拦自检期；S3 标定/S6 后处理/S7 故障三态按键漏进。

**方案（A＋AppContext 白名单，已与用户对齐）**：
1. `DeviceManager::setKeyStateGate(std::function<bool()>)`——setter 注入「当前全局态允许按键吗」谓词（未注入＝放行，兼容单测）
2. 闭包组合：`gate(类别) = 自检中 ? 拦 : (谓词 ? 谓词() : 放行)`——类别维度四类同判（矩阵门禁层无差异，功能口细分）
3. AppContext 装配处注入白名单：`状态 ∈ {S2 Standby, S4 扫标点, S5 标点+激光}` 放行
4. 逃生类不问 gate（已实现，不动）

**文件**：`DeviceManager.h/.cpp`（setter＋闭包组合）、`AppContext.cpp`（注入）、`test_device_manager.cpp`（注入谓词拦/放 2 用例）

**验证**：注入 false → 四类手势全丢弃（逃生类照常）；注入 true → 行为不变。

## P-2：显示远近档→03 显示端（#6）

**问题**：p1=112 事件已发，无消费者——显示远近档按键空转。

**方案**：AppContext（或 MainWindow）订阅 p1=112 → `OSGWidget` 摄像机按档值拉远/拉近。5 档映射：以当前 home 距离为锚，档 i → 距离 × factor[i]（占位 `[1.0, 1.5, 2.2, 3.2, 4.5]`，产线对账后替换）。快照兜底：UI 启动时读 `distanceLadderIndex()` 对齐。

**文件**：`AppContext.cpp`（订阅接线）、`OSGWidget.h/.cpp`（`setViewDistanceLadder(int idx)` 口）

**验证**：按键换档 → 3D 视图摄像机距离即时变化；重启后档位保持（档号内存态，不落盘——§7 持久化范围待确认项）。

## P-3：顶部大字横幅（#1）

**方案**（§3.4 形态）：
1. `MainWindow` 顶部全宽条带控件（半透明底/高对比大字/≤10 字短语＋方向符号/不遮中央预览）
2. 节奏：停留 1.8s 自动消失，新提示顶掉旧；红＝失败/急停，绿/白＝中性
3. **菜单期常驻**（p1=110 驱动）：进菜单显示 `菜单 ▸ ③ 扫描完成`，游标动即刷新；①子态显 `体素密度 第 N/M 档`；⑤子态红底 `再按中键确认重置`；瞬态反馈插入显示、结束自动恢复常驻
4. 订阅事件族渲染：111-114（`亮度 ▲ 第 5/20 档`/`景深：远`）、120+（拒因，红底）
5. P8 分源：DM 事件＝按键来源→横幅；UI 控件操作→statusBar 本地提示（天然分流）

**文件**：`MainWindow.h/.cpp`（横幅控件＋订阅）、`DeviceManager.cpp`（功能口拒发 p1=120+ 拒因码——把现有 JMW_LOG 拒点补事件）

**验证**：按键调档/切景深/进菜单/⑤确认/急停横幅逐场景过；菜单期瞬态后恢复常驻。

## P-4：景深屏蔽＋体素密度→07/09（#4/#5）

**方案**：
1. **通道**：AppContext 订阅 p1=113/114 → 经 `WorkflowContext`/`PipelineDeps` 注入 07 ScanPipeline 会话参数（`depthOfField`、`voxelDensityMm`）——装配期读 DM 快照＋运行时事件热更
2. **景深（#4）**：`ScanChains` 激光链按近/远取屏蔽区间（视差/Z 范围过滤）——区间数值〔外部依赖〕先用占位 `近 [200, 800]mm / 远 [800, 2000]mm`，常量集中在 07 一处便于产线替换
3. **体素密度（#5）**：融合累积器（`laser_cloud_fuse`）体素尺寸参数化按档取值；换档重算＝**待机改档下次会话生效**（防呆已拦采集中改档——不做会话中热重算，规避重算风暴）
4. 档值快照口：DM 侧 `voxelLadderValue()`（档值 mm）供装配读取

**文件**：`AppContext.cpp`、`WorkflowContext.h/.cpp`、`ScanPipeline.cpp/.h`（会话参数）、`ScanChains.cpp`（屏蔽区间）、`laser_cloud_fuse` 算子（体素参数化——算子契约已有参数则只接线）

**验证**：07 现有 e2e/单测绿＋新增「双景深过滤」与「双密度档」各 1 用例；占位区间常量处标 `〔产线对账〕`。

## P-5：UI 预设档滑条收敛（#2）

**方案**（§3.4 双向对齐）：
1. **DM 写入口**：`setBrightnessLadderIndex(int idx)` post 编队（UI 换档请求——与按键同梯同账；越界钳制）
2. **ScannerWindow**：bg/laser/exposure 三滑条＋数值标签 → **一根 20 档滑条**（离散刻度、松手提交终值 P6）＋三参只读显示；频率已移除（P0 完成）
3. **MainWindow**：`m_param1Slider` 比例旋钮＋自由/推荐/自定义页签 → 同一根 20 档滑条＋只读三参（预设按钮族收敛为「按当前档映射」——applyMeshPreset 等改走 `setBrightnessLadderIndex(10)` 面片推荐档）
4. 回显阻断（P5）：滑条由事件 111 驱动刷新时 QSignalBlocker，防环路
5. 快照兜底：两窗口启动读 `presetLadderIndex()` 对齐

**文件**：`DeviceManager.h/.cpp`、`ScannerWindow.ui/.cpp/.h`、`MainWindow.cpp/.h`

**验证**：按键调档↔滑条拖动双向同步（同梯同账）；绕滑条直改三参路径全数移除（grep 无 `setValue("exposure"...)` UI 来源调用）；P6 松手提交拖动中仅预览。

## P-6：换档事务性＋只落档号（#7/#8）

**方案**：
1. **只落档号（#8）**：G7 落盘格式改——`device_params.txt` 增 `brightLadder=N` 段、剔除三参段（exposure/laserLevel/bgLight 不再落）；开机读档：有档号 → `setLadder` 档号展开三参（Source::Boot）；旧档兼容：读到旧三参段则按最近档吸附（过渡期一版）
2. **事务性（#7）**：换档两段＝三参写账（相机直设＋N10 组参）→ 全部 confirmed 才提交档号广播 111；任一失败＝档号回弹＋p1=120 拒因事件。实现：ParamStore 既有 confirmed 链＋`pendingLadderIdx_` 在途记账（后值胜出：在途再来换档请求覆盖 pending）

**文件**：`DeviceManager.cpp`（落盘/读档/在途档号）、`ParamStore` 不动（用既有 confirmed）

**验证**：改档→断言落盘只含档号；模拟下发失败（mock 拒 N10）→ 档号回弹＋拒因事件；并发连按两档 → 终值＝最后一档。
