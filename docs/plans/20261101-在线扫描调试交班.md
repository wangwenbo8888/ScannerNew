#### 未解决的问题（在线扫描不产 3D 点）

**根因已定位（离线 vs 在线逐步对比实证）**：

```
步骤                离线                 在线
原图灰度            P50=85 P90=171      P50=67 P90=103   ← 在线暗 20-40%
直接阈值200          30 个 ≥800px         29 个 ≥800px     ← 都可检出！
分离 binary          47 个 ≥200px         59 个 ≥200px     ← 都有！
分离 survivor        13 轮廓 11 ≥800px    21 轮廓 0 ≥800px ← 在线标志点更小
分离 marking_mask    13 轮廓 11 ≥800px    21 轮廓 0 ≥800px ← 同上
CCL minArea=800      11 个通过            0 个通过        ← 全滤！
CCL minArea=200      —                   15,202 个通过    ← 但 99% 是噪声
ellipse             det=9~12            det=1           ← 只留 1 个真标志点
conic               有效 8~10            有效 0           ← 标定不匹配
```

**三层瓶颈**：
1. **分离产出质量差**：在线标志点掩膜组件 200-600px（离线 800-1050px）→ 800 门槛全滤。降到 200 后 99% 是噪声
2. **标志点检出率低**：det=1（离线 det=9）→ 不够配准（需 ≥3）
3. **conic 重建失败**：VirtualPlane → 标定坐标系与在线相机不匹配

**根本原因**：在线图像像素特性与标定数据不匹配（P50 差 20, P90 差 70）
