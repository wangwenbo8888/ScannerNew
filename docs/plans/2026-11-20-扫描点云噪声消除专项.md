## 1. 噪声类型学（已证实的机制）

| 类 | 名称 | 形态 | 产生机制 | 可否在线消除 | 可否离线消除 |
|---|---|---|---|---|---|
| A | 杂散反射飞点 | 孤立点/小簇，离面几 mm~几十 mm | 激光多次反射/边缘衍射产生的错误观测 | SOR/孤立门可拦大半 | ✅ SOR+min-weight 拦截 |
| B | 双线交叉误匹配浮层 | 成层，261119 数据中系统位于 ±6.5mm；历史形态近层 ~257 / 远层 ~445-480（devZ 提交实测） | 激光线 ID 交叉配对→错误视差→错误三角化 Z | devZ 带门拦带外层；**带内（±40mm）拦不住** | ✅ min-weight+carving 拦单帧孤证层 |
| C | GBA 位姿系统残差 | 表面整体粗糙/波纹（不是悬浮点） | 各帧位姿同向偏差（corr_mm 中位 ≈0.85~1.3），多帧平均不归零 | ❌ 上游平差问题 | ⚠️ TSDF 只能平滑（trunc 加宽），不能恢复 |
| D | 配准失败帧缺数据 | 无点（非噪声，是空洞） | 有效标志点 <4 → 位姿解算失败 → GBA 导出剔除（261119 数据 399 帧剔 96 帧 = 23.7% 点） | 上游标志点可见性问题 | ❌（数据不存在） |
| E | **261120 新形态（未定性）** | 3~12 点小簇悬浮于表面外 **5~40mm**（中位 17.4mm），沿整个行程均匀分布，避开物体核心带 | 指纹＝错误视差三角化；**上游误匹配率上升，根因未定**（见 §5） | 现有四门结构性漏杀（见 §3.2） | ✅ 离线 SOR 可拦 |

剖析口径：SOR 外点 = kNN(k=16) 平均距离 > 帧内均值+2σ；离面层 = 逐帧 PCA 平面残差 > 5×1.4826×MAD 后聚类。

### 2.2 同口径对比（融合云 vs 融合云）

| 指标 | 导出 ① `gba_cloud` | 导出 ② `pointcloud` |
|---|---|---|
| 点数 | 1,691,082 | 70,843 |
| SOR 外点率 | **2.18%** | **4.38%** |
| 外点离主体距离 | 中位 **1.2mm**，90.6% <5mm（贴表面的良性粗糙/边缘点） | 中位 **17.4mm**，**86% 悬浮 5~40mm** |
| 形态 | 无成层结构 | 全域雾状小簇（3~12 点，~1mm 级簇径），z 直方图避开物体核心带（350~380mm 空缺），两侧 200~350 / 390~510 均匀铺开 |
| 物体 z 带 | 282~342mm | 333~393mm（摆位/对象与 ① 不同） |

结论：**②的恶化是真实噪声，不是统计口径差异**；指纹指向错误视差三角化（E 类）。

### 2.3 导出 ① 的逐帧基线（261119，四门构建前）

- 全程 SOR 均值 ≈1.5%；前半段（帧 0~208）离面噪声 0.05~0.15%（背景级）。
- **后半段（帧 221~377）爆发 ±6.5mm 连贯浮层**（B 类）：单帧 200~750 点（如帧 299：+6.7mm×758；帧 247：−6.4mm×448）。
- 位姿口径已验证：`gba_poses.csv` 为 camera-to-world、毫米；判别依据=逐帧工作距离散度（c2w 0.111 vs w2c 0.204）+ 传感器 x 与帧质心 x 相关 +0.981。

### 2.4 配准失败帧（D 类，导出 ①）

96 被剔帧 vs 303 保留帧的 report.csv 指标：有效标志点中位 **2 vs 6**、配准匹配数中位 **0 vs 5**、激光点数相近（25.5k vs 25.9k）→ 剔除原因是**位姿不可解**而非激光质量；找回须上游改进标志点可见性。

### 3.2 对 E 类（261120 形态）的漏杀分析（结构性，非 bug）

| 门 | 为什么拦不住 5~40mm 悬浮小簇 |
|---|---|
| devZ ±40mm 带 | 浮点在带内 |
| ③ 空间孤立（5mm 格≥2 邻居） | 3~12 点小簇自带邻居 |
| ① 视差一致性（行内 MAD） | 成片错配在行内局部自洽 |
| ⑤ 平面残差门 | 逐帧激光条纹是细长曲线，平面拟合病态（法向不定）→门不稳 |
| ② 左右互检 | 默认关；且反查表依赖 CMTT 表质量 |

**关键推理：所有门只能删点、不能造点**——外点率 2.18%→4.38% 的翻倍必然来自**上游误匹配率上升或场景变难**，与防线无关；防线最多解释"为什么没拦住"，不能解释"为什么变多"。

## 4. 离线 TSDF 后处理方案（已建成，导出 ① 验证有效）

### 4.1 工具链（仓库外，路径固定）

| 件 | 位置 |

| 一键脚本 | `C:\devlibs\vdbfusion-demo\run_tsdf.ps1`（拆帧+SOR→TSDF→网格→表面点→预览图） |

### 4.2 参数标定（绑定当前 GBA 精度 corr_mm≈0.85）

```
SOR k=16 σ=2.0（拦截 ~1.5% 飞点）→ voxel 0.5mm → trunc 2.5mm(=5×voxel，须>2×(单帧σ+corr_mm))
→ min-weight 2 → carving on
```

调参口诀：先治悬浮（SOR/min-weight/carving，零细节代价），后治粗糙（trunc，有代价）；trunc 拉到 3mm 仍糙 → 是 C 类位姿残差，参数到头，回上游。

### 4.3 导出 ① 实测效果

| 版本 | 顶点 | 备注 |
|---|---|---|
| 基线（min-w 0.5 无 carving） | 109 万 | 有 A 类飞点 |
| **SOR+min-w2+carving+trunc2.5（推荐）** | **100 万** | 飞点消失、细节保留，✅ 用户验收"降噪效果可以" |
| min-w8+carving+trunc4（过强） | 61 万 | 误杀细窄特征，弃用 |

## 5. 未决问题 → **261120 晚已裁决**（逐帧转储取证）

三候选中 R2（场景）与 R1（绕过防线）先后排除（进程为 Release 版、系统无 JMW_* 环境变量、板同昨天）。261120 为 fc_executor 加装 `JMW_FC_NOISEDUMP` 逐帧转储（过门前 2D 匹配对/过门前 3D 点/各门杀点账本+位姿），复扫 470 帧取证：

### 5.1 裁决结果：**上游激光匹配失败（错线配对＋产量崩塌），非防线/融合问题**

| 证据 | 数据 |
|---|---|
| 帧产量崩塌 | e0 中位 **177 点/帧**（正常 ~26000）；仅少数帧达 2.2 万+；后半段会话（帧 253+）全面崩到 200~400 点/帧且视差全程散乱 |
| 好帧是干净的 | 2.2 万点帧：离面层 0、2D 误配 0.00%、SOR 2~3%（优于 261119 基线） |
| 错线配对指纹 | 坏帧 3~4% 匹配对视差聚在 **[-1200,-950]**（正常 -528~-412）——偏移＝一根激光线的量化间距；三帧一致双峰 |
| lid15 异常 | 误配点 850 中 757 来自 lid15 |
| 与 261115 事故同指纹 | 「误匹配散点＋正点不显示」＝当日 CMTT 温表出范围（帧温 35~40℃ vs 表 ~22℃ → uR 预测偏）的实锤症状 |

### 5.2 防线在该形态下的表现（转储账本）

- G1 视差一致性：465 帧**零击杀**——对量化错线偏移（行内自洽）无效，设计与实现需复审
- devZ 带门：195 帧中位杀 **45.6%**（P90 83%）——帧本已半空、中位 Z 不稳，**从防线退化成产量杀手**
- G3/G5：≈零击杀；G4 时域支撑：中位杀 16.8%（在坏帧上雪上加霜）
- 总杀率 e0→eEnd = 50.14%，但杀的都是半空帧残余——对根因无效

### 5.3 修复方向（按优先级，交上游）

1. **恢复匹配产量**：核查 CMTT/温表谱系（`2196b69` 撤表 + `JMW_FC_LMTEMP` 22.5℃ 固定档 vs 实际帧温）与 uR 查表预测偏移——261115 同型事故的修复路径可复用
2. **lid15 专项**：单线异常集中（757/850），查该线 uR 表行/亮度/遮挡
3. 匹配修复前**暂停 devZ 与 G4**（对半空帧具破坏性），避免产量进一步损失
4. G1 复审：按 lid 分组的行内 MAD 无法捕量化错线偏移，需改为跨 lid 的同 row 视差聚类或直接对 |disp−行趋势| 设物理上限（如 >1.3×正常带宽即杀）

### 5.4 取证工具（随本专项沉淀）

- 转储开关：`JMW_FC_NOISEDUMP=<dir>`（fc_executor `[261120 noise-dump]` 标记；默认关零影响）
- 分析脚本：`C:\devlibs\vdbfusion-demo\analyze_noisedump.py`（账本漏斗/3D 剖面/2D 误配指纹）、`lid_forensics.py`（线号视差深挖）

## 6. 下一步建议（按优先级）

1. **裁决 §5 三候选**：先答 R1（零成本），再决定是否复扫（R2）/完整导出（R3）。
2. ⑤ 门几何病态修复建议：平面拟合改为**条纹主曲线拟合**（沿条纹方向的 2D 弯曲模型），法向由标定先验给出而非逐帧估计。
3. E 类若确认源于误配：评估 ② 左右互检转正（`JMW_FC_BICHECK=1` 真机验证）＋ lid 门映射收尾（`bc79634` TBD 项）。
4. B 类带内浮层：devZ 带门对 ±6.5mm 层无效，靠 min-weight 式多帧票数思想在线化（融合格子票数门槛，现有"融合格子存储升级候选"问题池条目可合并推进）。
5. C 类根治在上游：GBA 平差精度（corr_mm 0.85→更低）后，trunc 可收窄、细节提升（离线参数联动调整）。
6. D 类：标志点布设/打光改进（96 帧配准失败，仅 2 个有效标志点）。
