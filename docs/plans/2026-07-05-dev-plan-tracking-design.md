## 3. 文档骨架

```
1. 文档说明（目的/读者/维护方式/快照日期）
```

## 4. 每模块固定六字段模板

```
## M0X 模块名  [状态徽章]
- 目的与职责（一句话 + 主层归属）
- 参考资料来源（3DSCANNER 源码/算子文档/ADR/外部库/硬件规格）
- 依赖关系（前置 framework 层 / 其他模块 / 外部库）
- ✅ 已完成（具体项）
- ⬜ 待办（3-7 个里程碑任务，可勾选 [ ]）
- ⚠ 风险/待决策
```
