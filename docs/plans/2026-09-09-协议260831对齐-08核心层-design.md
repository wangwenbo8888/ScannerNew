## 1. serial 层

- **FrameCodec**：删 `Version` 枚举/V3 分支/CRC 查表/`Frame.seq`；底座＝现 V2 `;` 分帧，载荷放行空格；**保留 50ms 半帧超时**（advanceTimeout）
- **McuFrame**：
  - 删 `RawKeyEvent/StatusFrame/AckFrame/parseKeyPayload/parseStatusPayload/parseAckPayload`
  - `TempFrame`：`celsius[4]` 恒 4 路，删 seq/channels
  - 新增 `GestureEvent{KeyId key, uint8_t gesture(1/2/3), TimestampMs ts}`、`ShotCountFrame{uint64_t count}`
  - 新增 `parseG01("G01 U1") / parseG02("G02 A25.3 B25.4 C26.0 D24.5") / parseG03("G03 S500")`
  - `SpscRing` 原样保留
- **CommandChannel**：删 ACK 挂表/重传/3 败收口/组链 seq/表容量逐出（约 80%）；退化为「encode＋入写队列，同步回告写成败」；`sendFireAndForget` 成唯一发送形态

## 2. IMCU / MCUDriver

- 命令面缩为 4（typed）：
  - `setCaptureParams` → `N10 H<1-200> B<0-100> T<0|1> V<0|1> C<0|1> D<0|1> L<0-100>`（参数间空格）
  - `stopScan` → `N11 H0`
  - `setTempReportPeriod` → `N12 T<5-1000ms>`（新增）
  - `setHeatTarget` → `N13 S<0-80>`（入口钳制）
  - 删：startScan(N11H1)/自检×2(N12Z)/待机×2(N13E)/queryTemperature(N15)/标定×2(N16B)
- `CaptureParams` 改七字段（H/B/T/V/C/D/L）；`McuUplink{onTemp, onGesture, onShotCount}`
- `dispatchFrame` 按 `G01/G02/G03` 前缀三分流：手势环 64 / 温度环 8 / 计数环 64；ackRing/seq 对账体（B8）/E 帧/回显遗迹（lastEcho_/probeN12Sent_/sendEchoProbe/feedTextLine 数值行）删
- **探测机制重造**（旧凭据＝固件整帧回显，新协议无回显）：逐口发 `N12 T100` → 300ms 内收到任意 G 帧＝命中（N12 即开温度上报，G02 到达为链路活凭据；纯回环线不回 G 帧不误命中）
- 启动自检：mcuLink 项改「G02 到达」；bgLight/laser 闪灯项改 **N10(H5 低频短采)→N11 H0 包裹**（新协议 N10 即启采，无独立灯控）
- 线程模型不变（rx 线程＋写线程＋逻辑线程 pump）

## 3. DeviceManager 编排

- open：自动搜口（N12 T100 探测）→ N12 T100 生效；close：N11 H0＋**复位 ModeController 黑板/capturing**（D8）
- 启采＝单发 N10（H=账本频率）；停采＝N11 H0；**采集中改参＝全参重发 N10＋warn 日志**（D1）
- 待机/标定＝纯软件态：`toIdle`/`enterCalibration` 删命令步只落板（D2）
- 预热：`startWarmup` 发 `N13 S<target>`（钳 0-80），3 败 detail 串 `N13S`；看火喂 celsius[0]（D3）
- 删：logicTick 的 channelTick ④/N15 兜底 ⑥/v2 常量；`DeviceConfig.protocol/ackTimeoutMs/seqGapWarn` 删
- 恢复路径（D8）：open 重发 N12＋按当前模式重同步 N10 参数；lastTemps_ 清零

## 6. 故障对表＋恢复路径

- 0x0802 串口静默：武装门 `lastRx>0` 改 **open 时刻武装**；判据按 `N12周期×倍数` 自适应
- 0x0804 温度乱跳：判据改**绝对差值**（去上报周期敏感——G02@T=5ms 时 1LSB 抖动＝20℃/s 必风暴）
- 0x0808 seq 跳变：码位闲置（G03 对账为后续新增功能，D6）
- 0x0806 挂手势环溢出；0x0807 缩义「串口写失败」，detail 串全换新命令名
