# 调试计划 · 扫描链路模拟数据调通（流水线出口数据 → 融合 → 3D 显示）

> 日期：2026-09-13 · 任务口径：**无硬件**，构造**模拟数据集（标志点＋激光点云）**，经**模拟数据输入模块**按扫描节奏逐帧取出（标志点整体移动、激光点逐点微抖）＋模拟 R/T，注入**真实融合→显示下游**，调通「流水线出口数据 → 体素融合 → 3D 窗口显示」。
> 范围＝FrameResult 出口之后（配准结果为模拟给定）；**不含**图像级三链算子、出口查表、光流配准、GBA、08 真机、后处理网格、编辑。

---

## 0. 验收标准（可判定）

1. **数据级**（headless ctest）：恒等 R/T 首帧冒烟后，N 帧序列注入——标志点融合云点数**恒==数据集标志点数**（体素去重稳定）；激光融合云 >0 且点数**有界趋稳**（抖动 σ < 体素分辨率）；R/T 正确（融合云形状==全局场景布局，不镜像不发散）。
2. **UI 级**（scan_demo）：模拟入口点「面片扫描」→ 3D 窗口标志点（同心圆盘，位置稳定）与激光点（浅蓝小点，云层渐厚）逐帧可见；日志链全通（§2）；停止 → 排空、合账落库（「点云数据 001」计数=激光融合云点数、markers 通道==标志点数）。
3. **核对**：`markers_snapshot.ply` / `laser_snapshot.ply` 导出并经「文件导入」重载，与数据集几何一致。

## 1. 注入设计（核心决策）

**注入层级＝FrameResult（流水线出口元素）**，不是图像级：

```
模拟数据集(JSON)                    真实下游（不改一行）
┌──────────────────┐    FrameResult{frameId, R/T,   ┌──────────────────────────┐
│ 标志点 N≈30(全局系) │──▶ markers, laser(GpuMat)}──▶ │ 07 FuseConsumer(真)       │
│ 激光点 M≈5k-2w(全局系)│    （推入 pipeline.output    │  ├ marker_cloud_fuse_cpu  │
└──────────────────┘     │    Queue()，MPMC 公开口) │  ├ laser_cloud_fuse_cuda  │
        ▲                │                          │  └ 30fps 节流推送         │
┌──────────────────┐     │                          └────────────┬─────────────┘
│ SimScanSource    │─────┘                                       ▼
│ · G_k 轨迹(整体移动)│                          SceneFeedAdapter(真)→queued→MainWindow
│ · markers=G_k⁻¹·M │                          →OSGWidget loadMarkerPoints/loadLaserPoints
│ · laser=G_k⁻¹·P   │
│   ＋逐点抖动σ可配  │
│ · R/T=G_k(设备→全局)│
└──────────────────┘
```

- 依据：任务口径即「从扫描流水线**出来的数据**」起调；FrameResult 是 07 出口元素（ScanTypes.h:50），`ScanPipeline::outputQueue()` 公开（ScanPipeline.h:87，MPMC 队列），`markerFuse()/laserFuse()` 公开可断言（ScanPipeline.h:92-96 / ScanWorkflow.h:94-97）。
- FuseConsumer 消费逻辑零改动：真融合（marker CPU 体素哈希＋laser CUDA 体素哈希＋法线）、真节流（每 5 帧）、真 SceneFeed 推送全走原路。
- 坐标约定：markers/laser 为**设备系观测**（＝全局场景经 G_k⁻¹ 变换），fuse 用 R/T=G_k 变回全局系——与真实链一致（FuseConsumer.cpp:103/109 `fuse(markers, R, T)`）。方向若弄反，首帧恒等冒烟立即暴露（云发散/镜像）。

## 4. 缺口与方案（新做的东西）

### G1 合成标定仓库（前置，P0）
- **为什么还要**：app 侧 `startScanSession`→`assemblePipeline` 仍走真装配：`session_.assemble(repo)` 两表全空→fail；激光表缺→enableLaser=false→**激光融合整段跳过**（FuseConsumer.cpp:108 `laserFuse && fr.laser`）。
- **方案**：`config/calibration.json`＋`laser_calib.json` 合成版——两表各**单档 25℃**，**只需格式合法**（本注入路径不经 laser_match_scan 几何，无自洽性要求——原计划最大风险 R2 就此消除）；K/D/R1R2P1P2/Q 取理想值。备份现有文件。
- **验证**：装配日志`激光温度表装载: 1 档`＋`readyForScan` 过门。

### G2 模拟数据集（P1）
- 单 JSON 文件（`config/sim_scan_data.json`，或 tools 生成）：
  - `markers[]`：N≈30，全局系 xyz＋法线＋半径＋globalId（0..N-1）；布局=面板网格＋少量离群（约 200×200mm 范围，间隔>体素分辨率×3）；
  - `laser[]`：M≈5000-20000 xyz 平铺；布局=平面/浅圆柱面片（模拟面片扫描的表面采样）。
- 附最小生成脚本或手写固定场景（固定 seed 可复现）。

### G3 SimScanSource 模拟输入模块（P1 核心）
- 职责：加载 G2 → 按帧序产 FrameResult：
  - 轨迹 `G_k`：小步长刚体递增（如 0.3°/帧旋转＋0.5mm/帧平移，**整体移动**）；
  - `markers_k = G_k⁻¹ · M`（标志点无逐点噪声——体素去重后点数恒定的对照组）；
  - `laser_k = G_k⁻¹ · P ＋ jitter`（**每点微小抖动**，高斯 σ 可配，默认 σ=0.02mm < 体素分辨率→融合云趋稳；调大 σ 可演示体素滤波膨胀）；
  - `R/T = G_k`；laser host→`cv::cuda::GpuMat`(CV_32FC3 1×N) 上传为 `GpuPointCloudBlock`（池外直构，FuseConsumer 只读 `points/count`）；
  - 节奏：QTimer 33ms（30fps）；帧号递增。
- 位置：`modules/07_pipelinemgmt/pipelines/scan/` 旁或 tests 公共头（headless/app 双端复用——倾向 `tests/sim_scan_source.h` 起步，app 引用同头；若 app 侧需要正式化再升模块）。

### G3a headless 数据级测试（P1）
- 新 ctest exe `test_scan_sim_frameflow`：
  1. **恒等冒烟**：单帧 G=I 注入→断言融合云==数据集原样（钉 R/T 方向约定）；
  2. **标志点恒等性**：N 帧轨迹→`markerFuse()->fusedPoints().size()==N_markers` 恒定；
  3. **激光趋稳**：`laserFuse()->fusedPointCount()` 单调增至有界上界（σ<体素）；
  4. 假 `ISceneFeed` 记录：`pushCloudSnapshot` 被节流调用（首帧＋每 5 帧）、hostMarker/hostLaser 指针内容合法。
- 结构：真 `ScanPipeline`（attachTestHooks 装三 no-op 钩子——lanes 空转不产帧）＋真融合适配器＋G3 注入 `outputQueue()`。

### G4 app 模拟入口（P2）
- `AppContext::startScanSession` 模拟分支（默认关闭，环境变量 `JMW_SIM_SCAN=1` 启用）：
  - 跳过 `isDeviceReady` 门禁与 08 `startFrameStream/startCapture`；
  - QTimer 喂 G3 产出的 FrameResult → 需 02 侧小改：`ScanWorkflow` 增 `FrameResultQueue<FrameResult>* outputQueue()` 透传口（对齐既有 `obs()` 附件模式，约 3 行）；
  - 停止顺序铁律：**先停 QTimer 再走 stopScanSession**（防 push-after-stop 竞态；consumer drain 语义保证已推帧全部融合完）。
- 原则：无环境变量时行为与现状完全一致（零影响）。

### G5 核对流程（P2）
1. 跑 scan_demo（Release）→ 模拟入口点「面片扫描」→ 盯 §2 日志链；
2. 3D 窗口：标志点圆盘位置稳定、激光云渐厚；中途暂停/恢复一次；
3. 停止 → 工程树计数==仓库真值；PLY 导出/导入核对几何。
