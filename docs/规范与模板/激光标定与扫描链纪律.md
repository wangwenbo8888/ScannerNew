# 激光标定与扫描链纪律（261107~261108 战役沉淀）

> 来源：两天战役全部事故与教训的提炼。违反任何一条都已在真机上付出过代价（附证据）。
> 收录位置：本文件为纪律正文；《开发进度.md》261107/261108 为过程档案；`docs/plans/2026-11-08-换机激光标定战役全记录.md` 为全文。

## 一、数据纪律

**D1. 标定完成前禁止关闭 factory_calib GUI**
关窗自动清空 data_in 图像。已两度丢失过门主力帧（261108 左斜 pose_67/85/86/89/92 永久丢失）。过门帧应在标定时立即安全拷贝到独立目录。

**D2. 单批纯数据，禁止跨批次混标**
不同批次亮度条件不同，混标互相拖累——261108 精细实测：混集 A6 7.92 vs 新批单独 1.60（差 5 倍）。

**D3. 网格化采集，不随机摆板**
深度×偏航×俯仰网格覆盖。随机批过门率 54~80% 且弱帧多；网格批 88% 且约束均匀（A6 14.6→1.6）。

**D4. 环境光是隐形杀手**
标定采集背景灰度目标 5~25（右斜 PASS 批 14~19）。背景 55 vs 14 的差＝rms 7.2 vs 0.12 的差。补光先归零，环境遮光是唯一解。

**D5. 拍前确认强观测**
带/线亮且连续（不是断续虚线）才拍。弱帧（出点<2000）在 PJC 被剔除等于白采；混入会拖累位姿。

## 二、标定纪律

**B1. PJC 标定必带 initialT，弱数据集先跑盆地网格**
自由收敛会掉错误盆地（精细 z=-88.9 rms 12.4 实证；左斜 z=-1.5 漂移）。initialT 用同机/同管已证深盆地解。盆地勘探用 `tools/calib_pjc_grid.py`。

**B2. 门禁硬等值不可放开（expectedLineCount）**
261108 放开实验：17 ok 但 rms 19.5（脏线毒化 PJC）。门禁高拒绝率（20~25%）是设计——过门帧质量>数量。

**B3. 弱观测帧用 minPointsPerPose 剔除，不做物理挑帧子集**
物理子集目录与全量同帧门禁结果不同（枚举序玄学，两度实证）。config 层剔除（mpp，精细定稿 100）安全有效。

**B4. 过曝无下限，只有上限（≤5%）**
过曝低不是问题（线亮由线数指标反映）；上限防粘连扩散。曾因「追过曝下限」过度拟合成功案例。

**B5. 标定提取器与实扫提取器必须同源同参（口径契约）**
标定 steger/实扫 flat 的口径断裂是精细匹配全灭的根因。改任一侧提取器必须同步另一侧（参数逐字一致）。

## 三、代码纪律

**C1. 09↔fc 任一侧改动当日回传同步**
261107 事故：flat 行模式修正三轮只改 fc 拷贝，主工程跑初版算子恒 0 点，浪费一整轮真机验证。

**C2. 运行期算子参数切换必须双实例，禁止 SetParams 在飞切换**
SetParams 重置 warmup/buffer 与在飞帧竞态（0xC0000005）；waitForCompletion 会打断 marker 图事务（conic 崩灭）。终版：每形态一个恒参实例＋纯选路。

**C3. 跨链禁止直接抄参数**
标定链与扫描链算子语义不同（ccl.minArea 2500 在标定链杀噪声、在扫描链杀标志点圆）。参数移植必须验证两链语义。

**C4. 算子参数有边界，越界值先查约束**
noiseErodeSize=1 无 kernel 档（下限 3）→ Bad erode 启动失败。改参数前查算子 validate()。

**C5. GUI/工具排障改动必须带轨迹日志**
自动调节的 [autoTune] 逐决策日志是定位「调不到位」的唯一手段。无日志的自动化是黑盒。

## 四、验证纪律

**V1. 重跑标定结果不同＝盆地漂移，不是玄学**
同一数据不同次跑 PJC 可收敛不同盆地（帧序/多级路径敏感）。重跑前固定 initialT。

**V2. 表质量看 rms＋A6；A7 是复现性不是误差**
A7 高说明「不用锚定会漂」，不说明部署表误差大（initialT 锚定后解确定）。绝对位置精度看 A6（<2.0 达标）。

**V3. 部署前用已知物实测**
标定板尺寸已知——扫描一次量点云实际尺寸/位置偏差，量化真实影响后再判断可否部署。
