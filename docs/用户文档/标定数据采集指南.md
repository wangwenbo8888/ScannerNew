# 激光标定数据采集指南

> 适用：换机/换管后的激光标定数据采集（左斜 T／右斜 V／精细 D／深孔 C 四管通用）。
> 目标读者：标定操作员。按本指南采集，标定一次通过率最高（右斜批 26 pose→PASS 实证口径）。
> 2026-11-08 整理——两天实战（左斜 12 轮＋精细宽带战役）的全部经验教训。

---

## 一、采集前 3 分钟准备

### 1. 环境（最重要——比任何参数都重要）

| 项 | 要求 | 为什么 |
|---|---|---|
| **环境光** | 越暗越好（拉窗帘/关灯/遮光） | 背景灰度每高 10，线对比度掉一档；背景 55 vs 14 的差就是 rms 7.2 vs 0.12 的差 |
| **补光档** | **先归零** | 背景高的第一嫌疑人；标定不需要补光 |
| 标定板 | 干净、无反光斑、平整 | 板上亮斑会被误判为激光线 |

### 2. 打开 factory_calib GUI → 采集页

1. 打开相机预览
2. 右上「目标线数」填对：**左斜/右斜 = 25，精细 = 7，深孔 = 1**
3. 看右侧「采集参数判定」面板

## 二、调参（两种方式任选）

### 方式 A：自动调节（推荐）

放好标定板 → 确认预览里能看到激光线 → 点「**自动调节**」按钮。

系统自动步进调整（每步约 1 秒）：
- 背景高 → 自动降背光 → 降曝光 → 升对比度
- 过曝高 → 自动降激光
- 线太暗 → 自动升激光 → 升曝光

**出现绿色「✅ 调节完成，可以采集」即成功**。
若提示「到达档位边界仍未达标」→ 转方式 B 手动，或检查环境遮光。

### 方式 B：手动（参照面板三项指标）

| 指标 | 绿灯条件 | 超标时调什么 |
|---|---|---|
| **过曝** | ≤5.0%（无下限——低不是问题） | 高了→降激光档 |
| **背景** | 5~25 | 高了→降背光/遮环境光（补光已 0 还高＝环境光，去遮光） |
| **线数** | 目标 ±5（辅助参考，**以肉眼看线为准**） | 少了→升激光；多了→降激光 |

调参节奏：调一档 → 看面板时间戳跳 2~3 拍（约 0.1 秒）→ 再读数，避免被旧结果带偏。

**肉眼最终确认（判定面板代替不了）**：
- 左右**两个**预览窗里线都清晰（**右相机是短板**，重点看右）
- 线独立无粘连（两条线粘成一条亮带＝激光太亮）
- 无多余亮斑/反光带

## 三、采集操作规范

### 摆板（每个 pose）

1. 距离在 **200~500mm** 范围内换着摆（近/中/远都要有——深度跨度决定标定几何约束强度）
2. 角度换着倾（正对/左倾/右倾/前倾/后倾——多样性提升位姿质量）
3. **让全部线落在画面内**（贴边的线出画＝该 pose 作废主因）
4. 每次挪板后**等画面稳定**（1~2 秒）再拍

### 数量

| 管 | 推荐 pose 数 | 原因 |
|---|---|---|
| 左斜/右斜 | **25~30** | 门禁过门率约 20~25%，需 ≥5 帧干净帧（右斜 26→6 过→PASS） |
| 精细 | **24~30** | 同上＋深度跨度要大（部分线深度观测不足是 A6 超阈主因） |
| 深孔 | 15~20 | 单线过门率高 |

### ⚠️ 三条铁律

1. **采完不要关 GUI**——关窗会自动清空 data_in 图像（只留备份）。采完直接喊工程师标定，标定完再关。
2. **调参测试帧不要混进正式采集**——中途要试别的档位，先拍完当前批次或等正式采集时再试。混档帧（黑帧/过曝帧）会在标定时被整批拒掉。
3. **一次采完**——分多天/多批次采的数据亮度条件不一致，混标会互相拖累。

## 四、采完后

把「采完了」告诉工程师，由工程师执行：

1. CLI 跑标定（`laser_calib.exe data_in/laser/<数据集> <输出>`）
2. 验收指标：
   - **finalRms < 1**（右斜 0.086 / 深孔 0.003 / 精细质心口径 0.076 是标杆）
   - verdict = PASS（A5 线漂移 <1mm、A6 位姿漂移 <2mm、A7 盆地 <0.5mm）
   - framesOk ≥ 5（越多越好）
3. 通过 → 新 CMTT 表部署到主工程 `config/`
4. 不通过 → 工程师按《开发进度.md》261107/261108 日志的排障路线处理

## 五、常见问题速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 标定大量帧被跳过（loop done: n ok, 大量 skipped） | 门禁拒帧——正常设计（拒的是脏帧），只要 ok ≥5 | ok<5 → 加采 pose |
| 右眼线总是比左眼暗 | 右相机增益/曝光偏低或激光入射角 | 重点调到右眼清晰；持续偏暗报硬件检查 |
| 线粘成一片亮带 | 激光档过高（过曝 >5%） | 降激光档 |
| 线断断续续 | 激光档过低或线在阈值边缘 | 升激光档 |
| 背景降不下来 | 环境光（补光已 0） | 遮光——这是唯一解 |
| 重跑标定结果和上次不一样 | PJC 盆地漂移 | 正常——工程师会用 initialT 锚定（勿自行改 config） |
