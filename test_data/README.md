# test_data — 测试数据集中区

> 261103 建（人工指令）：所有测试的**输入与输出**统一归档在此，**每个测试主题一个子文件夹**，避免测试数据散落各处。

## 约定

- 子文件夹命名：`YYMMDD-主题`（例：`261103-probe抽检转储/`）
- 每主题内固定两档：
  - `in/` —— 本次测试的输入快照（配置文件、回放数据集路径说明等）
  - `out/` —— 本次测试的产出（probe 转储目录拷贝、日志摘录、对拍结果等）
- 软件运行时仍写自己的工作目录（exe 锚定 `build/bin/Release`，如 `diagnostics/fc_probe`）；**测试结束后由人工/AI 把产物拷贝归档**到主题 `out/`——改软件写盘路径须另立主题评审，不在本约定内
- **本区内容不入库**（`.gitignore` 忽略全部内容，仅本 README 与 `.gitignore` 随库）——大文件自行管理，仓库不背
