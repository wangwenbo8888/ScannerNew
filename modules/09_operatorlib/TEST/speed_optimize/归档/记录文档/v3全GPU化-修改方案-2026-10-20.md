# laser_match_scan_v3 单算子全 GPU 化·修改方案（2026-10-20 定稿 · v1.4 终版）

> 目标：**单算子全 GPU 化——无错误、更快**（4.16ms → 1.4-1.7ms 中位）。不考虑流水线。
> 演进：v1.0 三轮代理分析定稿 → v1.1 四代理审核（硬伤修正）→ v1.2 五代理瘦身（协作出局/原子版）→ v1.3 人工裁定原子版 → **v1.4 六代理终审修订（本版，实施以此为准）**。
> 实施以**沙箱副本**为准（`ops/scanning/laser/laser_match_scan_v3/`，3453 行；产线 1800 行是旧世代）。只动沙箱，不动 07，无 fc 同步债。

## 〇、承诺的准确措辞（终审定稿）

1. **常态热路径 100% 设备侧计算**：零中途同步、出口仅 1 次 ≤64B 回读＋终 sync；异常帧（U>48／超 250 轮／段分裂／溢出／CUDA 错误）回退宿主旧路径；
2. **无错误（统计性口径）**：在验证集（ALL 399 帧＋17 退化帧＋空帧＋注入路径）与漂移分类门覆盖下，与宿主 oracle 判定**等价**（winner 结构差＝0），仅容 pairSum 类末位漂移 ≤1e-6；不外推温漂/新数据形态；
3. **更快**：单算子中位 1.4-1.7ms（sparse_30 口径），最坏帧（走回退）不劣于基线 4.16ms。

数字置信标注：**实测锚定**＝4.16 基线／IssueCards 0.587ms／WDDM 间隔 5-20(隔离)/60-150(流水线)μs／c7 四相宿主耗时；**待 G-1 确认**＝K2 30-90μs（假设 10-30 轮）／U>48 频率／前半 0.7-0.9ms 纯执行拆分。重写段 0.10-0.20ms 上限略紧（K1a 70＋K1b 80＋K2 90≈0.21ms，K0 清零 15-70μs 与发射间隔未计）。

## 二、回退路径设计补丁（v1.4 新增，8 条）

1. **回退包定义**：votes＋segRows＋segmap＋ptRow＋left＋sorted＋segoff ≈0.8MB 统一下载函数＋pinned 池（数据源全部仍在设备侧 d_* 成员，无需重算；代价 ~0.2-0.4ms 仅尖刺帧）；
2. **K2 不变量**：d_seg_votes_ 全程**只读**（工作副本驻 shared）；H8 仅成功后写 winner/drop；中止＝置 flag＋跳过 H8，设备态保持＝K1 输出（否则宿主重算输入已被毁）；
3. fallback flag 并入终末 ≤64B 打包；**K2 后设检查点**（常态小同步 10-30μs 或回退帧重跑 Gather ~50μs，二选一）——防 Gather 已用半途 winner 跑完→回退帧 matched=0；
4. U 检测点＝K2 入口读 H6 输出（防 K1a/K1b 间多余同步）；
5. **错误分级**：sticky 错误（上下文坏）→fail 帧（D2H 也会失败，无回退可言）；非 sticky→回退包重算；沿用出口纪律，不递增 status_gen_、不打包半成品；
6. 回退帧记账：tbd 串加 `fb=U48/R250/ERR` 标签＋原因计数；benchOp/G3 **分桶剔除**回退帧（不污染中位/P90）；
7. G0 影子跑对回退帧同样逐位 diff（回退路径不豁免验证）；
8. 旧 g1/g2 下载代码标"回退专用，非热路径"。

## 三、验证体系（5 门＋分类器规格）

### 3.1 漂移分类器（终版规格）

**漂移面（已证明只有两个 float 门）**：票数/位图/行归属/share/margin 平票裁决全部整数或序无关＝零漂移；唯一入口＝门 A（友军均距 ≤15.0px，:1100）与门 B（间距带 |mdx−36.9|>20.295）。门 A 处分布空谷（真友军 <3px／非友军 ≥20px）→良性翻转概率 ≈1e-7/帧，399 帧期望 ≈0——**若真出现即异常信号，必须因果复现检验**。

```
for f in 399帧:
  A,B = oracle双跑(f)                          # 同输入宿主路径 vs GPU 路径
  if winner/drop/matched 全同: PASS
  if votes/pairN/xCnt 任一整数差: FAIL         # 原子丢失更新必中此网
  定位首个分歧段（票表/配对/单元/winner 二分）
  flips = [对(a,b) | A 判定≠B 判定]
  near  = all(|mean−15.0|<1e-6 或 |mdx−带边|<1e-6)
  repro = 宿主重放翻转 flips 后精确复现 B 的 winner/drop
  verdict = PASS(良性,归档+PLY≤0.01mm) if near且repro else FAIL
兜底：良性率>1% → 原子版 G0 不成立 → 启用确定性归约逐位版备胎（§五存档）
```

四类真 bug 报警性已论证：原子丢失更新（整数层 diff）／哨兵泄漏（剧烈结构差＋远离门限）／并查集错误合并（无近门对＋复现失败）／轮淘汰错序（选优键纯整数导出，flips 空或 near 假）。
