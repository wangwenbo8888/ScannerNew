# laser_cloud_normal · 激光法线估计（CPU）

## 1. 目标

- 功能：体素点 PCA 法线估计（后处理阶段 0），只算本帧新建体素
- 方法/参数：邻域复用融合哈希 O(1) 查找＋手写 3×3 Jacobi；kernelRadius=1、minNeighbors=3，邻域不足 3³→5³ 扩圈再走回退法线
- 注意点：法线不定向（±号歧义）；FusedPointPtr 勿跨帧持有

## 2. 现状

- 体素点 PCA 法线估计（后处理阶段 0）：达成｜主类 `LaserCloudNormalCPU`（laser_cloud_normal_cpu.h）：协方差最小特征值方向＝法线，手写 3×3 Jacobi 分解 ≤12 轮；在用：07 postprocess/NormalStage.cpp
- 只算本帧新建体素：达成｜只处理 fusedPoints_ 末尾连续段 [beginIdx,endIdx)——创建帧算一次、后续帧不重算，原位写入 FusedPointPtr(i)->{nx,ny,nz}
- 邻域复用融合哈希 O(1) 查找：达成｜复用 `LaserCloudFuseCPU` 的 GatherVoxelNeighbors O(1) 查邻居，零额外空间索引
- 方法参数 kernelRadius=1、minNeighbors=3＋3³→5³ 扩圈回退：达成｜代码实测＝卡默认：kernelRadius=1（3×3×3）/minNeighbors=3/fallback 法线 (0,0,1)＋fallback 计数统计；预设 smooth＝5×5×5＋最小 5 邻居
- 性能/质量锚：达成｜平面 10K 新建体素 3.66ms 零退化、典型帧 1-5K 体素 <2ms；退化率 <10% Normal／10~50% Degraded／≥50% Warning
- 约束（法线不定向／FusedPointPtr 勿跨帧持有）：达成（已固化）｜±号歧义需下游定向；无状态非线程安全、指针重分配后失效已记（单线共线点集 PCA 不稳靠扩圈缓解）
