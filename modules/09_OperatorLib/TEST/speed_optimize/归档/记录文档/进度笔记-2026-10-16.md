## 优化清单（全部落在本沙箱，产线零改动）

### laser_match_scan_v3（946→~7ms）
1. **温表注备缓存**：同（源表指针,档温,rowStep）重复注入跳过 873 万条 host
   分桶排序＋140MB×2 上传（根因：harness 每帧 SetTempTable/SetCurrentTemperature）
2. **单同步重构**：GPU segmap（CUB 排序＋游程 rank；成员位 rank=exSum−1）＋
   GPU winner/second 选举＋GPU exclCount 预备＋单批 pinned D2H；kSegCap=4096
   溢出/值域异常双回退 host 段表路径（防御）
3. **P6b**：segPts CSR＋excl GPU 预备（rowOrder 零卡下载）＋量门预检＋行窗口化
4. **P7**：稠密 S² 行主序对累加器（累加序与原版逐行升序一致→逐位一致）、
   assembly 单成员直拷、|lid差|>1 免归并、位图枚举免排序
5. PinnedBuf 持久回传；每帧日志降 DEBUG；maxCnt 折入 cards 核

### mask_separation（45.7→~8.5ms 双眼）
1. 每帧 Pipeline timings 日志降 DEBUG（省 ~20ms 控制台 IO）
2. 大核还原膨胀（41×41）→ **prevOne 算法**（行内最近 255：段含 255 ⟺
   prevOne[b]>a；O(N·R) 聚合读替 O(N·R²)）；step3 kh≥6 同样接入
3. prevOne/prevZero 行扫描 **向量化**（8 字节/步位技巧）＋**uint16** 存储
   （宽 1688<65535 恒成立；编码=位置+1，0=无——哨兵语义正确）
4. L/R 双流实测劣化（GPU 吞吐饱和）→ 保持串行

### 执行结构
1. **双链并行**：标记点链（CPU 工作线程，独立 CycleProducts 后合并）∥ 激光链
   （GPU 主线程）；ccl 走 streamMarker_；计时基点线程感知；JMW_SERIAL=1 可回退串行
2. **PNG 解码 IO 预取**：双 IO 线程（L/R 各一）＋深度 2（FramePrefetcher）——
   消除周期性 ~90ms spike（IO 为回放装置开销，产线相机直出）
3. **accumulateGlobalLaser 搬 GPU**（需求 §5）：__dmul_rn/__dadd_rn 显式 IEEE
   运算（禁 FMA 收缩，与 CPU 左结合树逐位一致）；grow-only 容量缓冲；
   ⚠ cv GpuMat::copyTo 会把目标降采样回源尺寸——扩容拷贝须写 grown 的 ROI 视图
4. **事件计时制**：纯 GPU 步骤（mask L→R 直通等）免逐步同步——timeBegin/End(gpu)
   只在流上记 cudaEvent，帧尾 flushStepEvents 一次同步统一算时长（更真实且省
   CPU-GPU 往返 ~2-4ms/帧）；mask 算子内部计时同步改 JMW_SEPTIME 门控

## steger 专项（2026-10-16 下午，全部落沙箱 ops/core/laser/steger_fast/，产线零改动）

**基线实测（本机构建，sparse_30 全 14 帧）**：steger 步中位 9.22ms（双眼合计、
事件计时、含算子内同步气泡），min 5.17；BENCH 分步/眼：Row3 0.42-0.74｜Col5
0.69-2.18｜Hessian 0.11-0.40｜Dedup 1.08-5.41｜Group 1.58-8.08｜Out 0.21-1.04
（后三段噪声大＝同步气泡＋ccl 争用）。原图 1688×1400，σ4→25tap，N≈3.2-3.4万/眼。

**三项优化（每项独立 A/B 验证后叠加）**：
1. **P0+P2-lite 同步/开销削减**：传播定轮（幂等不动点，免收敛回读）、溢出改帧尾
   合并回读（wait 6→3/眼）、5 次 memset 吸收进 kernel（CellPack/DedupInit/
   SegBoundary 顺带清零）、Flat 分组直通（label≡1，hist/CPU 前缀/scatter 全免，
   输出＝常驻缓冲 ROI 视图，免每帧 cudaMalloc×2＋D2D×2）、BENCH/日志改
   JMW_STEGTIME 门控、h_reject_ 改 pinned、删冗余 eventSynchronize → 中位 7.42
2. **P1 全融合卷积 kernel**（FusedConvHessianKernel）：Row3＋Col5＋Hessian/宽度门
   三合一，tile 32×16/512 线程，三中间平面只驻 smem（~118MB/眼显存流量归零），
   空 tile 核心区掩膜早退（tile 自足——tg 不落显存，跳块无需 halo 膨胀）。k 升序
   ＋同款 guard＋renormalize 逐字保留 → **与三分 kernel 版逐位一致**（同二进制
   FUSED 0/1 对拍：L1-steger CSV 排序后逐串相等）→ 中位 4.76（最好时段）
3. SegEmit 直出 coords/ids（dedup 成功路径免 FlatCopy 拷贝）

**精度验收（对基线二进制 golden，out_golden_base/）**：L1-steger CSV 多重集逐位
一致；report.csv 逐字节一致（非翻转运行）；全局激光 PLY 多重集差 0-8 行
（≤0.001mm，既有原子序类）；gtest 21/21。

**重要裁定——整帧翻转类抖动为链条固有**：全局激光 PLY 偶发单帧 ~2.07 万行移位
（~243mm，v3 段级投票在边际帧的配线翻转），双版本各 18/21 次对照：基线 3/18、
优化版 4/21——发生率无差异，**与 steger 优化（含输出点序）无关**，系本批退化
标定数据（极线 0.224px 超标）下 v3+配准链的固有非确定性。修复属 v3/配准专题。

**终态计时**（跨会话 GPU 状态方差大，同会话口径为准）：最好时段中位 4.76/
min 3.35；常态时段中位 6.3-6.6/min 4.9-5.7。同会话 FUSED 0/1：min 9.68→6.22
（融合 kernel 净省 ≥3.4ms/帧）。同步点 6→3/眼、发射 ~44→~24/眼。
**1ms 未竟**——剩余大头：DedupTangent（7×二分/点）、2×CUB RadixSort、
3 次 wait 气泡；破局需 CUDA Graph 定容捕获（P3，见前次方案评审）。

## 关键教训（排障记录）
1. ExclusiveSum 临时区必须与排序临时区分离（异步竞态→崩溃）
2. d_left_idx_in_ 预填＋D2D 方案在特定帧产生 segmap 不一致（回退 kernelCopySeq）
3. cv GpuMat::upload 会把缓冲**缩**到源尺寸（winner 上传后 kSegCap 缓冲变窄）
4. GPU double 运算须 __d*_rn 显式指令防 nvcc FMA 收缩（与 CPU 逐位对齐）
5. PNG 解码 ~50ms/张＞处理时长 → 预取深度不足会造成隔帧等待 spike
