# 速度优化执行计划 v2（2026-10-21 第三会话·第一轮审查后改版）

> v1 经第一轮 3 代理审查（R1-A 完备性/R1-B 正确性红线/R1-C 性价比）改版。
> 核心变更：废弃"memset 哨兵"方案 → **设备侧计数参数化＋紧缩后尾部戳记＋单点合并排水**；
> 采纳裁剪：砍第 3 步图打包与 4b float 化（R1-C：期望值负/验证纪律冲突）；S4 降为视时间。

## 关键设计（v2 核心：三条不变量替代哨兵 memset）

**不变量 D（设备计数）**：flat 的 K1 已用 atomicAdd 写设备计数（d_stats_[0]）。
undistort/interp 的逐点内核加可选参 `const int* dcnt`：`if (dcnt && tid >= *dcnt) return;`
（nullptr → 旧行为，legacy 路径零影响）。全链无 memset、无 NaN 编码、无跨帧残留读取——
每个内核的活动区间由设备计数硬界定。

**不变量 T（尾部戳记）**：任何"紧缩/持久输出"阶段后，尾段 [count,cap) 由**容量网格、
读设备计数**的小内核戳记为安全值（排序键→0xFFFFFFFF 排尾；紧缩点表→无效标记）。
替代 R1-A/B 指出的"Select 尾段陈旧数据"缺陷，无需宿主计数。

**不变量 P（合并排水）**：1b 每帧结构改为——
```
连续提交：flat L/R(deferred) → undist L/R(容量grid+dcnt) → interp L/R(内部容量化+dcnt+尾戳；计数→pinned异步)
一次排水（新增唯一宿主同步点）：流同步
读 pinned（flat N 左右/interp count 左右）→ 建精确 [0,N) ROI（FinishDeferred/FinishInterp 语义保留）
v3 前段 Execute（内核零改动——吃精确 ROI；其内部 sync#1/#2 保留＝S4 不做的代价）
RLE 拷出（gpuDrained=真，免事件同步）
```
每帧同步 6→3（合并排水 1＋v3 前段内部 2）。wall1b 预期 8.7→3.5-4.5ms（R1-C 口径）。
