## 一、通用构件

### 1.1 有界阻塞队列模板（SPSC 基型，MPSC 变体）

```cpp
template <class T, int Cap>
class BoundedQueue {
public:
    template <class U> bool push(U&& v);   // 满则阻塞 cvFull_；closed_ 返 false（仅 abort）
    bool pop(T& out);                      // 空则阻塞 cvEmpty_；closed_&&空 返 false
    // —— 载荷队列专用（B/D：容量三方回收，见 1.2）——
    void pushSwap(T& v);                   // buf_[tail].swap(v)：v 带回槽内旧容量缓冲
    void popSwap(T& out);                  // buf_[head].swap(out)：out 旧容量还给环
    bool tryPush(T& v);                    // 满则 v 原样带回返 false
    bool popWaitFor(T& out, std::chrono::microseconds us);  // 谓词等待＋定时（窃取探测用）
    void close();                          // 幂等；双 CV notify_all
    void closeProducer();                  // MPSC：各生产者结束调；prodCnt_ 归零才真关
    int  size();                           // mtx_ 下读（窃取探测/诊断）
private:
    std::mutex mtx_;
    std::condition_variable cvFull_, cvEmpty_;  // 空/满分离：生产者等 cvFull_，消费者等 cvEmpty_
    T buf_[Cap];                                // 构造一次性默认构造——运行期零分配
    int head_ = 0, cnt_ = 0, prodCnt_ = 1;
    bool closed_ = false;
};
```

```cpp
// push 伪代码
{ std::unique_lock lk(mtx_);
  cvFull_.wait(lk, [&]{ return closed_ || cnt_ < Cap; });
  if (closed_) return false;
  buf_[(head_ + cnt_) % Cap] = std::move(v);      // pushSwap 版：buf_[..].swap(v)
  ++cnt_; }
cvEmpty_.notify_all();   // 统一 notify_all：杜绝丢唤醒类死锁（pipe:549-550 范式）
// pop 对称：cvEmpty_.wait(...cnt_>0||closed_) → out=move → cvFull_.notify_all()
```

- **SPSC**（灰度环/C/E/F/A 子队列/TR）：prodCnt_=1 直接用。
- **MPSC**（B，3 生产 1 消费）：3 个 CPU链1 各 push；结束时各调 closeProducer()。
- P2 一律 mutex 版；P5 若链1 生产者侧 push 合计 >0.8ms 再评估无锁化（head/tail 各 alignas(64)），接口不变。

### 1.2 容量三方回收约定（B/D 载荷队列）

```
生产者.work ──pushSwap──▶ 环槽 ──popSwap──▶ 消费者.scratch
     ▲────────── 槽内旧容量缓冲经 swap 原路带回 ◀──────────┘
```

三方对象各只建一次，容量单调涨到数据集上界后**稳态零分配**。
POD 通道（A/C/E/F/TR/灰度）用普通 push/pop。

### 2.2 idx%3 分派器＋窃取

**P2 最小集：A 为单队列 BoundedQueue<AElem,8>（单消费者，无 %3 拆分）；P3 起 config
`fivechain.markerLanes` 切三子队列＋窃取（结构与下同）〔R7-A〕。**

```cpp
// 分派：lane = frameIdx % 3（确定性，同 laserQs_ 范式 pipe:230,540）；墓碑同入本 lane（帧序保持）
// CPU链1 lane i 主循环（〔R7-A 修正版〕——原 break 系线程退场 bug，禁用）：
for (;;) {
    AElem e;
    if (aQ_[i].pop(e)) {                         // 正常路径：弹出即处理
        process(e); rleFree_.release(e.slotIdx); pushB(e);
        continue;
    }
    if (aQ_[i].closed() && aQ_[i].size() == 0) break;   // close 且空 → 正常收队退出
    // 空转探测：谓词等待 100μs，醒后区分超时/关闭
    if (!aQ_[i].popWaitFor(e, 100us)) {
        if (aQ_[i].closed() && aQ_[i].size() == 0) break;
        if (trySteal(i, e)) {                    // 偷到元素 → 走处理，**勿 break**
            process(e); rleFree_.release(e.slotIdx); pushB(e);
            continue;
        }
        continue;                                // 超时/伪唤醒无害，重查谓词
    }
    process(e); rleFree_.release(e.slotIdx); pushB(e);
}
bool trySteal(int i, AElem& out) {               // 己空 && 邻 size≥2 → 偷 FIFO 首端（最紧迫）
    for (int j : {(i+1)%3, (i+2)%3})
        if (aQ_[j].size() >= 2)
            if (aQ_[j].tryPopFront(out)) { aQ_[j].cvFullNotify(); return true; }
    return false;
}
```

窃取改变"谁处理"，不改任何序约束（B 乱序合法区）；per-lane 帧处理直方图入 fc_metrics
（P3 判定＝Σ==totalCycles＋每帧恰一实例互斥，处理数差仅作窃取激活度观测）。
死锁论证不变：子队列容量=池容量→队满永不阻塞生产者；池级阻塞最终由消费释放解锁。
100μs 探测轮询为 P3 基线；可选优化：OnePerLine<atomic<bool>> hungry_[3] 跨队 notify。

evStegSlot[8] 流级事件＋stegFed_ 提交序，二者均由 1b 侧驱动。

## 三、CUDA 事件使用规范

1. **创建**：一律 cudaEventCreateWithFlags(cudaEventDisableTiming)（pipe:133-135 范式）。
2. **记录/等待分工**：生产流写完 record；消费流读前 wait。事件覆盖式：重录不影响已入队 wait；
   未记录过 wait 立即返回〔pipe:696-697〕。**任何跨流序依赖必须"提交序计数器＋执行序事件"双保险**。
3. **query vs 阻塞**：池回收轮询用 cudaEventQuery（E 块、GT）；帧尾批量对账用 Synchronize。
   自旋＋_mm_pause 仅限绑核专用线程 μs 级等待；P2 全部阻塞式。
4. **事件池复用**：每槽固定事件（evUpl_[8]/evStegSlot_[8]/evH2D_[9]/GT 每帧表），启动建 join 后销；
   禁止运行期 create/destroy。

## 四、关机协议

```
正常 EOS（墓碑保证每帧每通道恰一元素后）：
  预上传/读帧 → grayQ_.close()
  CUDA链1 → 产完 A/D（含墓碑）→ aQ_[0..2].close(), dQ_.close()
  CPU链1×3 → bQ_.closeProducer()                // MPSC 计数关闭
  CPU链2 → eQ_.close()
  CPU链3 → reorder_ 必已排空（断言）→ cQ_.close()
  CUDA链2 → mapC_/mapE_ 空（断言）→ fQ_.close()
  主线程 → fQ_ 排空 → join 全部线程（任意序）
  收尾 → cudaDeviceSynchronize() → 销毁全部事件 → cudaFreeHost 全部锁页池
         （次序照 pipe:155-175；执行器成员声明于 Harness 末位——先停线程再 Destroy 算子）

abort（析构停机）：全局 stop_=true＋全部 CV notify_all；push 一律返 false 丢弃（pipe:546 同款）；
消费侧 drain 后退出；join 后收尾同上。
```
