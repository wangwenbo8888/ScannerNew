### A.4 做什么＋为何 13 轮×2 眼

Scan 模式插值输出按行聚簇（每行 ≤SCAN_SLOTS=32 簇），行间断线需重连成段：LinkParent 给每簇在 `scan_link_gap_rows=8` 行窗内找 `|Δx|≤scan_link_dx=4.0px` 最近簇建父指针（森林）；LinkJump 指针倍增求根，簇根即段 ID。

13 轮来历（`:1066-1068`）：`rounds=ceil(log2(cap))`，cap=65536→16 轮**封顶 13**——父链每步必跨行（`rd>0` 强制 `:657`）→ 链深 ≤ 行数 8192=2¹³。双眼各 1 parent＋13 jump ⇒ **每帧 2 parent＋26 jump＝28 launches**。接力口径「link 26/帧」只计 jump；本报告以 28/帧 为收益口径。

## B) 图外原因

**结论：纯粹没并入（历史时序），不是数据依赖。**

1. 历史时序（主因）：submitLinkAtCapacity 是 10-23「WDDM 滴流修复」引入——把 link 从 FinishInterp（排水后、需 D2H 回读精确 N）提前到提交段按容量发射。1B 图是更早设计，捕获体边界就是 submitScanSequence（`:898` 注释「图捕获体＝逐发体同源」）；`:851-853` 注释明说「链接相位不在图内——图发射后按容量补提交」。
2. 容量化已消灭全部 host 数据依赖：rounds 是 cap 纯函数；有效界 `d_scan_ccount_` 是设备指针、内核内直读（`:647`）——天然合法图节点依赖。不存在「回读后决定下一轮」。
3. 真实障碍仅工程性：`d_link_parent_/d_link_label_` 惰性 create（`:1053-1056`）＝捕获窗内 cudaMalloc 需前置；host 分支 `scan_link_dx<=0 || cap<2`（`:1052`）捕获期可定死；两处 `cudaGetLastError`（`:1065/:1071`）据此 return false 会作废捕获，需移出。

## C) 入图方案（推荐案 A：并入现有 1B 捕获体）

1. **缓冲前置**：ensure 移到 `:827`（排空）之前、`:828` BeginCapture 之前——首建一次性此后 no-op。
2. **图激活条件**（`:822`）追加 `params_.scan_link_dx > 0.0f`：link 禁用时图不含 link 节点，与 FinishInterp 的 linked=false 语义（`:1152-1154`）一致。
3. **捕获体**：submitScanSequence 尾部（或新增 submitLinkPhase）追加 `dualScanLinkParent<<<256,256>>>`（gridL=256）＋13×`dualScanLinkJump`——网格/参数/轮数全容量定值，静态节点链。
4. **错误处理**：捕获体内删除两处 cudaGetLastError；错误统一走 EndCapture/Instantiate/Launch 失败→graphDisabled_ 永久回退（`:839-846` 机制已在）。
5. **消费端零改动**：删 `:853` 补提交；`lastLinkAtCap_` 改「图发射成功即置 true」；FinishInterp 只建视图逻辑不变；逐发 `:885` 原样保留。
6. **连带加固（必须）**：`SetParams`（`:1592-1614`）现重置 warmup 但**不销毁 deferGraphExec_**——图内参数烧死（现有 1B 图已烧 epipolar_row_step/window/max_x_diff/scan_x_gap，入图再烧 scan_link_dx/gap_rows）。应加：SetParams 时销图＋重置 graphWarmCalls_（或保守置 graphDisabled_）。

**落选案**：B 独立小图（graphLaunch +2/帧，无对价优势）；C 设备侧条件节点（无需求，徒增复杂度）；D 削减轮数（13 轮由链深≤8192 结构性封顶论证，减轮＝正确性风险，禁止）。

**CUDA Graph 限制逐条对照**：捕获窗内禁 malloc→前置 create 解决；host 分支不可入图→并入激活条件；禁 D2H 驱动结构→无此依赖；指针烧死→SetParams 销图连带修；捕获窗内 API 受限→cudaGetLastError 移出；无事件入图需求。

**WDDM 纪律对照**：捕获前排空本流 `:827` 已有；`:828` 已 ThreadLocal；C2 是协作次数，图化确定性下降（可对账）；帧率判据走 ABBA 不回退，勿预设收益。

## E) 风险清单

1. **数值零影响（红线）**：入图后内核/参数/发射序与逐发体完全同源；13 轮 jump 图内串行依赖链 FIFO 语义不变；尾部陈旧数据无害性论证（`:1044-1049`）不因提交方式改变；d_scan_ccount_ 读序由图内节点依赖保证。
2. **SetParams 图陈旧**（现有隐患，入图扩大面）：切片 1 连带修。
3. **缓冲 realloc 图陈旧**：cap 恒 kOutCap 实际不触发；作已知类风险记录。
4. **捕获失败回退正确性**：graphDisabled_ 永久回退＋FinishInterp 精确版双保险需专项验证臂。
5. **WDDM/竞态**：ThreadLocal＋排空纪律照旧；前置 create 在窗外；20 连跑零崩＋WER 核对。
6. **census 防虚降**：核对 graphLaunch 恒 298、beginCap/endCap 恒 2、C0 同额下降——防「只减计数不减真发射」。
