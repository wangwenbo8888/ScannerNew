## 六、关键设计决策记录（供新会话查阅）

| 决策 | 要点 |
|---|---|
| D1 无支持段＝弃＋告警 | 候选集空→设备误差信号 |
| D2 B 第二名全量口径 | 有分量的对手在场就不轻易定 |
| D3 votes_floor=4 | P2 镂空件约束 |
| D4 骨架不动只打补丁 | 人工 8 步骨架为权威 |
| D5 ZG 采纳 4 项 | ln 票数（未启用）/距离门（已关）/残差清洗/残差输出 |
| D6 简化＋速度优先 | P3 |
| ⑬ 大段优先排序 | 修"碎片抢号"事故 |
| ⑯ 三阶段回环重排 | 修"抢号竞速"（334 墙拆除） |
| 对称双门公式 | E=B×(r2/r1)；确认/翻案/死区三态；方向 bug 内建修复 |
| 按线号局部τ＋min 全局钳 | L1~16 局部收紧/L17~25 钳回全局 |
| 逐点门只对小段 | 人工最终裁定（261114） |
| τ 用中位数×k 而非标准差 | 代理分析：标准差≈只换 k 值＋抗污染差 7~20 倍 |
| ⑪ 与逐点门互补 | ⑪抓个别离群（跟同伴比）；逐点门抓绝对超标（跟字典比）；大段"整段一致偏高"是共同盲区（用户知情选择） |
