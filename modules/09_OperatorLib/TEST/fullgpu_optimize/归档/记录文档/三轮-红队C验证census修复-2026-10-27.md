## 二、必须修正清单（精确到行）

1. **case 替换边界**：整段替换 **:191-198**（同步版含 :198 外层 break）与 **:199-206**（async 版含 :206）——规格漏 break 行，机械按行替换残留悬挂 break
2. **【丢账风险】同步 2D 线程变体是 `_ptds_v7000`(=216) 非 _ptsz**：订阅四项＝cudaMemcpy2D_v3020(32)＋**cudaMemcpy2D_ptds_v7000(216)**＋cudaMemcpy2DAsync_v3020(44)＋cudaMemcpy2DAsync_ptsz_v7000(228)；ptds 须 `case A: case B:` fallthrough 并入 v3020 case（params 布局逐字段同构已核，cast 用 v3020_params 安全）——否则该订阅落 switch default 静默丢账
3. **【静默错位风险】两结构体同锚点插入**：cuda_census.h Counters（mc/mca 行 :21-22 附近）与 cpp StageRow（:28-29 附近）同一相对位置插 mc2D/mca2D——toCounters 整拷＋sizeof 断言不挡布局错位（不崩但快照字段静默错列）
4. **total() 两处都不加**（.h :33-41 与 cpp :40-48）——C0/C1/C2 冻结锚
5. **kCsvCols 插列位置＝writeRow 参数位置＝结构体字段位置**（列序==字段序==单一事实源约定）；格式串 41→43 个 %ld
6. 【建议】GEN 行输出在 COLLAB_C2 之后 fclose 之前（:391-393 间）；顺带更新接力文档 :25 表述
7. 【信息】无需额外 include
