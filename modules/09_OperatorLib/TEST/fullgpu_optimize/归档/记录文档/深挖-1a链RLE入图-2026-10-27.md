## C) RLE 图化主案（独立双眼小图 × 槽实例轮换）

对照 P2-4 link 入图模式逐条映射：

| P2-4 条款 | RLE 对应 |
|---|---|
| 容量定值零 host 依赖 | ✓ 全满足（网格=H×256 构造后不变；rleCap_/rleWin_ 构造期定值；单块 scan 无回读）——**比 link 更干净** |
| 缓冲前置 | tRows/tTotal（gpu_accum:170-172）前置首捕前；环已构造期建 ✓ |
| 图指针烧死对策 | **核心差异**：RLE 输出＝环形槽（dRleRingL_[rs]/rleCntRing_+2rs/rleRunsRing_+6cap·rs，随 rs 变）→ **每槽一个 graphExec（4 槽）轮换选择**——指针全固定烧死，零参数更新 API；输入 mask（分离实例 d_markingFinal）本就固定 ✓ |
| host 分支入激活条件 | 无 ✓ |
| 错误查询移出捕获体 | RLE 路径现无 ✓ |
| ThreadLocal＋排空 | 捕获帧 1 次 gS_.waitForCompletion()（仿 impl:1140；同流图在飞紧接 BeginCapture 有驱动崩溃前科） |
| SetParams 销图 | RLE 不含分离参数；仅 mask 尺寸守卫（尺寸变→4 槽全毁重建） |

**图节点（每槽）**：rleCount L/R→rleScan L/R→rleEmit L/R（6 内核）→memcpy ×3（counts＋runsL/R）→event record evRleRing[rs]（CUDA 12.6 支持）。**每帧图外仅 cudaGraphLaunch(rleGraphExec_[rs]) 1 次**（替代 10 次 API）。

**落选变体**：B 并入分离图（双眼耦合 vs per-眼实例，8 实例跨文件感知改动面大）；D 单深固定缓冲（rleCopied_ 闸门把在飞距压至 0＝串行化，禁止——lmask 单槽教训在案 fc_executor.h:337-341）。

**超窗路径不变**：gpuRleTailCopy（gpu_accum:224-241）消费图外事件后私有流补拷。
