# 测量纪律卡（2026-10-29 全天实证版，性能调试前必读）

## 五条铁律

1. **只认同窗配对差值**——跨窗/跨日绝对值差不可引用。当天三次实证：
   「健康态 B+20」是跨窗档案混引（M0 翻案起点）、H/fa 阶梯分化是机器波谷
   污染、B5 首轮画像 25% 是换档期坏样本。同窗 A/B 工具：`run_abba.ps1`
   （成对差值）/ `ladder_ab.ps1`（多臂阶梯）。
2. **测前先体检**——单遍 repeat 3 看 ALL median：**~165＝健康带**；148-158＝
   半恢复（可测相对值）；<120＝机器干预（只报告后停）。复健配方（ThrottleStop
   管理员）：TPL 面板 PL1=45＋勾 Sync MMIO＋不勾 BD PROCHOT＋不勾 Disable
   Controls；**重启后必须重设**（165 平台非重启即得）。
3. **双口径并列**——中位帧率对停顿失明（百遍定谳）：长窗结论必须「逐帧间隔
   中位＋时间域逐秒（fps_per_second.csv）」并列；停顿归因先查 fc_summary
   分段墙钟＋stdout rehash 行。
4. **同窗阶梯判形不判幅**——多臂阶梯块内配对看方向；幅度跨块仍不可比。
5. **改默认必过三门**——ctest 全绿＋同窗 ABBA（NO-REGRESSION 起）＋输出
   正确性抽验（同帧 markers/laser 逐位同）。

## 已踩坑清单（勿重踩）

- **typeperf**：残留输出文件→「没有有效的计数器」假报错，采样前必删旧文件
- **nsys 2024.5.1**：`--` 分隔符＝空选项 ambiguous，正确＝选项后直接跟 exe
- **PowerShell 管道早关**：`Select-Object -First N` 会杀原生进程（exit=-1
  假象＋产物缺失）；过滤一律 `*> $null` 后查文件
- **census 与竞速分跑**：回调污染帧率 -9~12%；**双锚口径**（2026-10-29 归档）：
  PSPIN 默认态 C2=1576.96＝轮询含（evQuery ~1550/帧）仅 PSPIN 臂内可比；
  跨版本对账一律 `JMW_PSPIN=0` 锚（C2=24.57，`Baseline_20261029_ps0_sp.csv`，
  与 N6 历史档逐位一致）
- **只编主程序忘编测试**：改路径类代码须同时重编 test 目标，否则旧测试
  二进制静默 SKIP 还报通过（征兆：ctest 从 ~80s 变 <1s）
